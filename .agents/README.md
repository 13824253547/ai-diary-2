# Local Agents Directory

This directory is reserved for project-local agent instructions.

## Purpose

Use this folder for repository-specific agent context that should override generic external habits when working on this project.

## Suggested Contents

- `project-context.md`: business background and boundaries
- `release-context.md`: local release identity and distribution notes
- `ui-rules.md`: visual consistency and component usage rules
- `workflow.md`: local development and verification workflow

## Rule

Anything stored here is considered higher priority than outside project context, as long as it does not conflict with the user's latest instruction.
