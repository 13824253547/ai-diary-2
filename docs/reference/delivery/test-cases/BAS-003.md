## CASE-BAS-003-001 重启恢复（待决策）

覆盖：T-BAS-003-A01。层级：存储集成 + iOS 流程。状态：待决策（Q-001/015）。
前置：按确认方案保存 D1、其公开设置、素材、聊天、点赞、纠正、成长及一个未提交草稿。
步骤：记录快照，结束进程并重开；从对应页面读取。
预期：应留存对象值/ID 与快照一致；草稿按 Q-001 决策恢复或清除，没有把未提交修改当已保存。

## CASE-BAS-003-002 资产稳定与缺失（待决策）

覆盖：T-BAS-003-A02。层级：媒体存储集成。状态：待决策（Q-001/015）。
前置：确认 P1 与生成配图属于需留存对象，明确生命周期。
步骤：导入 P1 并保存一张配图，移除导入临时文件后重启；另注入不存在的 URI。
预期：前两项在确认生命周期内可读取实际图片；缺失项提示缺失，相关作品仍可读，未显示无关样例图。

## CASE-BAS-003-003 启动竞态和空身份

覆盖：T-BAS-003-A03。层级：确定性存储集成。
前置：已有 D1 的仓库，延迟或拒绝加载；另准备全新身份。
步骤：启动应用，在加载完成前检查写调用；失败后重试；再加载新身份。
预期：加载前/失败时不提交空快照；重试仍有 D1；新身份无样例作品、历史对话或已解锁成长。

## CASE-BAS-003-004 原子写失败与重试

覆盖：T-BAS-003-A04。层级：故障注入集成。
步骤：保存新草稿时令写失败/提交中断，检查日记与草稿；恢复后重复提交同一草稿。
预期：失败不标已保存，存在完整可重试状态；成功后只有一篇完整作品，引用和草稿提交标志一致。

## CASE-BAS-003-005 迁移和损坏隔离

覆盖：T-BAS-003-A05。层级：存储集成。
数据：前一个支持的 schema 版本 D1、当前 D2、单条损坏记录及不支持版本记录。
步骤：加载并迁移，再重启读取。
预期：D1/D2 内容和 ID 保留；损坏/不支持项可定位且不清空其他对象；重复启动不重复迁移或复制数据。

## CASE-BAS-003-006 恢复后关联与访问

覆盖：T-BAS-003-A06。层级：存储/服务集成。
步骤：保存选段匿名 D1 后恢复；检查块/照片引用与公开投影；以其他身份请求私密部分。
预期：引用均指向有效所属资产，投影一致，越权不能读取完整作品。
