## CASE-BAS-003-005 迁移和损坏隔离

覆盖：T-BAS-003-A05。层级：存储集成。状态：partial。
数据：旧 schema（无 `Diary.contentSnapshot`）中的日记 D1、当前 schema D2；另有本地快照中的损坏记录及不支持版本记录。

预期：迁移后 D1 的 ID 和已有字段保留，新增正文列符合 nullable 契约；重复部署不再改变 schema。baseline 仅在 schema diff 无差异、migration history 是已知连续前缀且调用方显式确认时写入 migration metadata；业务表数据不变。损坏/不支持本地数据可定位，不清除其他有效数据。legacy 正文仍需有依据的回填策略，不得用摘要伪造正文。
