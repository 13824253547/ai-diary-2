# T-BAS-001 测试案例

关联：[任务](../tasks/BAS-001.md)。状态：部分执行。本文是文档/契约评审，后续接口实现另做运行测试。

## CASE-BAS-001-001 决策可追溯

覆盖：T-BAS-001-A01。层级：文档评审。
前置：选取一个准备开发的业务任务及其 Q 列表。
步骤：逐项检查任务内容和验收，追到 FSD/BR 或决策记录；检查未关闭问题的标签。
预期：所有确定要求有依据；未定部分有明确阻塞范围，不存在把 mock 数字或缺口当正式规则的项。

## CASE-BAS-001-002 对象与校验契约

覆盖：T-BAS-001-A02。层级：契约评审。
数据：D1 草稿/已保存版本、P1 URI、跨月日期、缺失 ID 与损坏数据样例。
步骤：用契约说明各对象的归属、引用、日期及留存，按定义判定样例有效性。
预期：每个字段和引用的解释唯一，缺失/非法样例有确定校验结果，图片支持真实 URI，不限于数字 require 资源。

## CASE-BAS-001-003 服务与异步事件

覆盖：T-BAS-001-A03。层级：契约评审。
数据：同一请求重复、响应丢失、取消后迟到回调、权限拒绝及空列表。
步骤：逐项按契约推演客户端与服务端状态及恢复动作。
预期：可以确定是否提交、是否可重试、是否更新数据；没有“收到响应即全部成功”的歧义。

## CASE-BAS-001-004 AI 评测可执行

覆盖：T-BAS-001-A04。层级：评测方案评审。
前置：某项 AI 能力的契约及质量表完成。
步骤：选正常、缺少元数据和失败样例，检查评测输入、输出结构、维度、通过标准和证据方式。
预期：结构和照片归属可自动判断，质量有明确标准；没有固定 mock 正文逐字断言或未经确认的分数门槛。

## CASE-BAS-001-005 变更同步

覆盖：T-BAS-001-A05。层级：文档评审。
步骤：选一条已关闭 Q（例如日期或导出）；比较决策、FSD、任务验收和案例预期。
预期：版本和行为一致，旧矛盾已更正或标停用，受影响案例能按同一规则执行。
