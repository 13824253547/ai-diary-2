# GRW-005 自动成长与花朵测试案例

**关联任务：** [T-GRW-005](../tasks/GRW-005.md)。**状态：未执行。** 遵循[共同约定](../execution-context.md)。成长数值来自确认读模型或 Q-006 规则，不从 mock 初始两朵推断。

## 可执行设计

### CASE-GRW-005-001 真实主题、进度与加载态

**覆盖：** T-GRW-005-A01。**层级：** 组件 / 契约。
**前置数据：** 一组真实成长读模型含主题、里程碑状态和当前进度，另有空 / 未加载夹具。
**操作：** 延迟读取结果后打开花朵页，依次返回有数据与空状态。
**明确预期：** 有数据时主题和进度等于读模型，里程碑名称 / 状态可辨；加载和空态不伪装为固定 2/3 已累积。

### CASE-GRW-005-002 未解锁拦截

**覆盖：** T-GRW-005-A02、T-GRW-005-A04。**层级：** 端到端 / 权限集成。
**前置数据：** 成长仓库给出未满报告门槛的真实状态。
**操作：** 点击报告入口，随后直接请求报告或带 `scenario=unlocked` 路由进入。
**明确预期：** 花朵保持对应锁定状态；入口解释集满 3 朵条件且不导航成功报告；生产权限不因开发参数改变，服务拒绝未授权正文。

### CASE-GRW-005-003 已解锁访问一致

**覆盖：** T-GRW-005-A03、T-GRW-005-A04。**层级：** 真实读取集成 / 端到端。
**前置数据：** 仓库有已达条件的真实成长状态，非开发页设置。
**操作：** 从树进入花朵，查看状态并点击报告，再重开两页。
**明确预期：** 树提示、花朵绽放状态、按钮语义和报告权限一致，入口可用；报告生成状态仍按 GRW-006 展示，不把解锁等同于报告已生成。

### CASE-GRW-005-004 状态写入失败、重试与身份

**覆盖：** T-GRW-005-A06、T-GRW-005-A04。**层级：** 存储 / 契约集成。
**前置数据：** 合法计算器输出待写入成长状态，写入失败；U1 / U2 成长不同，Q-001 留存已确认。
**操作：** 提交成长写入并失败，恢复重试，重启后切换身份，再送达旧 U1 回调。
**明确预期：** 未成功写入前不凭失败事件误解锁；恢复后与已确认持久状态一致；重开恢复 U1 允许留存的状态，U2 不继承 U1 花朵或权限。
