## 可执行设计

### CASE-PET-002-001 真实概览与空数据

**覆盖：** T-PET-002-A01。**层级：** 组件 / 契约。
**前置数据：** 统计读模型分别返回明确日记数与锚点数，及无记录状态。
**操作：** 进入萌宠页，先读取有记录模型，再切换空数据夹具。
**明确预期：** 小橘名称 / 形象可见；两个维度分别等于返回模型，无记录时依空数据契约展示，不出现固定 12 或示例累计数。

### CASE-PET-002-002 锚点入口与空集合

**覆盖：** T-PET-002-A02。**层级：** 端到端。
**前置数据：** 一个有锚点和一个空锚点的用户集合，默认集合契约已确认。
**操作：** 分别点击记忆锚点入口。
**明确预期：** 进入对应用户的默认集合；有数据可阅读，空数据显示锚点空态，不使用样例日记补齐。

### CASE-PET-002-003 跨页面同版本统计

**覆盖：** T-PET-002-A03。**层级：** 集成 / 端到端。
**前置数据：** 一个统计版本 V1，多个页面共享该读模型。
**操作：** 依次打开萌宠、我的、成长入口。
**明确预期：** 三处日记数均等于 V1；不因入口不同或页面重开多计一次。

### CASE-PET-002-004 数据更新与乱序刷新

**覆盖：** T-PET-002-A04、T-PET-002-A03。**层级：** 契约 / 集成。
**前置数据：** V1 与新增已保存记录后的 V2，V2 的数值由已确认 Q-005 算出。
**操作：** 返回萌宠刷新，先返回 V2 再延迟返回 V1，并前往其他概览。
**明确预期：** 已接受 V2 后不回退到 V1；最终三处与 V2 一致，新增锚点只在真实读模型确认后进入概览。

### CASE-PET-002-005 失败、重开与身份隔离

**覆盖：** T-PET-002-A04、T-PET-002-A01。**层级：** 存储 / 端到端。
**前置数据：** U1 有记录，U2 空集合；注入统计读取失败。
**操作：** 读取 U1 后令刷新失败，重试；重开并切换 U2，最后到达 U1 的慢响应。
**明确预期：** 失败不伪装成真实空数据；恢复后显示成功模型；U2 不见 U1 计数 / 锚点，迟到响应不污染其页面；缓存保留按确认契约。
