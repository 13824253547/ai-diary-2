# GRW-002 成长树与标签测试案例

**关联任务：** [T-GRW-002](../tasks/GRW-002.md)。**状态：未执行。** 遵循[共同约定](../execution-context.md)。四主题仅为展示基线夹具，不预设每个用户都有同样标签。

## 可执行设计

### CASE-GRW-002-001 标签读取与稳定 ID 导航

**覆盖：** T-GRW-002-A01。**层级：** 组件 / 集成。
**前置数据：** 标签读模型有当前四主题、稳定 ID 和不同锚点集合；其中两个标签测试别名相似。
**操作：** 查看树并逐个点击标签。
**明确预期：** 标签名称来自读模型，各路由携带正确 ID；锚点标题匹配对应名称，不靠名称 substring 选择集合。

### CASE-GRW-002-002 花朵与提示入口

**覆盖：** T-GRW-002-A02。**层级：** 端到端。
**前置数据：** 用户有真实成长读模型。
**操作：** 分别点击树上花朵、花朵主题文案和成长提示后返回。
**明确预期：** 三种动作都打开同一用户的真实花朵页，不只在某图形区域可用，不带生产解锁作弊参数。

### CASE-GRW-002-003 统计与成长读模型

**覆盖：** T-GRW-002-A03。**层级：** 契约 / 集成。
**前置数据：** 共享统计 V1 与成长状态 G1，具有不同于 mock 的进度；另备加载中状态。
**操作：** 进入树，延迟返回分区结果，然后返回 V1 / G1。
**明确预期：** 未加载时不显示固定“差3片叶子”或固定锚点 12；成功后两个统计和提示等于各自批准读模型，版本可识别。

### CASE-GRW-002-004 有栈与无栈返回

**覆盖：** T-GRW-002-A04。**层级：** 导航 / 端到端。
**前置数据：** 一次从我的进入，一次直接打开成长路由。
**操作：** 点击返回。
**明确预期：** 有栈回到上一页，无栈进入我的，不跳到其他身份上下文。

### CASE-GRW-002-005 更新、空态和读取失败

**覆盖：** T-GRW-002-A05、T-GRW-002-A01。**层级：** 组件 / 契约。
**前置数据：** 标签模型 V1、移除失效标签后的 V2、空集合及失败。
**操作：** 刷新到 V2，切空数据，再注入读取失败并重试。
**明确预期：** 成功更新后失效标签不再可点到旧集合；空集合可辨且不补四个样例标签；失败不是空数据成功态，重试恢复真实模型。

### CASE-GRW-002-006 身份切换与旧响应

**覆盖：** T-GRW-002-A05、T-GRW-002-A03。**层级：** 权限 / 存储集成。
**前置数据：** U1 标签和成长不同于 U2；U1 请求故意延迟。
**操作：** 切 U2 后接收 U1 标签 / 成长响应，重开页面。
**明确预期：** 只显示 U2 数据，旧请求不改变树、概览或跳转目标；重开按真实仓库恢复。
