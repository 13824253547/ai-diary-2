## 验证边界

- 前后端 Jest 替身、仓储和 Store 测试不等同真实 Prisma/MySQL 验收。
- 真实 E2E 必须通过 `backend/test/e2e-database-safety.ts` 并提供隔离的 `E2E_DATABASE_URL`；不得指向生产库或默认开发库。
- 真实 iOS 系统确认弹窗和已分享文件无法撤回的行为须分别记录，不自动计入完整 CASE passed。

本轮定向运行：后端 5 suites / 27 tests、backend build 通过；客户端 4 suites / 54 tests 与 root typecheck 沿用此前记录。既有页面 React `act()` 警告仍输出；完整 CASE 及矩阵 passed 数不据此更新。
