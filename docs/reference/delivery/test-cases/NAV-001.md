# T-NAV-001 测试案例

## CASE-NAV-001-001 入口参数隔离

覆盖：T-NAV-001-A01。层级：界面流程。状态：部分执行。
前置：D1/D2、两个草稿、素材照片和两个故事均存在。
步骤：从首页/回忆/素材/明信片/发现/我的依次打开目标；返回后再打开另一目标。
预期：每页展示所选对象；切换对象不沿用上次 ID、草稿或临时素材。
当前执行：`app/__tests__/more-actions-screen.spec.tsx` 已验证详情操作菜单会把当前 `diaryId` 正确带入编辑/公开范围/分享入口，且继续编辑复用同一草稿；`app/__tests__/replace-photos-route.spec.tsx` 已验证整篇换图辅助入口会优先复用显式 `draftId` 或同作品现有编辑草稿，不会串到其他作品。首页、回忆、素材、明信片、发现、我的等完整入口矩阵仍待补齐。

## CASE-NAV-001-002 创作流程退出

覆盖：T-NAV-001-A02。层级：iOS 界面流程。状态：部分执行。
步骤：从未授权开始，依次允许、选图、选类型、选角色、生成；在每个步骤返回/取消，并另测试人物命名跳过和编辑放弃。
预期：草稿及角色/照片选择按规则保留或丢弃；未确认选择不写入；保存后回到正确完成页/详情。
当前执行：`app/__tests__/photo-permission-screen.spec.tsx`、`app/__tests__/album-select-screen.spec.tsx`、`app/__tests__/naming-screen*.spec.tsx`、`app/__tests__/edit-screen.spec.tsx` 与 `src/components/navigation/__tests__/bottom-tabs.spec.ts` 已验证授权沿用同一草稿、选图取消继续/放弃、命名保存/跳过/失败保留、编辑页返回继续/放弃，以及底部导航离开确认。生成页返回、浏览排版师后页面顺序和部分返回目标仍受 Q-009 / Q-018 影响，暂不宣称全链路通过。

## CASE-NAV-001-004 无效目标与深链

覆盖：T-NAV-001-A04。层级：路由/安全集成。状态：部分执行。
前置：D1 为当前身份可访问的已保存作品，另准备不存在目标及无权目标。
步骤：冷启动及深链分别打开有效 D1、不存在日记/故事/草稿、无权目标和无效参数的公开/编辑路径；以未授权状态访问照片路径。
预期：有效 D1 恢复后正常打开；其余显示对应空态/错误态或进入权限页，不展示其他对象，不执行越权读取或写入。
当前执行：`app/__tests__/replace-photos-route.spec.tsx` 已验证无效 `id` 的整篇换图辅助入口不会误跳到其他作品；`app/__tests__/saved-diary-screens.spec.tsx` 已验证未保存 `draftId` 不会被误当成正式详情。冷启动、公开深链、故事详情、无权目标和未授权照片路径的整矩阵仍待补齐。

## CASE-NAV-001-005 取消与重复打开

覆盖：T-NAV-001-A05。层级：界面 + 领域。状态：已执行。
步骤：编辑 D1 输入修改后返回选择继续，重复打开同一草稿，再放弃；对保存按钮连续点击。
预期：继续时草稿仍在且 D1 原文未变；放弃后草稿消失；保存只产生一次符合幂等规则的提交。
当前执行：`src/components/navigation/__tests__/bottom-tabs.spec.ts` 已验证未保存创作路径离开时，选择“继续编辑”会保留草稿，选择“放弃”才会真正丢弃并跳转；`app/__tests__/more-actions-screen.spec.tsx` 与 `app/__tests__/replace-photos-route.spec.tsx` 已验证重复打开编辑/换图时会复用同一草稿，不创建重复草稿；`app/__tests__/album-select-screen.spec.tsx`、`app/__tests__/edit-screen.spec.tsx` 已验证取消不提交、放弃清理、保存成功回详情以及连续点击保存只提交一次。
