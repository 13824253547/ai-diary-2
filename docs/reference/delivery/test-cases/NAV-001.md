# T-NAV-001 测试案例

关联：[任务](../tasks/NAV-001.md)、[页面映射](../../business-spec/page-map.md)。状态：未执行。

## CASE-NAV-001-001 入口参数隔离

覆盖：T-NAV-001-A01。层级：界面流程。
前置：D1/D2、两个草稿、素材照片和两个故事均存在。
步骤：从首页/回忆/素材/明信片/发现/我的依次打开目标；返回后再打开另一目标。
预期：每页展示所选对象；切换对象不沿用上次 ID、草稿或临时素材。

## CASE-NAV-001-002 创作流程退出

覆盖：T-NAV-001-A02。层级：iOS 界面流程。
步骤：从未授权开始，依次允许、选图、选类型、选角色、生成；在每个步骤返回/取消，并另测试人物命名跳过和编辑放弃。
预期：草稿及角色/照片选择按规则保留或丢弃；未确认选择不写入；保存后回到正确完成页/详情。

## CASE-NAV-001-003 详情操作（待 Q-009）

覆盖：T-NAV-001-A03。层级：界面流程。状态：待决策（Q-009）。
步骤：从详情执行继续编辑、设置公开范围、分享并返回。
预期：按 Q-009 确认的入口和返回目标验收；当前原型“更多”仅隐私入口不能直接作为最终通过证据。

## CASE-NAV-001-004 无效目标与深链

覆盖：T-NAV-001-A04。层级：路由/安全集成。
前置：D1 为当前身份可访问的已保存作品，另准备不存在目标及无权目标。
步骤：冷启动及深链分别打开有效 D1、不存在日记/故事/草稿、无权目标和无效参数的公开/编辑路径；以未授权状态访问照片路径。
预期：有效 D1 恢复后正常打开；其余显示对应空态/错误态或进入权限页，不展示其他对象，不执行越权读取或写入。

## CASE-NAV-001-005 取消与重复打开

覆盖：T-NAV-001-A05。层级：界面 + 领域。
步骤：编辑 D1 输入修改后返回选择继续，重复打开同一草稿，再放弃；对保存按钮连续点击。
预期：继续时草稿仍在且 D1 原文未变；放弃后草稿消失；保存只产生一次符合幂等规则的提交。

## CASE-NAV-001-006 路由映射核验

覆盖：T-NAV-001-A06。层级：文档/人工导航验收。
步骤：按页面映射逐项检查 37 个页面/别名/辅助入口，记录入口、参数、返回和权限；另检查根布局及 tabs 布局的页面栈、弹层与底部导航配置。
预期：每个入口有有效或明确的辅助/重定向说明；别名与主路由行为一致，两个布局支持相应导航且不作为独立页面打开，不存在未记录的业务入口。
