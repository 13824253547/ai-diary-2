# DSC-001 发现浏览与搜索测试案例

**关联任务：** [T-DSC-001](../tasks/DSC-001.md)。**状态：部分执行（TEST-14 后端 MySQL 子集）。** 遵循[共同约定](../execution-context.md)；S1 / S2 的作者、地点、日期为可控夹具。

## 可执行设计

### CASE-DSC-001-001 分类状态与最新排序

**覆盖：** T-DSC-001-A01、T-DSC-001-A02。**层级：** 组件 / 契约。
**前置数据：** S1 日期晚于 S2，查询替身故意以旧故事先返回；分类契约已确认。
**操作：** 进入发现，依次点击三个分类，再选最新。
**明确预期：** 初始推荐选中；每次查询条件与选中分类一致；最新视图 S1 在 S2 前，不依返回数组的错误顺序。

### CASE-DSC-001-002 三字段搜索与分类交集

**覆盖：** T-DSC-001-A03。**层级：** 契约 / 集成。
**前置数据：** S1 / S2 的标题、城市、作者各含唯一检索片段，已确认城市集合。
**操作：** 分别搜索三种片段，再带相同关键词切换分类。
**明确预期：** 每个片段命中相应字段；结果同时满足分类和关键词，切换不清空词，不能把不满足分类的命中混入。

### CASE-DSC-001-003 无结果与清空恢复

**覆盖：** T-DSC-001-A04。**层级：** 组件 / 集成。
**前置数据：** 当前分类有 S1 / S2。
**操作：** 输入确定不存在的词，再清空。
**明确预期：** 真正零结果显示空态；清空后恢复当前分类的两条夹具，不改变所选分类。

### CASE-DSC-001-004 收起展开保留筛选

**覆盖：** T-DSC-001-A05、T-DSC-001-A03。**层级：** 组件 / 端到端。
**前置数据：** 输入唯一片段后仅显示 S1。
**操作：** 收起搜索框，再展开。
**明确预期：** 收起期间仍仅显示 S1；重开时关键词相同，未触发无条件全量查询。

### CASE-DSC-001-005 卡片与详情目标

**覆盖：** T-DSC-001-A06。**层级：** 真实集成 / 端到端。
**前置数据：** 真实测试内容源有 S1 / S2，封面和作者不同。
**操作：** 验证卡片后点击 S2 封面或标题。
**明确预期：** 封面、作者、标题及点赞摘要对应真实 S2；路由带 S2 的稳定 ID，详情不打开 S1。

### CASE-DSC-001-006 查询乱序与重复页

**覆盖：** T-DSC-001-A07。**层级：** 契约 / 集成。
**前置数据：** 查询 Q1、Q2 条件不同，可控响应；分页返回含重复 S1 的下一页。
**操作：** 发 Q1 后立即改词发 Q2，先返回 Q2 再 Q1；按已确认分页契约连续加载 / 重放同一页。
**明确预期：** 列表保持 Q2 条件对应结果；旧 Q1 不覆盖；同一 ID 仅一张卡片，不因重复加载丢页或重复展示。

### CASE-DSC-001-007 离线失败与重试

**覆盖：** T-DSC-001-A04、T-DSC-001-A07。**层级：** 集成 / iOS 端到端。
**前置数据：** 真实测试服务可恢复，首次加载注入离线 / 超时。
**操作：** 进入发现，观察失败，恢复网络后重试。
**明确预期：** 失败有可恢复反馈且不是“无故事”空态；重试使用当前分类与词，返回真实数据，不自动回到旧查询。

### CASE-DSC-001-008 权限过滤与身份重开

**覆盖：** T-DSC-001-A07、T-DSC-001-A06。**层级：** 真实服务集成。
**前置数据：** 服务契约中 U1 可见 S1、U2 不可见；S2 为共有可见故事。
**操作：** U1 浏览后重开，切换 U2 并刷新，延迟送达 U1 查询响应。
**明确预期：** U2 仅见其可访问结果，缓存和迟到回调不能展示 S1 私有字段；重开读取真实内容，不能从固定数组补数据。
