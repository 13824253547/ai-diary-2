# T-BAS-005 账号认证测试案例

状态：部分定向验证，完整验收未执行。测试隔离、安全边界与证据格式遵循 [共同约定](../execution-context.md) 和 [BAS-004](../tasks/BAS-004.md)。

2026-11-19：隔离 MySQL 定向 E2E 覆盖注册邮箱码错误后重试、登录替换旧会话、退出、注销、并发登录单会话、事务回滚及注销时其他账号日记保留；邮件适配器为测试替身。真实 SMTP 收件、iPhone 拼图交互及完整业务数据/媒体删除验收仍待执行，不将 CASE 标为完整通过。

## CASE-BAS-005-001 用户名与密码注册

- 覆盖：T-BAS-005-A01。
- 验证用户名/密码边界、邮箱格式与规范化唯一性、Argon2id 哈希、密码及邮箱验证码不出现在日志。
- 邮箱验证码应由注册拼图挑战触发；覆盖拼图错误/重放、邮箱验证码错误/过期/重放/超尝试次数，只有有效邮箱码可创建账号并签发会话。
- 验证已注册邮箱的发码响应不泄露邮箱是否存在，SMTP 凭据缺失或投递失败时不创建账号。

## CASE-BAS-005-002 登录与单活跃 session

- 覆盖：T-BAS-005-A02。
- 验证正确凭证可登录；错误用户名和错误密码使用相同外部错误语义。
- 第二次登录使第一次 session 立即失效；两次并发登录最多保留一个有效 session。

## CASE-BAS-005-003 用户主体与跨账号隔离

- 覆盖：T-BAS-005-A03。
- 在隔离 MySQL 中建立账号 A/B、各自日记/照片/聊天/锚点/成长数据。
- A 替换 body、query、路径 ID 或伪造旧 `x-device-id` 访问 B 资源，均不得读取或修改 B 数据。

## CASE-BAS-005-004 启动门禁与登出

- 覆盖：T-BAS-005-A04。
- 无 token、过期 token、已撤销 token、断网和有效 token 分别启动；验证无身份不能进入受保护主路径。
- 登出后 token 立即被服务端拒绝，本机凭证和当前账号内存态清除；新登录不得读取前账号缓存。

## CASE-BAS-005-005 永久注销与文件清理

- 覆盖：T-BAS-005-A05。
- 请求注销验证码前要求当前密码；错误密码不得发送邮件。验证码必须发往账号绑定且已验证的邮箱。
- 删除接口同时要求当前密码、有效的一次性注销码；错误、过期、重放或不匹配账号的验证码均不得删除数据。
- 验证公开快照撤下、账号业务行/会话/媒体文件清理；注入文件清理失败时本机凭证清除、接口明确返回待清理且后台重试。

## CASE-BAS-005-006 新旧数据隔离

- 覆盖：T-BAS-005-A06。
- 按 2026-11-19 用户决定，新系统不得读取、兼容、迁移或清理旧匿名数据；验证账号草稿与素材按新身份和服务地址隔离，启动不会删除本机旧缓存。
- 部署仅使用独立的新数据库和媒体目录；在专用资源中验证旧数据不被读取或修改，新账号从空数据开始。

## CASE-BAS-005-007 设备身份移除

- 覆盖：T-BAS-005-A07。
- 静态检索运行路径确认无 `x-device-id`、设备身份注册/续期、App Attest 和安装密钥入口。
- 检查 Expo/iOS 最终配置不再声明 App Attest entitlement；账号 bearer session 仍能访问业务 API。

## CASE-BAS-005-008 隐私与商店披露

- 覆盖：T-BAS-005-A08。
- 人工比对政策、App Store 数据收集说明、邮箱字段、SMTP投递接收方和注销实现；邮箱声明与账号关联并以 App 功能为用途。
- 无密码找回仍需明确说明；无法确认的 SMTP 日志/备份时限保持待核，不作即时清除承诺。
