### CASE-GRW-001-005 读取失败、刷新乱序与重开

**覆盖：** T-GRW-001-A06、T-GRW-001-A04。**层级：** 存储 / 契约。
**前置数据：** U1 V1/V2、U2 独立资料；注入读取失败和延迟旧响应。
**操作：** 读取 U1 后刷新失败再恢复 V2，终止 / 重开并切 U2，最后返回 U1 V1 回调。
**明确预期：** 失败不是零记录成功态；已接受 V2 不被 V1 覆盖；U2 不含 U1 资料、计数或月份；恢复依留存契约，页面状态可解释。
