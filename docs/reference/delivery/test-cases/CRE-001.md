# CRE-001 相册授权测试案例

关联任务：[T-CRE-001](../tasks/CRE-001.md)

状态：未执行

夹具、替身与真实环境以及执行证据格式统一遵循[共同约定](../execution-context.md)。各案例独立初始化；“待决策”先补明确断言再执行。真实集成必须保留请求/资源/存储证据，替身通过不能替代真实交付。

### CASE-CRE-001-001 未授权拦截相册读取

- 覆盖任务验收：**T-CRE-001-A01**
- 层级：确定性/组件与契约
- 状态：未执行
- 数据/前置：权限替身为未决定；新建草稿 G1；读取适配器记录调用次数。
- 步骤：开始创作；在说明页未操作时尝试直接打开选择路由。
- 明确预期：用途说明先出现；相册读取次数为 0；选择页不可进入；草稿仍未授权。

### CASE-CRE-001-002 允许后沿用有效草稿

- 覆盖任务验收：**T-CRE-001-A02**
- 层级：确定性/组件与状态
- 状态：未执行
- 数据/前置：G1 已选第二位有效角色，权限替身成功；记录 G1 ID、角色及类型。
- 步骤：点击允许；返回允许事件；读取选择页与草稿。
- 明确预期：只进入一次选择页，draftId 为 G1；角色及类型与请求前一致，没有新建 G2。

### CASE-CRE-001-003 暂不允许与关闭放弃新建

- 覆盖任务验收：**T-CRE-001-A03**
- 层级：确定性/组件
- 状态：未执行
- 数据/前置：两个独立 G1 初始场景：暂不允许、关闭；未保存列表为空。
- 步骤：分别执行对应退出动作，再返回首页查看列表和草稿。
- 明确预期：不进入照片选择；G1 被删除、activeDraftId 不再指向 G1；日记列表未增加，权限未标记允许。

### CASE-CRE-001-004 授权不能公开作品

- 覆盖任务验收：**T-CRE-001-A04**
- 层级：确定性/领域
- 状态：未执行
- 数据/前置：新建 G1；权限替身允许。
- 步骤：初始化草稿；完成授权并选择 P1/P2/P3；读取草稿公开范围。
- 明确预期：初始化及操作后 privacy 均为 private；没有公开范围保存请求。

### CASE-CRE-001-005 关闭后迟到授权及重复回调

- 覆盖任务验收：**T-CRE-001-A05**
- 层级：确定性/竞态
- 状态：未执行
- 数据/前置：可延迟权限请求；G1 开始请求后关闭，并建立 G2。
- 步骤：先返回 G1 的允许事件两次；再完成 G2 的权限操作。
- 明确预期：G1 不复活、不导航；G2 不被旧回调覆盖；有效请求最多推进一次。

### CASE-CRE-001-006 iOS 系统授权读取真实相册

- 覆盖任务验收：**T-CRE-001-A01**、**T-CRE-001-A02**、**T-CRE-001-A05**
- 层级：真实集成/iOS
- 状态：未执行
- 数据/前置：重置测试设备授权；实际准备 P1～P4；记录设备、系统及权限适配器版本。
- 步骤：从创作说明发起系统授权，选择 BAS-001 已确认允许状态；进入照片选择。
- 明确预期：系统显示真实授权结果；许可范围内实际图片可加载；记录权限状态与资源 ID，不能用 mock 网格作为证据。

### CASE-CRE-001-007 有限访问、拒绝与撤回

- 覆盖任务验收：**T-CRE-001-A03**、**T-CRE-001-A05**
- 层级：真实集成/待决策
- 状态：待决策
- 数据/前置：Q-018 关闭后按其权限状态矩阵重置设备。
- 步骤：分别有限选择、拒绝、从设置撤回并重新进入创作。
- 明确预期：依 Q-018 已确认状态矩阵补入导航与恢复断言；通用底线为未许可资源读取为 0，不能标记授权成功。
