# GRW-003 锚点提取与关联测试案例

**关联任务：** [T-GRW-003](../tasks/GRW-003.md)。**状态：未执行。** 遵循[共同约定](../execution-context.md)。AI 短摘按来源与质量评测，不逐字比对样例首句。

## 可执行设计

### CASE-GRW-003-001 真正提取与来源追溯

**覆盖：** T-GRW-003-A01。**层级：** 真实提取服务集成 / AI 评测。
**前置数据：** Q-016 / Q-002 提取契约已确认；D1 / D2 正文、日期、封面不同，真实保存成功。
**操作：** 触发规定提取事件，等待成功，再按标签打开集合。
**明确预期：** 有实际提取请求和保存结果；每个展示锚点的来源 ID / 版本、日期、标题、封面可追溯到对应日记；短摘通过确认的相关性维度，不能凭固定映射产出与来源无关的示例内容。

### CASE-GRW-003-002 点击原日记

**覆盖：** T-GRW-003-A02。**层级：** 端到端 / 权限集成。
**前置数据：** D1 / D2 标题相同但 ID、正文不同，各有锚点。
**操作：** 点击 D2 的锚点卡片。
**明确预期：** 打开 D2 ID 和正文，不通过标题误开 D1，也不读取其他用户同名作品。

### CASE-GRW-003-003 纠正叠加与原提取保留

**覆盖：** T-GRW-003-A03。**层级：** 集成。
**前置数据：** 两锚点，一条有真实保存纠正 C1，一条无纠正。
**操作：** 读取集合并重开。
**明确预期：** 前者显示 C1 和更新标识，后者显示自身提取结果；两者仍有来源引用，纠正不伪造为原日记正文。

### CASE-GRW-003-004 不可访问来源与空集合

**覆盖：** T-GRW-003-A04。**层级：** 契约 / 权限集成。
**前置数据：** 集合中仅有已明确不可访问 / 不存在的来源；不要求新增删除界面。
**操作：** 读取集合，尝试打开旧锚点 ID。
**明确预期：** 不显示对应卡片或死链接，集合显示空态；旧 ID 查询不返回来源私密正文。

### CASE-GRW-003-005 提取失败、重复与旧版本

**覆盖：** T-GRW-003-A06、T-GRW-003-A01。**层级：** 契约 / 集成。
**前置数据：** D1 版本 V1、编辑保存后的 V2；两个提取请求可重放；一次注入超时 / 畸形返回。
**操作：** 触发 V1 后 V2，先返回 V2，再返回 V1 和重复 V2；失败按契约重试。
**明确预期：** 畸形结果不被当有效锚点，失败可见；同版本重放不重复创建，V1 不覆盖 V2；最终读模型与当前已提交来源版本相符。

### CASE-GRW-003-006 留存与身份切换

**覆盖：** T-GRW-003-A07、T-GRW-003-A02。**层级：** 真实存储 / 权限集成。
**前置数据：** 已确认 Q-001 范围，U1 已保存锚点，U2 无权访问 U1 日记。
**操作：** 重启后打开 U1，再切 U2 查询同锚点 ID，交付迟到 U1 提取结果。
**明确预期：** U1 在批准范围恢复锚点 / 来源版本；U2 不见内容或计数，旧回调不跨身份写入；服务与客户端均遵守隔离。
