## 可执行设计

### CASE-DSC-002-001 真实内容完整阅读

**覆盖：** T-DSC-002-A01。**层级：** 真实集成 / iOS 端到端。
**前置数据：** 真实测试服务保存字段互不相同的 S1 / S2。
**操作：** 从卡片打开 S2，滚动阅读全部正文。
**明确预期：** ID、标题、作者、封面、日期、地点、正文和点赞摘要来自 S2，与实际服务记录相同；正文完整可达，无 S1 混入。

### CASE-DSC-002-002 来路返回与直接打开

**覆盖：** T-DSC-002-A02。**层级：** 导航 / 端到端。
**前置数据：** 一次从列表带历史进入，一次从有效故事链接无历史进入。
**操作：** 各点击顶部返回。
**明确预期：** 有历史返回进入前页面；无历史按 BAS 路由契约进入可用发现页面，不留死页面或无效返回按钮。

### CASE-DSC-002-003 无效 ID

**覆盖：** T-DSC-002-A03。**层级：** 契约 / 端到端。
**前置数据：** 服务明确返回目标不存在。
**操作：** 以不存在 ID 进入详情，点击返回发现。
**明确预期：** 显示缺失态，不展示上一次故事；返回动作进入发现。

### CASE-DSC-002-004 网络失败与恢复

**覆盖：** T-DSC-002-A04。**层级：** 集成。
**前置数据：** 有效 S1，详情第一次请求超时，第二次成功。
**操作：** 打开 S1 并重试。
**明确预期：** 超时不显示“目标不存在”；恢复动作可执行，第二次显示 S1，不使用样例正文代替成功。

### CASE-DSC-002-005 权限拒绝不泄露正文

**覆盖：** T-DSC-002-A04。**层级：** 真实服务 / 权限集成。
**前置数据：** BAS 身份契约中 U1 可读 S1，U2 不可读；权限拒绝返回不含正文。
**操作：** U1 打开后切 U2，直接打开 S1 ID，并交付迟到的 U1 响应。
**明确预期：** U2 看不到封面中的敏感信息或正文，旧缓存 / 回调不突破当前身份；缺失 / 权限用户提示遵循已确认错误契约。

### CASE-DSC-002-006 路由切换乱序

**覆盖：** T-DSC-002-A01、T-DSC-002-A04。**层级：** 组件 / 契约。
**前置数据：** S1 详情请求慢于 S2。
**操作：** 发 S1 请求后转 S2，先返回 S2 再 S1，退出详情再返回。
**明确预期：** 当前路由只显示 S2；迟到 S1 不改变标题或正文；退出后回调不导致错误导航或幽灵内容。
