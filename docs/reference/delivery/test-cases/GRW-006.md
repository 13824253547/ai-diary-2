## 可执行设计

### CASE-GRW-006-001 未解锁直接访问

**覆盖：** T-GRW-006-A01、T-GRW-006-A02。**层级：** 服务权限 / iOS 端到端。
**前置数据：** 用户真实未解锁；可以直接调用读取 / 生成能力并打开路由。
**操作：** 直达报告，带开发解锁参数，再直接请求生成 / 读取；点击锁定页花朵动作。
**明确预期：** 仅显示锁定说明，正文不返回、未授权生成不执行；参数不能改变权限；花朵动作进入真实成长页。

### CASE-GRW-006-002 真实报告生成与三维结构

**覆盖：** T-GRW-006-A03。**层级：** 真实 AI / 存储集成与评测。
**前置数据：** 已解锁用户，来源 D1 / D2；Q-002 质量表和生成契约已确认。
**操作：** 按批准时机触发报告生成，检查请求、结果和持久记录，再阅读报告。
**明确预期：** 有真实服务结果而非静态三段内容；报告关联正确来源版本，展示标题、来源数量和三类维度；内容相关性 / 依据通过确认质量表，不逐字比对 mock。

### CASE-GRW-006-003 请求失败与畸形返回

**覆盖：** T-GRW-006-A05、T-GRW-006-A03。**层级：** 契约 / 集成。
**前置数据：** 合法已解锁来源，分别注入超时、缺失维度、空正文和服务返回错误身份来源。
**操作：** 触发生成，观察并按契约重试到有效结果。
**明确预期：** 不显示报告完成或保存无效输出；失败可见且能恢复；有效重试才产生可读报告，错误身份来源被拒绝。

### CASE-GRW-006-004 乱序结果与持久恢复

**覆盖：** T-GRW-006-A05。**层级：** 契约 / 真实存储集成。
**前置数据：** 已批准版本更新契约，源版本 V1、V2 和两个请求；Q-001 留存范围已确认。
**操作：** 先返回 V2 报告，再返回 V1 和重复 V2，随后重启读取。
**明确预期：** 当前已确认 V2 不被 V1 覆盖；重复响应不创建重复已生效报告；重启可恢复批准留存的报告 / 来源版本，不退回静态示例。

### CASE-GRW-006-005 身份切换与私有来源

**覆盖：** T-GRW-006-A06、T-GRW-006-A01、T-GRW-006-A05。**层级：** 权限 / 契约集成。
**前置数据：** U1 报告及来源私有，U2 有不同状态；U1 请求延迟。
**操作：** U1 生成期间切 U2，旧 U1 结果返回；U2 直接请求 U1 报告 ID。
**明确预期：** U2 不看到 U1 正文、统计或来源；服务拒绝越权读；迟到结果仅按原归属处理，不误解锁 U2。
