### CASE-CRE-002-005 替换取消隔离暂存选择

### CASE-CRE-002-007 真实设备照片可读与失效

- 状态：未执行
- 数据/前置：实际相册 P1～P4；选择前后从设备删除一个资源或撤回许可；范围按 Q-018。
- 步骤：选择三张可读图片确认；另场景移除其中一张后确认。
