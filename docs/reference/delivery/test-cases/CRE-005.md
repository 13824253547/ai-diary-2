### CASE-CRE-005-001 生成前置与真实进度事件

- 覆盖任务验收：**T-CRE-005-A01**、**T-CRE-005-A06**
- 层级：确定性/服务替身
- 状态：未执行
- 数据/前置：G1 三张有效照片及 R1；两个独立场景：服务提供 10%、70%、乱序 30%、成功事件，或仅提供“分析照片→组织内容→迟到分析照片→成功”阶段事件。
- 步骤：启动生成并注入各场景事件，成功前及成功后查看状态。
- 明确预期：只一任务；成功前草稿/任务为 generating/running，事件来源可观察，百分比或阶段不因迟到事件倒退。两个场景都可通过，不要求阶段服务提供百分比；只在有效成功后显示完成。
