本轮补充：`openai-compatible` 输出缺失或非法的契约必需字段时不再用 PHOTO_FACTS / 默认文案补齐，而是按不可重试 `provider_failed` 拒绝；服务单测覆盖各字段与非法 `people` 容器，任务 e2e 验证缺标题快照失败。deterministic provider 的固定夹具路径不变。
