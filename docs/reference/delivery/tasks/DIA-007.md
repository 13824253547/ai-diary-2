## 任务内容

- 用真实已保存日记和统一归档规则生成月份分册，预览与导出读取相同成员及作品版本；不可把起始日期字符串截取固化为跨月规则。
- 以真实导出流水线替换本地 Alert：生成交付文件、写入约定位置、确认可打开，再显示完成。格式/封面/选段/隐私依 Q-011，不自行选择 PDF 或服务商。
- 实现导出进度、取消、失败清理和重试，固定导出快照；坏文件、文件写失败或交付取消不能记录成功。

## 任务验收

- **T-DIA-007-A01：**映射 **DIA-007-AC01**。月份分册与归档成员/数量一致；单日记录可先验收，跨月待 Q-004。
- **T-DIA-007-A02：**映射 **DIA-007-AC02**。分册仅列其成员，点击打开正确作品。
- **T-DIA-007-A03：**映射 **DIA-007-AC03**。无日记展示先记录的空态，无伪造合集。
- **T-DIA-007-A04：**映射 **DIA-007-AC04**。选定月份生成可打开且内容正确的交付物；具体格式、内容及隐私按 Q-011 补定。
- **T-DIA-007-A05：**【工程新增】导出失败/取消不标成功，不交付损坏或过期月份结果；重试使用明确的成员/作品版本。

## 必要待定规则

Q-011 阻塞真实导出格式、内容、封面、隐私/选段和留存；Q-004 阻塞跨月归档；Q-001 阻塞文件保存期限。原 DIA-007-AC05 为证据限制，不作为正式验收。 详见[问题清单](../../business-spec/open-questions.md)。

- 当前代码已具备真实月度分组链路，而非固定示例书册：
  - `src/store/diary-domain.ts` 的 `getHistoryGroups(...)` 已按真实已保存日记日期聚合月份分册，并导出月份标签与成员 `diaryIds`。
  - `app/profile/monthly.tsx` 会基于真实分组渲染月份书册、月度合集成员面板和空态；本轮又补了对 `2026-01 / 2026.01` 这类真实月份参数的识别，并为合集成员入口增加了“标题 + 日期”的可访问标签，避免同名日记串篇。
  - `app/(tabs)/profile.tsx` 本轮已去掉静态演示月份参数，改为从真实月度分组生成 `/profile/monthly?month=YYYY-MM` 入口，不再伪造固定 8/7/6/5 月示例。
- 本轮新增 `DIA-007` 专属证据：
  - `app/__tests__/monthly-screen.spec.tsx` 已验证：一月/二月分册会按真实保存日记生成，数量文案分别为 2/1 篇；指定月份参数只打开对应分册，成员列表不会混入其他月份；同名日记点击后会打开被点击的那一篇；无已保存日记时展示“先写下第一篇日记吧”，且不会出现伪造分册或导出按钮。
  - `app/__tests__/profile-screen.spec.tsx` 已验证：个人页月度装订入口改为使用真实月度分组参数，点击二月书册会跳到 `/profile/monthly?month=2026-02`；无已保存日记时不会伪造月度快捷入口。
  - `src/services/monthly-export.ts` / `src/store/create-app-store.ts` / `app/profile/monthly.tsx` 本轮已补齐 `A05` 的工程底座：导出会固定当前月份与成员版本快照，store 维护运行中 / 成功 / 失败 / 取消状态；切到其他月份重新导出时，会先中止旧任务并只保留当前月份结果；页面也已补上“取消本次导出”和失败 / 取消提示，不再把迟到结果误报为成功。
  - `src/store/__tests__/monthly-export.spec.ts` 已验证：导出器抛错时状态收口为 `failed` 且不改原日记集合；取消后状态保持 `cancelled`，迟到成功不会复活；1 月导出 A 切到 2 月导出 B 后，只会保留 B 的结果与快照，A 会按 `superseded` 被忽略。
  - `app/__tests__/monthly-screen.spec.tsx` 本轮也补了页面级反馈：当前月份导出失败时只弹“导出失败”，不会误弹成功；运行中会显示“取消本次导出”，取消后只弹“已取消”；切到其他月份时会显示“重新导出会覆盖这次任务”的明确提示。
