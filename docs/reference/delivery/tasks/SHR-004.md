# T-SHR-004 分享海报与全文预览

状态：**未开始**。业务依据：[隐私与分享 · SHR-004](../../business-spec/modules/sharing-and-privacy.md#shr-004-分享海报与预览)；原始验收：`SHR-004-AC01`, `SHR-004-AC02`。

## 实施范围

- 以真实目标 ID 读取已保存版本，使用 SHR-002/003 处理后的内容呈现海报：标题、允许照片或无图内容、摘要、日期/地点与匿名提示。
- 全文预览与海报读取同一内容投影；支持关闭预览回原分享页，不修改公开范围、选段或原文。加载、失效资产、渲染错误需可辨识，不显示其他日记作为兜底。
- 异步读取/渲染绑定目标和版本；加载目标变化后旧结果不得闪现或覆盖新的目标。预览关闭不当作分享完成。
- 二维码仅按已表达面板展示开关；只有 Q-014 明确纳入真实扫码后，才实现链接、读取权限、有效期和撤回，不将装饰矩阵当真链接。
