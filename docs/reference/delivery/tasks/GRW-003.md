# T-GRW-003 真实锚点提取与原日记关联

**状态：未开始。** 关联 [FSD GRW-003](../../business-spec/modules/growth-and-insights.md#grw-003-锚点阅读与原日记关联)，原验收 GRW-003-AC01～AC05；[同名案例](../test-cases/GRW-003.md)。

**依赖：** [BAS-001](BAS-001.md) 提取 / 版本 / 标签 / 默认集合契约、[BAS-002](BAS-002.md) 私有记忆数据隔离、[BAS-003](BAS-003.md) 锚点留存、[BAS-004](BAS-004.md) AI 与事件替身；[T-DIA-005](DIA-005.md) 的真实已保存作品及提交事件。纠正文案按 GRW-004 交付的读模型叠加；可先用无纠正数据实施，避免循环依赖。

## 任务内容

- 建立对真实已保存日记的锚点 / 标签提取流程，按 Q-016 决策触发，不从固定 diary ID 映射或简单首句截断充当最终提取。保存作品版本、锚点 ID、标签 ID、来源日记 / 段落与提取状态，能追溯依据。
- 保存 / 编辑事件按契约驱动提取或更新；处理中、失败、重试和旧版本回调必须可区分。原日记变更、不可访问或消失后按 Q-016 的规则同步，读页面不得展示不可访问来源。
- 按标签读取锚点卡片，显示真实日期、标题、封面、短摘；叠加用户纠正并保留原提取依据；卡片打开真实源日记。空集合、无效标签及默认分类按契约处理。
- 真实集成使用两篇正文不同的测试日记检验锚点来源与内容相关性；不逐字断言 AI 摘要，不用固定锚点数量替代质量评测。
