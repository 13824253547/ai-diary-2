## 任务内容

- 将发现页接入真实已发布快照，展示封面（存在时）、标题、作者和点赞摘要；推荐暂时隐藏，只开放最新/同城。
- 分类状态与搜索词组合提交到统一查询能力。「最新」按日期降序；「同城」只在用户主动进入时请求一次前台定位，并精确匹配规范化城市键；城市/日记地点未知时不补猜测结果。搜索字段覆盖标题、地点、作者，收起 / 展开保持输入状态。
- 公开日记快照只包括已选正文/引用及其关联照片；编辑保存刷新快照，切回私密立即撤下。启用前历史公开作品不回填。
- 分类、搜索、刷新请求乱序返回时，只显示当前条件对应的结果；网络失败保留可解释状态和重试入口，不能把失败误报为空结果。
- 卡片使用稳定故事 ID 导向 T-DSC-002；公开照片只有在源故事仍发布、来源版本仍有效、且 photoId 属于公开快照时才能读取。

## DEV-63 公开日记发现接线

- `GET /discovery/stories` 支持 `latest` 与需要城市参数的 `same-city`；发现页默认最新，只展示最新/同城，推荐入口隐藏。Expo Location 只在用户打开同城时申请前台权限并反查 `city`，不使用照片 GPS/EXIF、不传送坐标、不请求后台定位。
- `/sharing/project` 成功保存非私密范围后与日记编辑事务共同创建/刷新 `DiscoveryStory`；快照严格过滤到已选正文/引用和关联照片，来源日记版本可追溯。切回私密时同事务撤下并清除公开快照内容，图片接口同时停止读取。历史公开日记未批量回填。
- 匿名文本会移除已知姓名/别名并隐藏地点；当所选匿名内容含照片且目前没有可靠遮挡资产时，服务拒绝发布，范围保存回滚，避免原图外泄。
