# T-DSC-001 发现分类浏览与搜索

**状态：未开始。** 关联 [FSD DSC-001](../../business-spec/modules/discovery.md#dsc-001-发现分类浏览与搜索)，原验收 DSC-001-AC01～AC06；[同名案例](../test-cases/DSC-001.md)。

**依赖：** [BAS-001](BAS-001.md) 故事查询 / 搜索 / 排序契约、[BAS-002](BAS-002.md) 可见权限、[BAS-003](BAS-003.md) 内容缓存与留存、[BAS-004](BAS-004.md) 测试数据；[T-DSC-002](DSC-002.md) 详情入口的可用目标。Q-007 的发布 / 撤回规则影响内容源契约，不意味着本任务要制作发布界面。

## 任务内容

- 将固定发现数组替换为真实可见故事查询；在列表展示封面、标题、作者和点赞摘要，支持加载、空态、失败、刷新及适用的分页能力。服务侧应按访问身份过滤私密、撤回或不可读内容。
- 分类状态与搜索词组合提交到统一查询能力。「最新」保证日期降序；推荐排序、同城定位依据和分页稳定排序待 Q-007。搜索字段按 FSD 当前范围覆盖标题、地点、作者，收起 / 展开保持输入状态。
- 分类、搜索、刷新请求乱序返回时，只显示当前条件对应的结果；网络失败保留可解释状态和重试入口，不能把失败误报为空结果。
- 卡片使用稳定故事 ID 导向 T-DSC-002，列表在重开后从真实来源恢复。
