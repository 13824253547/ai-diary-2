# T-MAT-001 真实照片导入、搜索与预览

状态：**未开始**。业务依据：[素材与灵感 · MAT-001](../../business-spec/modules/material-library.md#mat-001-照片素材添加搜索与预览)；原始验收：`MAT-001-AC01`, `MAT-001-AC02`, `MAT-001-AC03`。

## 实施范围

- 将示例照片选择替换为真实设备照片导入；选定符合 Expo/iOS 环境的照片适配器，按系统许可读取用户选中照片。当前依赖不代表已有可用上传/导入实现。
- 建立素材资产仓库与共享解析接口：稳定资产 ID、可读取 URI/资源、媒体类型/尺寸、标题、时间/地点及来源；让素材、日记照片组件和明信片读取同一真实资产，而非只在 `mockPhotos` 查 ID。
- 同一已识别照片再次导入只复用已有素材；导入成功须真实可读且仓库提交成功。处理许可拒绝/撤回、用户取消、失效 URI、损坏图片、写入失败，不创建伪成功条目。
- 按标题/地点片段查询素材；预览对应资产并能关闭。使用状态以当前已保存日记引用为依据，未保存草稿不提前改成已用于日记；提交后刷新。批量上限与元数据缺省由 Q-003 确定。

## 依赖

[BAS-001](BAS-001.md)（照片身份/许可/元数据契约）、[BAS-003](BAS-003.md)（素材资产留存）、[BAS-004](BAS-004.md)（设备导入测试）、[CRE-001](CRE-001.md)（共享相册许可能力）。依赖用于完整验收，接口与纯规则可先使用明确的测试替身。共同约定见[执行上下文](../execution-context.md)。

## 决策与阻塞范围

- [Q-015](../../business-spec/open-questions.md)：阻塞跨次导入的身份等价规则（同系统 ID、复制文件、内容相同是否去重）、资产删除及已引用作品处理；先按稳定相同身份做去重，不臆造哈希规则。
- Q-003：阻塞格式/尺寸/数量上限与时间地点缺失预期；Q-018：共享 CRE-001 的全量/有限/拒绝/撤回许可决策适用于本任务设备导入。
- Q-001/Q-015：阻塞 URI 生命周期、重启与恢复边界；当前只加入 mock ID 不算真实导入完成。
