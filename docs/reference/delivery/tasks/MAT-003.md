# T-MAT-003 贴纸与城市印章预览和应用

状态：**进行中**。业务依据：[素材与灵感 · MAT-003](../../business-spec/modules/material-library.md#mat-003-贴纸与城市印章)；原始验收：`MAT-003-AC01`, `MAT-003-AC02`。

## 实施范围

- 为已表达贴纸/城市印章建立稳定装饰 ID 与可读取资源映射，预览显示所选资源与名称，不把所有装饰固定指向默认资源。
- 素材库首页城市印章区只展示已保存且 `ready` 日记地点匹配后解锁的印章，最多显示 3 枚；无匹配记录时展示“暂无城市印章”空态；按地区浏览仍进入完整目录。
- 日记纸张封面邮戳根据该篇日记地点查找可靠且唯一的目录城市；无匹配时不展示邮戳，不回退为固定装饰图。
- 将所选装饰 ID 明确传递至明信片，由 PCD-001 渲染在当前卡片与实际结果中。资源可能内置，本任务不要求后台装饰商城。
- 关闭预览返回素材列表，不更新日记、草稿或素材引用状态；无效装饰输入和读取错误不得错误宣称已应用，正式回退/提示规则见 Q-015。
- 范围仅预览和用于明信片，不自动加入自由拖拽/旋转、贴纸编辑或日记装饰功能。
- 全球城市印章目录只收各地官方认定的城市级行政单位或城市型市政单位；逐区审计按当前分区顺序执行。WUP 2025 Cities table F21、GeoNames populated-place、OSM place 标签及名称后缀只作为候选发现/交叉检查依据，不能单独证明行政类别。中国大陆继续采用民政部截至 2025-12-31 行政区划代码，只收 4 个直辖市和 293 个地级市，共 297 个市级单位；不含县级市、自治州、地区、盟、县、区、镇或街道。大陆拉丁字母名为官方中文名称的无声调汉语拼音转写，并保存行政级别、省份及代码。其他地区逐条保存类别、稳定 ID、名称来源、上级行政区及许可证据；无法核实项列入来源缺口，不得用 WUP 回填。香港与澳门保持单一区域单位，不展开行政分区。采用 OSM 派生数据时按 ODbL-1.0 发布并保留贡献者署名。
- 印章文本按 SVG 安全宽度动态缩放，超长名称按规则省略；上弧显示地区英文名与序号，下弧居中显示 `TRAVEL POST`。
- 中国 CN 地区显示名使用“中国大陆 / MAINLAND CHINA”，并排在“中国台湾”之前；港澳台分别使用“中国香港”“中国澳门”“中国台湾”。
- 城市可预览，只有已保存且 `ready` 的日记地点与城市名或经审核别名完整匹配后才解锁应用；同名城市需由地点中的地区信息唯一消歧。港澳台显示“中国香港 / HONG KONG · CHINA”“中国澳门 / MACAO · CHINA”“中国台湾 / TAIWAN · CHINA”。
- 保留 `stampKyoto`、`stampKamakura`、`stamp` 旧 ID 的解析兼容；锁定门禁不得阻止已有明信片读取旧装饰。
