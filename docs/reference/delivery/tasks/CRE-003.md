# T-CRE-003 日记类型

状态：未开始

## 关联 FSD 与原始 AC

[CRE-003 规格](../../business-spec/modules/diary-creation.md)：CRE-003-AC01、CRE-003-AC02、CRE-003-AC03。

## 依赖

- [BAS-001](BAS-001.md)
- [BAS-004](BAS-004.md)

依赖 BAS-001 中相关问题决策及契约；留存遵循 BAS-003、测试遵循 BAS-004。服务供应商选择不在本任务中预设。

## 任务内容

- 把展示选项与可创建类型能力分开；旅行类型选中后显式更新草稿类型，而非仅依赖默认 travel。
- 界面、深链、领域层及真实生成请求共同校验能力白名单；工作/情绪不可因绕过 disabled 创建任务。
- 保留已保存历史类型的读取能力，类型提交幂等且不创建多份草稿。

## 任务验收

- **T-CRE-003-A01：**映射 **CRE-003-AC01**。旅行游记可选择，当前草稿类型为 travel 并进入角色页。
- **T-CRE-003-A02：**映射 **CRE-003-AC02**。工作反思/情绪记录未开放且不可新建；绕过 UI 的选择也不能启动生成。
- **T-CRE-003-A03：**映射 **CRE-003-AC03**。历史情绪作品可阅读，新建能力仍关闭。
- **T-CRE-003-A04：**【工程新增】非法/重复类型请求不破坏草稿，真实服务按同一能力契约拒绝非法类型。

## 必要待定规则

未开放类型不进入实施范围；如需开放，先补模板结构、商业范围及新 AC，不预设发布日期。 详见[问题清单](../../business-spec/open-questions.md)。
