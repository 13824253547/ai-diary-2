# T-GRW-002 成长树与真实主题标签

**状态：未开始。** 关联 [FSD GRW-002](../../business-spec/modules/growth-and-insights.md#grw-002-成长树与标签)，原验收 GRW-002-AC01～AC04；[同名案例](../test-cases/GRW-002.md)。

**依赖：** [BAS-001](BAS-001.md) 标签 / 成长读模型契约、[BAS-002](BAS-002.md) 身份隔离、[BAS-003](BAS-003.md) 留存、[BAS-004](BAS-004.md) 测试；BAS-001 定义的共享统计契约（与 [T-GRW-001](GRW-001.md) 共用，可并行实现）、[T-GRW-003](GRW-003.md) 标签提取与锚点集合、[T-GRW-005](GRW-005.md) 成长状态。标签的生产归 GRW-003，本任务负责消费与导航。

## 任务内容

- 将素材元数据中的固定标签列表与固定进度文本替换为真实标签集合和成长读模型。保留当前四类主题的视觉表达作为已确认展示基线；是否固定词表及如何处理新主题由 Q-016 决定，不能用四类标签伪造所有用户记忆。
- 以稳定标签 ID 导向对应锚点集合，显示名称、记录 / 锚点概览；花朵与成长提示使用 GRW-005 真实状态。标签新增、纠正或失效后更新树，不承担锚点提取逻辑。
- 标签 / 统计 / 成长分区加载和失败可辨识，空集合不生成假标签。返回有栈回上一页，无栈回我的；慢请求不能在切换用户后写回旧树。
