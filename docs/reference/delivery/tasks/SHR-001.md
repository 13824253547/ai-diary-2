# T-SHR-001 公开范围设置的真实保存

状态：**部分实施（DEV-63 非私密发布/撤下与发现快照接线；匿名照片保护受原生能力限制）**。业务依据：[隐私与分享 · SHR-001](../../business-spec/modules/sharing-and-privacy.md#shr-001-公开范围设置)；验收见[对应案例](../test-cases/SHR-001.md)。

## 实施范围

- 从真实日记仓库读取目标作品的公开范围与已选段 ID。新作品提交时默认 `private`；非私密范围保存成功后，将已选正文/引用及关联照片同步至发现「最新」；转私密时撤下。当前 UI 只开放私密、匿名公开和公开仅点赞，评论选项暂时移除。
- 页面选择保存在页面暂存状态，只有“完成”才通过仓库提交目标日记设置。校验目标与可选段，非私密空选段按 SHR-002 原子拒绝；改回私密移除公开选段限制。
- 接入异步保存、进行中防重、持久化结果及失败反馈；公开范围、发现快照及撤回在同一数据库事务中提交。失败不能将未提交选择作为已保存状态。返回目标按已确认入口约定处理。
- 目标不存在或保存前已失效时提供可返回空态，不引用当前日记或其他作品替代；保留日记原文、照片及 D2。
- 匿名文本替换已知姓名/别名并隐藏地点；含照片而无法安全遮挡时服务端拒绝发布，不向发现返回原图。

## DEV-63 公开范围与发现快照同步

- `updateDiaryVisibility(...)` 在锁定日记行的事务内更新 `privacy/publicBlockIds` 并创建、刷新或撤下来源日记对应的 `DiscoveryStory`；日记编辑保存事务也同步当前公开版本。公开快照仅投影选中正文/引用及相关照片，不批量回填旧公开日记。
- 发现读模型只开放 `latest` 与 `same-city`；后者由设备前台定位城市匹配日记保存地点。匿名文本脱敏、地点隐藏；含照片时当前遮挡模块无法生成安全副本，服务返回 `publication_blocked`，且事务回滚。
- 2026-10-27 用户确认暂时移除分享设置中的“公开 · 可评论”；当前页面仅提供私密、匿名公开、公开仅点赞。旧 `public-comments` 值映射为 `public-likes`，服务端/数据类型暂保留旧枚举以兼容历史值，不开放评论接口。
- 隔离 E2E 验证公开/选段/撤下和匿名图片失败关闭；iPhone 17 包已重建并确认定位用途键，模拟器定位授权/拒绝及公开非空故事仍待设备交互验收。
