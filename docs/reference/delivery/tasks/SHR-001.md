# T-SHR-001 公开范围设置的真实保存

状态：**未开始**。业务依据：[隐私与分享 · SHR-001](../../business-spec/modules/sharing-and-privacy.md#shr-001-公开范围设置)；原始验收：`SHR-001-AC01`, `SHR-001-AC02`, `SHR-001-AC03`。

## 实施范围

- 从真实日记仓库读取目标作品的公开范围与已选段 ID。新作品提交时默认 `private`；四个值仍为私密、匿名公开、公开仅点赞、公开可评论，权限意图不自动扩展为评论发布或发现分发。
- 页面选择保存在页面暂存状态，只有“完成”才通过仓库提交目标日记设置。校验目标与可选段，非私密空选段按 SHR-002 原子拒绝；改回私密移除公开选段限制。
- 接入异步保存、进行中防重、持久化结果及失败反馈；只有确认保存成功才完成返回。失败不能将未提交选择作为已保存状态。返回目标按已确认入口约定处理。
- 目标不存在或保存前已失效时提供可返回空态，不引用当前日记或其他作品替代；保留日记原文、照片及 D2。

## 决策与阻塞范围

- [Q-001](../../business-spec/open-questions.md)：阻塞重启恢复、保留期限的最终验收，不阻塞四种范围与暂存/提交逻辑。
- Q-007：阻塞范围对应的社区权限、匿名身份或自动发布规则；本任务只保存表达出的范围值。
- Q-009：阻塞不同入口的最终返回路径；Q-013：阻塞公开后改动/撤回的下游处理，本任务不承诺已导出文件可撤回。
