## 任务内容

- 编辑会话读取仓库快照并创建隔离草稿；标题/正文/引用修改更新指定块及派生摘要，不直接写已保存对象。
- 用 CRE-005 的真实 AI 服务边界替换 rewriteDraftBlock 固定文案；请求携带选中块、角色、目标照片图像和整篇其它正文/引用块的只读文字上下文，作用域限制在目标正文/引用块。
- 重写绑定 draftId、blockId、内容版本与请求 ID；失败保留原文，取消/过期回调不能覆盖新输入。Provider 单次请求最多等待 4 分钟，从后端实际提交模型请求后计时；排队和模型请求前的照片准备不计入，每次新的 Provider 提交重新计时。候选采用方式及用户输入冲突由 Q-002/Q-008 确认。
- 保存和放弃统一调用 DIA-005；输入长度按 Q-003，入口由 NAV-001 衔接。

## 任务验收

- **T-DIA-002-A01：**映射 **DIA-002-AC01**。标题修改只改变草稿；提交前已保存版本保持原值。
- **T-DIA-002-A02：**映射 **DIA-002-AC02**。编辑正文/引用只改变目标块，其他块不被直接改写。
- **T-DIA-002-A03：**映射 **DIA-002-AC03**。选中正文/引用重写后得到可继续编辑的替换文本；其它内容仅作为只读语境，只有目标块文字改变，目标块 `photoIds` 与其它块保持不变。
- **T-DIA-002-A04：**映射 **DIA-002-AC04**。无可重写块或目标不存在不产生变更并呈现相应无效/空态。
- **T-DIA-002-A05：**映射 **DIA-002-AC05**。编辑保存/放弃结果遵循 DIA-005；质量按 Q-002，不验收固定示例正文。
- **T-DIA-002-A06：**【工程新增】重写失败/取消保留原文，旧版本结果不覆盖新输入，重复触发按请求契约去重；超出日记范围的请求在模型调用前拒绝，越界模型结果不写回；同设备有全文生成或重写任务活动时拒绝新的不同任务。每次 Provider 请求从后端实际提交模型时起最多等待 4 分钟，排队及请求前照片准备不计时；新的自动重试/显式重试 Provider 提交按既有 turn/task 契约开启独立计时。

当前已形成真实代码与自动化证据的是 A01、A02、A03、A04、A05、A06；剩余未完成部分主要受 Q-002 / Q-003 / Q-008 约束，集中在真实重写质量、文本边界和候选覆盖策略，不再是页面级失败反馈缺口。

## DEV-19 排版重写范围与并发边界（2026-10-20）

- `MemoryStoreService.rewriteDraftBlock(...)` 在读取目标图片和调用 provider 前检查目标原文及只读上下文；显式代码/脚本、小说/剧本、商业推广、提示覆盖和已知危险操作请求按 `invalid_input` 拒绝，原段落不变。
- 共享 `MemoryStoreService` 设备任务锁覆盖全文生成和单段重写；同一设备已有任一任务活动时，新的不同任务返回 `version_conflict`。同幂等生成请求仍返回原任务，不会重复调用 provider。
- `DiaryGenerationService` 对全文/单段 provider 输出再次执行规则检查，越界文本不进入生成成功快照，也不写回编辑草稿；编辑页在现有 Alert 中区分范围拦截与设备忙，不增添页面入口或改变布局。
- `memory-store.generation-task-lock.spec.ts` 与 provider policy/service suites 已验证重写输入前置拒绝、模型输出拒绝、全文任务期间重写冲突，以及任务结束后锁释放。真实 Ark 输出红队、MySQL E2E 和多实例锁未验证；确定性规则无法覆盖全部混淆表达，CASE-DIA-002-011 保持部分执行。

## DEV-27 Provider 单次请求时限（2026-10-22）

- 后端 rewrite Provider 默认等待上限为 `240000` ms；允许环境变量设置更短时限，超过 4 分钟的值封顶。计时在图片/请求体准备完成并实际提交模型请求前启动，每次新的 Provider 提交独立计时。
- 客户端重写请求外层传输保护为 `360000` ms，避免 120 秒旧上限提前终止模型等待，并留出上传/服务处理余量。
- 验证：生成/重写 Provider 时限 4 项、聊天 Provider 时限 2 项、客户端回归 2 suites / 116 tests、root typecheck、backend build 与 `git diff --check` 通过；包含 300 秒配置封顶断言。真实模型四分钟等待、真实上传慢速场景和隔离 MySQL e2e 未验证；CASE-DIA-002-006 既有状态不变。
