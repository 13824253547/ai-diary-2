## 任务范围

- 从日记详情的既有“更多操作”菜单提供单篇删除入口，并在调用前使用系统确认弹窗说明删除及保留范围。
- 由当前设备身份调用 `DELETE /diaries/{diaryId}`。服务端在事务内校验并锁定该设备的日记，再清理目标日记及关联的公开内容、记忆、编辑草稿和派生记录。
- 删除目标日记的独立照片副本及文件；不删除素材库原图、系统相册原图、其他日记或其他设备的数据。
- 清除引用已删除日记的洞察报告与成长识别摘要；已授予的成长里程碑保留，但移除被删除日记的来源 ID。
- 服务端失败时保留客户端日记状态；服务端确认成功后，客户端移除日记、关联编辑草稿和缓存照片副本，并返回回忆列表。

## 验收条件

- **T-DIA-008-A01：**详情操作菜单提供单篇删除；取消确认不会调用删除接口或改变任何本地/远端状态。
- **T-DIA-008-A02：**确认后仅删除目标日记，回忆列表及详情入口不再展示该篇；其它日记保留。
- **T-DIA-008-A03：**删除按设备身份隔离；缺少身份或目标不属于当前设备时，服务端拒绝且不触碰关联数据。
- **T-DIA-008-A04：**删除后公开快照、点赞、锚点、纠正、日记照片副本及引用来源的 AI 派生内容不可再读取。
- **T-DIA-008-A05：**素材库原图、系统相册原图、其它日记及已授予的成长里程碑不受影响；里程碑不再保留该日记的来源引用。
- **T-DIA-008-A06：**事务/HTTP失败时客户端不提前移除日记；成功后清理客户端的目标日记、编辑草稿及专属照片副本。
- **T-DIA-008-A07：**在途成长识别或报告提交必须复核来源版本；已删除的日记不能在迟到回调中重新生成锚点、报告或成长来源记录。

## 实现边界

- 单篇永久删除，不提供批量删除、整设备/账号删除或恢复站。
- 删除发现快照会使发现页公开内容及其点赞一并移除；外部已保存的分享文件不受应用控制。
- 数据库事务提交后再清理独立照片副本文件。其他功能的整体留存、备份清理期限和完整设备身份删除仍属于 Q-001，不由本任务扩展。
- 新增删除源接口，不增加数据库 schema migration。生产以只读模块挂载发布删除逻辑；部署验证未对生产日记执行删除。
