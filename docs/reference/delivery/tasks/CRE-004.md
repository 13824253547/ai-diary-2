# T-CRE-004 排版师选择

状态：进行中

## 关联 FSD 与原始 AC

[CRE-004 规格](../../business-spec/modules/diary-creation.md)：CRE-004-AC01、CRE-004-AC02、CRE-004-AC03、CRE-004-AC04。

## 依赖

- [BAS-001](BAS-001.md)
- [BAS-004](BAS-004.md)
- [CRE-003](CRE-003.md)

依赖 BAS-001 中相关问题决策及契约；留存遵循 BAS-003、测试遵循 BAS-004。服务供应商选择不在本任务中预设。

## 任务内容

- 从角色能力契约读取当前三种开放风格，替代以本地数组截取决定正式能力；校验角色有效性及版本。
- 选择更新指定草稿，生成输入读取同一角色；浏览模式经授权和类型页保留选择，上下文恢复交 NAV-001/Q-009。
- 角色目录失败或失效时保留已有选择；重复点击和导航回调只能推进同一草稿一次。

  - 角色页和首页排版师入口都已改为读取显式角色能力白名单，不再用 `slice(0, 3)` 假定开放角色；当前只展示 `character-blue / character-green / character-brown` 三种开放风格。
  - 角色页已补异步目录加载、失败态提示与“重新加载”恢复路径；目录首次失败时会明确展示“排版师目录暂时不可用”，重试成功后恢复角色列表，不会改动既有 UI 卡片参数。
  - 选择角色会更新当前草稿，并且草稿后续每次关键变更都会重新同步到远端；生成任务启动前，后端读取到的是最新角色而不是默认角色。
  - 浏览模式下先选角色、再授权、再选照片和模板时，当前草稿会保留同一个角色，不会在后续步骤被重置。
  - 无效角色和已下线角色不会覆盖当前角色；真实后端也会拒绝把隐藏角色作为新建草稿角色写入，但带 `sourceDiaryId` 的历史隐藏角色草稿仍可保留原角色。
  - 角色页重复点击同一角色不会创建多份草稿，也不会重复推进导航；目录失败后重试恢复时也仍沿用同一页面选择路径。
- 当前未完成：
  - 浏览模式在授权、选图、模板之后是否需要再次回到角色页确认，仍受 Q-009 约束；当前只能确认角色选择不会丢失，不能把页面顺序写死为正式规则。

## 任务验收

- **T-CRE-004-A01：**映射 **CRE-004-AC01**。展示当前开放的三种角色及对应风格说明。
- **T-CRE-004-A02：**映射 **CRE-004-AC02**。选择写入草稿，后续生成请求使用该角色。
