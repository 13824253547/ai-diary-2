## 任务内容

- 从角色能力契约读取当前三种开放风格，替代以本地数组截取决定正式能力；校验角色有效性及版本。
- 选择更新指定草稿，生成输入读取同一角色；浏览模式经授权和类型页保留选择，上下文恢复交 NAV-001/Q-009。
- 角色目录失败或失效时保留已有选择；重复点击和导航回调只能推进同一草稿一次。

## 任务验收

- **T-CRE-004-A01：**映射 **CRE-004-AC01**。展示当前开放的三种角色及对应风格说明。
- **T-CRE-004-A02：**映射 **CRE-004-AC02**。选择写入草稿，后续生成请求使用该角色。
- **T-CRE-004-A03：**映射 **CRE-004-AC03**。浏览选择经首次授权后有效草稿仍保留角色。
- **T-CRE-004-A04：**映射 **CRE-004-AC04**。无效角色 ID 不覆盖当前角色。
- **T-CRE-004-A05：**【工程新增】目录加载失败和重复点击不创建多份草稿或多次生成，错误可重试。

## 必要待定规则

Q-009 阻塞浏览后是否重复确认角色；Q-002 仅阻塞文风质量；Q-008 阻塞更换角色是否需重生成。 详见[问题清单](../../business-spec/open-questions.md)。
