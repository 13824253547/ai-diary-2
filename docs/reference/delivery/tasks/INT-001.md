# T-INT-001 真实业务端到端交付

状态：未开始。依赖：相关功能任务、[BAS-001](BAS-001.md)、[BAS-002](BAS-002.md)、[BAS-003](BAS-003.md)、[BAS-004](BAS-004.md)、[NAV-001](NAV-001.md)。关联用户流程：[J-01～J-06](../../business-spec/user-journeys.md)。

## 任务内容

1. 在隔离真实环境中串通核心流程：照片授权/选图→生成→命名/编辑→保存→回忆；再覆盖编辑、隐私投影、分享/导出、素材、明信片、陪伴、发现和成长。
2. 验证同一真实数据在各页面和服务之间保持 ID、照片引用、公开范围、匿名像素、统计和锚点关系；不存在只在 mock 页面内成立的状态。
3. 对每个真实出口保存实际证据：可打开图片/PDF、服务请求/响应、平台交付准备或回调、重启恢复数据、用户归属检查。外部平台不能证明的“他人已收到”单列限制。
4. 执行失败、取消、离线、权限变化、重复点击、应用杀进程后恢复和版本升级；复测共享规则和安全边界。
5. 将问题、缺陷和未决 Q 回链到任务/AC/CASE；未满足任何一条核心流程验收时不标记整体完成。

## 验收条件

- **T-INT-001-A01**：J-01/J-02 从真实照片资产完成保存、回忆检索、编辑/放弃和重启恢复，数据与任务验收一致。（CRE/DIA、BAS-003）
- **T-INT-001-A02**：J-03 的私密拦截、选段/匿名投影、可打开导出物和已确认渠道交付分别有证据；演示提示不计真实成功。（SHR、Q-013/014）
- **T-INT-001-A03**：J-04 的真实素材、配图和明信片资产可被目标流程读取、保存、再次打开，失败不误报完成。（MAT/PCD、Q-002/015）
- **T-INT-001-A04**：J-05 的聊天、统计、锚点、花朵和报告使用真实留存数据；未确认的统计/成长/提取规则不被伪造通过。（PET/GRW、Q-005/006/016）
- **T-INT-001-A05**：J-06 的社区查询、详情和点赞在列表/详情/重启后保持一致，并执行已确认的发布与权限边界。（DSC、Q-007）
- **T-INT-001-A06**：所有核心流程记录版本、环境、CASE、结果和实际证据；失败/阻塞/待决策项可追溯，没有仅以 mock 或成功 toast 标记通过。（BAS-004；新增实施验收）
