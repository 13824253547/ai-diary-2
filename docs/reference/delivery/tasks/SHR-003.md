# T-SHR-003 匿名文本与人脸区域处理

状态：**进行中**。业务依据：[隐私与分享 · SHR-003](../../business-spec/modules/sharing-and-privacy.md#shr-003-匿名公开)；原始验收：`SHR-003-AC01`, `SHR-003-AC02`, `SHR-003-AC03`。

## 实施范围

- 使用当前作品已知人物姓名、曾用名和称呼完成匿名文本投影：标题、副标题、正文、小标题、摘要、地点、图片说明均参与替换；对外移除人物名单，个人原文不变。
- 读取照片真实尺寸及已标记人脸区域，确定坐标/缩放/裁切契约；海报和全文不同尺寸都能对齐遮挡。避免仅以屏幕绝对坐标计算。
- 为真实输出生成已遮挡的图片像素或统一匿名渲染资产；不得把未遮挡原图交给导出/分享，仅在 UI 上画遮罩。匿名衍生资产与原始照片区分管理。
- 与 SHR-002 同一投影管线组合选段和匿名处理；缓存/资产标识包含匿名设置与内容版本，防止误用原图或其他作品结果。未知人脸处理不默认为已有检测能力。
