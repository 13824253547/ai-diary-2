# T-GRW-001 个人空间与真实统计

**状态：未开始。** 关联 [FSD GRW-001](../../business-spec/modules/growth-and-insights.md#grw-001-个人空间与统计)，原验收 GRW-001-AC01～AC04；[同名案例](../test-cases/GRW-001.md)。

**依赖：** [BAS-001](BAS-001.md) 资料 / 统计契约与 Q-005 决策、[BAS-002](BAS-002.md) 身份隔离、[BAS-003](BAS-003.md) 留存、[BAS-004](BAS-004.md) 测试；[T-DIA-005](DIA-005.md) 已保存记录来源、[T-DIA-006](DIA-006.md) 回忆、[T-DIA-007](DIA-007.md) 月度合集、[T-GRW-002](GRW-002.md) 成长入口目标。统计契约可先实现，不等待各个目标页面完成。

## 任务内容

- 从当前身份资料与真实作品仓库加载头像、昵称、简介及已定义的身份展示；不能给所有用户固定 VIP 标识。账号编辑、购买、通知 / 设置产品按 Q-012 的明确范围另行补规格，不擅自加入。
- 建立共享统计查询 / 订阅能力，替换示例基线和会话增量；依据 Q-005 定义已保存 / 草稿、照片去重、记录天数及同行人身份口径。新增、编辑及已存在的数据删除事件按该规则更新，不能因页面不同重复计数。
- 我的、萌宠、成长入口使用相同数据语义与版本；加载 / 失败 / 空态可辨认。月份封面和路由参数使用真实合集 ID / 年月，不用固定四本书或字符串包含定位。
- 重开、身份切换和数据刷新不复用其他用户的资料 / 统计；真实统计通过可审计的记录集合验证。

| T-GRW-001-A04 | GRW-001-AC04 | 我的、萌宠和成长入口使用同一统计口径，对相同记录版本展示相同日记数。 |
