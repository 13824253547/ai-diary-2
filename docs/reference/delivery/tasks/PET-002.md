# T-PET-002 陪伴记忆概览与锚点入口

**状态：未开始。** 关联 [FSD PET-002](../../business-spec/modules/companion.md#pet-002-陪伴记忆概览与锚点入口)，原验收 PET-002-AC01～AC03；[同名案例](../test-cases/PET-002.md)。

**依赖：** [BAS-001](BAS-001.md) 统计与锚点读取契约、[BAS-002](BAS-002.md) 数据隔离、[BAS-003](BAS-003.md) 留存、[BAS-004](BAS-004.md) 测试环境；[T-GRW-001](GRW-001.md) 共用真实统计口径，[T-GRW-003](GRW-003.md) 锚点阅读目标。只需相关契约和数据准备，无需等 GRW-004 纠正完成才实现入口。

## 任务内容

- 用用户可访问的真实日记与锚点查询结果替换示例基线及固定锚点数；加载、空数据、失败和数据变更后的刷新状态均明确展示。
- 萌宠页与个人空间、成长树订阅同一统计语义；日记新增 / 编辑以及锚点新增或失效后避免旧缓存长期显示。统计计算和身份范围遵守 Q-005、BAS 契约。
- 保持小橘形象和锚点入口，入口导航到用户有权读取的锚点集合；无锚点可达 GRW-003 空态，不用伪造卡片。

## 任务验收

| ID | 来源 | 可验收结果 |
| --- | --- | --- |
| T-PET-002-A01 | PET-002-AC01 | 显示小橘、日记数和锚点数两个维度，数值由当前身份真实数据给出，空数据不套样例数字。 |
| T-PET-002-A02 | PET-002-AC02 | 点击锚点入口进入 GRW-003 的默认集合；空集合显示真实空态。 |
| T-PET-002-A03 | PET-002-AC03 | 同一数据状态下萌宠、我的、成长入口日记数一致。 |
| T-PET-002-A04 | 新增工程 AC | 数据变更、读取失败及重开页面时统计不混用过期值或其他身份的值，并有可恢复反馈。 |

**局部阻塞：** Q-005 决定正式统计范围与去重算法，阻塞 A01、A03 的最终数值预期；Q-016 决定锚点生成与默认分类，阻塞 A02 的默认集合定义；Q-001 决定统计缓存与重启恢复，阻塞 A04 的留存边界。入口导航、数据隔离和空 / 错态可先实施。
