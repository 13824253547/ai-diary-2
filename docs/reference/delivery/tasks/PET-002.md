- 用用户可访问的真实日记与锚点查询结果替换示例基线及固定锚点数；加载、空数据、失败和数据变更后的刷新状态均明确展示。
- 萌宠页与个人空间、成长树订阅同一统计语义；日记新增 / 编辑以及锚点新增或失效后避免旧缓存长期显示。统计计算和身份范围遵守 Q-005、BAS 契约。
- 保持小橘形象和锚点入口，入口导航到用户有权读取的锚点集合；无锚点可达 GRW-003 空态，不用伪造卡片。

## DEV-3 独立范围复核

- 萌宠页仍使用 `getDiaryStatistics(...)` 的固定 `SAMPLE_BASELINE`，锚点数仍为固定 12；`app/profile/anchors.tsx` 的默认集合与成员仍来自静态 ID。现有锚点入口已可到达该页面，页面也有空集合组件，但目前空态判断针对静态列表，不证明真实读模型空态。

- 因此本轮登记为无独立可开发缺口并跳过代码接线，待 Q-005/Q-016 和统计读模型明确后恢复；Q-001 的重启缓存边界也不作推断。未改页面/样式/路由，未运行 CASE。
