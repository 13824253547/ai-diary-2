# T-MAT-002 素材照片替换首段引用并加入编辑草稿

状态：**进行中**。业务依据：[素材与灵感 · MAT-002](../../business-spec/modules/material-library.md#mat-002-将照片用于已有日记)；原始验收：`MAT-002-AC01`, `MAT-002-AC02`, `MAT-002-AC03`, `MAT-002-AC04`。

## 实施范围

- 素材预览选择目标日记后创建或复用该作品编辑草稿，将当前草稿第一段正文的引用替换为素材照片，同时把素材照片加入整篇照片集合，随后进入正确草稿编辑页。被替换的照片仍留在整篇集合中。
- 修复 `applyPhoto` 在 `beginEdit` 后仍从已保存日记读取首段及引用的覆盖问题：首段/照片引用/标题/文字等均以当前草稿为准；按 DEV-14 用户确认，素材照片替换首段引用并加入整篇集合，不恢复已删除的草稿内容或覆盖未保存修改。
- 每个正文/引用文本块最多关联一张照片；素材应用替换首段引用而非追加。复用日记编辑的引用一致性、保存/放弃能力；提交沿用原日记 ID，放弃对原作品无影响，既有独立图片关联遵循 DIA-003。
- 入口至提交之间校验素材可读取、目标仍存在且当前草稿含正文；目标失效、无正文、草稿载入失败不污染原作品或其他草稿，具体反馈/返回在相关决策后补齐。
