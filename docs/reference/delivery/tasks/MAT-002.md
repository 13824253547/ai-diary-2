# T-MAT-002 素材照片追加到编辑草稿

状态：**未开始**。业务依据：[素材与灵感 · MAT-002](../../business-spec/modules/material-library.md#mat-002-将照片用于已有日记)；原始验收：`MAT-002-AC01`, `MAT-002-AC02`, `MAT-002-AC03`, `MAT-002-AC04`。

## 实施范围

- 素材预览选择目标日记后创建或复用该作品编辑草稿，在当前草稿第一段正文追加照片，同时加入整篇照片集合，随后进入正确草稿编辑页。
- 修复当前 `applyPhoto` 在 `beginEdit` 后仍从已保存日记读取首段及引用的覆盖问题：首段/照片引用/标题/文字等均以当前草稿为准，追加去重，不恢复已删除的旧引用或覆盖未保存修改。
- 复用日记编辑的引用一致性、保存/放弃能力；提交沿用原日记 ID，放弃对原作品无影响，既有独立图片关联遵循 DIA-003。
- 入口至提交之间校验素材可读取、目标仍存在且当前草稿含正文；目标失效、无正文、草稿载入失败不污染原作品或其他草稿，具体反馈/返回在相关决策后补齐。

## 依赖

[BAS-001](BAS-001.md)（追加/失效目标契约）、[BAS-003](BAS-003.md)、[BAS-004](BAS-004.md)、[MAT-001](MAT-001.md)（真实资产）、[DIA-003](DIA-003.md)（引用一致性）、[DIA-005](DIA-005.md)（草稿保存/放弃）。依赖用于完整验收，接口与纯规则可先使用明确的测试替身。共同约定见[执行上下文](../execution-context.md)。

## 决策与阻塞范围

- [Q-015](../../business-spec/open-questions.md)：原型差异为未保存引用被覆盖；本任务将保留草稿修改作为待确认业务目标单列验收，确认后执行 A04 案例。是否可选任意目标段落不包含在当前首段追加范围。
- Q-009：阻塞素材到编辑的最终导航/返回路径；Q-015：阻塞无日记、无正文与目标失效的具体反馈，基础数据不损坏仍可验证。
- Q-001：重启恢复与草稿留存由 BAS-003 处理，不在本任务自行扩展。
