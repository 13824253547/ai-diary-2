# T-MAT-002 素材照片追加到编辑草稿

状态：**进行中**。业务依据：[素材与灵感 · MAT-002](../../business-spec/modules/material-library.md#mat-002-将照片用于已有日记)；原始验收：`MAT-002-AC01`, `MAT-002-AC02`, `MAT-002-AC03`, `MAT-002-AC04`。

## 实施范围

- 素材预览选择目标日记后创建或复用该作品编辑草稿，在当前草稿第一段正文追加照片，同时加入整篇照片集合，随后进入正确草稿编辑页。
- 修复当前 `applyPhoto` 在 `beginEdit` 后仍从已保存日记读取首段及引用的覆盖问题：首段/照片引用/标题/文字等均以当前草稿为准，追加去重，不恢复已删除的旧引用或覆盖未保存修改。
- 复用日记编辑的引用一致性、保存/放弃能力；提交沿用原日记 ID，放弃对原作品无影响，既有独立图片关联遵循 DIA-003。
- 入口至提交之间校验素材可读取、目标仍存在且当前草稿含正文；目标失效、无正文、草稿载入失败不污染原作品或其他草稿，具体反馈/返回在相关决策后补齐。
