# T-BAS-003 业务数据与照片资产持久化

状态：未开始。依赖：[BAS-001](BAS-001.md) 的 Q-001/015 与存储契约；远程模式另依赖 [BAS-002](BAS-002.md)。关联：BR-01/02/05/11、Q-001；[实施约定](../execution-context.md)。

## 任务内容

1. 建立持久化仓库，保存已提交日记、公开设置、素材照片、聊天、点赞、锚点纠正和成长结果；未提交草稿按确认的恢复策略保存。
2. 将照片从数字资源编号扩展为真实可读取的资产引用，保存稳定 ID、URI/远程引用、时间地点及人物标记；导入和配图不能只依赖临时缓存。
3. 启动加载与 Zustand 初始化协调；未加载完成不把空列表写回覆盖历史。生产空账户从真实空数据开始，mock 仅用于显式演示或测试。
4. 日记保存、草稿完成标记及关联对象按契约原子提交；写失败保留可恢复草稿，不显示保存成功。
5. 处理 schema 版本迁移、损坏记录和媒体失效；不静默清空用户数据。按确认方案落实本地/远程同步、冲突和留存。

## 验收条件

- **T-BAS-003-A01**：数据按已确认 Q-001 跨应用重启恢复，所有需留存对象值一致；未提交草稿恢复或清除符合规则。（新增实施验收）
- **T-BAS-003-A02**：Q-001/015 确认需留存的导入/生成资产，在规定生命周期内移除临时来源或重启后仍能读取；失效资产有明确缺失处理，不替换成无关 mock 图。（BR-05；新增实施验收）
- **T-BAS-003-A03**：加载未完成或失败不会写空数据覆盖已有数据；新生产身份不会自动拥有样例日记/聊天/成长结果。（新增实施验收）
- **T-BAS-003-A04**：提交写失败或中断不会产生半篇日记、重复作品或误标已保存；重试按幂等规则完成。（BR-01/02；新增实施验收）
- **T-BAS-003-A05**：支持已存在版本迁移；损坏/不支持记录可报告和恢复，不丢失其他有效对象。（新增实施验收）
- **T-BAS-003-A06**：保存/恢复后的引用、公开范围与数据归属仍符合契约；远程冲突执行确认策略，不无声覆盖。（BR-05～09/11；新增实施验收）

## 待定规则

Q-001 决定留存、重启恢复、跨设备范围；Q-015 决定素材/衍生作品留存。跨设备、删除和历史明信片不因本任务自动纳入产品范围。
