# T-BAS-002 真实服务接入与数据访问边界

状态：未开始。依赖：[BAS-001](BAS-001.md) 的相关契约与身份方案。关联：Q-002、Q-007、Q-012；[实施约定](../execution-context.md)。

## 任务内容

1. 按已确定契约建立客户端服务适配层及需要的受控后端能力，承接 AI、发现社区和远程数据操作；由各业务任务实现具体服务行为。
2. 区分生产服务和测试替身；生产服务失败时返回可处理错误，不自动改用固定 mock 成功结果。
3. 在受控服务保存供应商凭据；客户端配置只含可公开配置和访问凭证。记录请求标识、错误与取消状态，日志中避免记录完整私密正文和照片内容。
4. 落实已确定的访问身份与数据归属：读取/修改日记、草稿、聊天、锚点等检查归属；对外只提供已允许公开的投影。
5. 实现契约规定的请求超时、取消、幂等和版本冲突处理，并提供测试替换入口。

## 验收条件

- **T-BAS-002-A01**：生产配置向真实服务发送符合契约的请求；成功、失败与畸形响应可区分，失败不回退为 mock 成功。（新增实施验收）
- **T-BAS-002-A02**：供应商秘密不出现在客户端源码配置、打包资源、请求返回和客户端日志中。（新增实施验收）
- **T-BAS-002-A03**：一个访问身份无法通过替换目标 ID 读取或修改另一身份的私密对象；对外接口只返回允许投影。（BR-06～09；新增实施验收）
- **T-BAS-002-A04**：取消和过期响应不能更新当前任务；重复提交及版本冲突按契约处理，不产生重复副作用。（BR-02/03；新增实施验收）
- **T-BAS-002-A05**：同一能力能使用可控测试适配验证失败/乱序，又能以真实环境执行集成验收；两类执行证据明确区分。（新增实施验收）
