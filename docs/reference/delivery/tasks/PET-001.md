# T-PET-001 小橘聊天真实会话

**状态：未开始。** 关联 [FSD PET-001](../../business-spec/modules/companion.md#pet-001-小橘聊天)，原验收 PET-001-AC01～AC04；[同名案例](../test-cases/PET-001.md)。

**依赖：** [BAS-001](BAS-001.md) 的会话、请求标识、错误与取消契约；[BAS-002](BAS-002.md) 的访问身份与隔离；[BAS-003](BAS-003.md) 的聊天留存；[BAS-004](BAS-004.md) 的确定性替身与集成环境。与 GRW-003 的锚点上下文是 Q-002 决策后的条件依赖，不阻塞基础会话链路。

## 任务内容

- 将关键词即时回复替换为真实陪伴生成能力和会话仓库。发送用户消息、请求回复、保存会话与重开加载均读取同一用户的真实记录；欢迎语可以是产品引导，不能代替已发送消息。
- 定义消息 ID、角色、顺序、请求状态与请求标识在 UI 和服务之间的映射。发送中、失败及重试在页面给出可观察状态；重复点击、响应丢失和乱序回复不得生成重复消息或把旧回复接在错误会话之后。
- 保留空白拦截、去空白、角色气泡、滚动定位及可用平台的键盘行为。输入长度和 AI 质量、时限、安全边界从 Q-002、Q-003 落地，不沿用 mock 关键词为产品规则。
- 对本机退出 / 重开及身份切换验证会话归属和留存；真实集成以隔离账号和真实服务响应为证据。

## 任务验收

| ID | 来源 | 可验收结果 |
| --- | --- | --- |
| T-PET-001-A01 | PET-001-AC01 | 空或纯空白输入不能发出请求，也不新增消息。 |
| T-PET-001-A02 | PET-001-AC02 | 有效输入经去空白后形成一条用户消息，真实服务响应形成一条对应的小橘消息，输入清空。 |
| T-PET-001-A03 | PET-001-AC03 | 两种角色可辨识；收到新消息后定位最新消息；历史会话重开后顺序一致。 |
| T-PET-001-A04 | PET-001-AC04 | 支持相应事件的键盘环境中 Enter 发送、Shift+Enter 换行且不提交。 |
| T-PET-001-A05 | 新增工程 AC | 超时 / 离线 / 响应丢失可见且可恢复；按契约重试不重复保存，乱序响应不会覆盖更新会话。 |
| T-PET-001-A06 | 新增工程 AC | 重启及身份切换后，只加载契约允许的本用户会话，无跨身份消息泄漏。 |

**局部阻塞：** Q-001 决定会话保留、重启和跨设备范围，阻塞 A06 的最终期望；Q-002 决定上下文、质量、安全、时限与重试语义，阻塞 A02 的质量维度和 A05 的最终错误策略；Q-003 决定输入长度及跨平台键盘范围，阻塞 A04 的设备矩阵。空值和角色链路可先实现测试。
