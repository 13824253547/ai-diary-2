# T-MAT-005 真实AI配图任务与资产入库

状态：**进行中（Seedream Flash 真实服务及素材持久化/读取已实测；页面端预览和 iOS 系统相册验收仍待设备验证）**。业务依据：[素材与灵感 · MAT-005](../../business-spec/modules/material-library.md#mat-005-ai-补图)；原始验收：`MAT-005-AC01`, `MAT-005-AC02`, `MAT-005-AC03`。

## 实施范围

- 将同步添加 `photo-9` 替换为真实配图请求，通过安全服务边界提交非空描述；输入校验同时覆盖 UI 与提交入口，不向客户端放置服务密钥。
- 为任务记录请求 ID、输入版本和进行中/可使用/失败状态；按钮等待态防重复，取消、超时、重试按 Q-002 约定，不让旧/重复响应覆盖新任务或重复入库。
- 成功结果须下载/接收为真实可读图片资产并完成仓库提交，记录来源与描述关联，随后加入素材并打开该结果预览；服务返回但资产不可读/入库失败不算成功。
- 复用 MAT-001 的真实资产解析和素材列表；AI 配图预览提供“保存到相册”“用于明信片”和“生成日记”按钮。“用于明信片”传递同一生成素材 ID；“生成日记”创建新草稿、直达素材库照片选择并预选当前生成素材，仍遵守 CRE-002 的至少 3 张规则。不得恢复旧式“用于日记”操作或溢出菜单。留存、费用和质量指标不以示例图或 mock 数字定义。
