# T-MAT-005 真实AI配图任务与资产入库

状态：**未开始**。业务依据：[素材与灵感 · MAT-005](../../business-spec/modules/material-library.md#mat-005-ai-补图)；原始验收：`MAT-005-AC01`, `MAT-005-AC02`, `MAT-005-AC03`。

## 实施范围

- 将同步添加 `photo-9` 替换为真实配图请求，通过安全服务边界提交非空描述；输入校验同时覆盖 UI 与提交入口，不向客户端放置服务密钥。
- 为任务记录请求 ID、输入版本和进行中/可使用/失败状态；按钮等待态防重复，取消、超时、重试按 Q-002 约定，不让旧/重复响应覆盖新任务或重复入库。
- 成功结果须下载/接收为真实可读图片资产并完成仓库提交，记录来源与描述关联，随后加入素材并打开该结果预览；服务返回但资产不可读/入库失败不算成功。
- 复用 MAT-001 的真实资产解析和材料列表，提供用于日记/明信片入口；由 MAT-002/PCD-001 完成引用。留存、费用和质量指标不以示例图或 mock 数字定义。

## 依赖

[BAS-001](BAS-001.md)（AI任务/资产/重试契约）、[BAS-002](BAS-002.md)（真实配图服务）、[BAS-003](BAS-003.md)、[BAS-004](BAS-004.md)、[MAT-001](MAT-001.md)（真实资产仓库）。依赖用于完整验收，接口与纯规则可先使用明确的测试替身。共同约定见[执行上下文](../execution-context.md)。

## 任务验收

| 任务验收 ID | 原始验收 / 类型 | 可检查结果 |
| --- | --- | --- |
| T-MAT-005-A01 | MAT-005-AC01 | 空/空白描述不能触发请求；非空描述原意完整传递给真实生成任务。 |
| T-MAT-005-A02 | MAT-005-AC02 | 有效生成完成后获得可读取、可预览且已加入素材仓库的真实图片资产，保留来源/描述关联。 |
| T-MAT-005-A03 | MAT-005-AC02 | 结果预览提供日记/明信片入口，传递该新资产 ID，下游能读取并引用同一结果。 |
| T-MAT-005-A04 | MAT-005-AC03；异步目标待 Q-002 | 生成中按钮和提交处理器共同防重，同一任务重复响应只入库一份结果。 |
| T-MAT-005-A05 | 补充工程验收；支持 AC02/03 | 超时/服务错误/坏图片/入库失败不宣称成功或添加固定示例；迟到、取消或旧输入版本结果按任务契约隔离，不能覆盖当前结果。 |

## 决策与阻塞范围

- [Q-002](../../business-spec/open-questions.md)：阻塞生成质量、等待/取消/重试、覆盖、时效/费用/次数及 A04 正式规则；可先实现请求和资产通路，但不能用固定示例图验收真实生成。
- Q-003：阻塞描述长度和图片规格边界；Q-015/Q-001：阻塞生成资产的来源字段、保存期限和恢复策略。
- 日记/明信片引用入口的完整验收需 MAT-002/PCD-001 能力；这不使资产生成反向依赖其编辑实现。
