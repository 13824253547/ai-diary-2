# T-MAT-004 灵感回答接入真实陪伴对话

状态：**未开始**。业务依据：[素材与灵感 · MAT-004](../../business-spec/modules/material-library.md#mat-004-灵感卡与陪伴联动)；原始验收：`MAT-004-AC01`, `MAT-004-AC02`。

## 实施范围

- 选择灵感卡时固定当前问题及回答输入；空字符串/仅空白禁用并在提交层再校验。问题不能因异步过程切换到另一卡。
- 有效提交通过 PET-001 会话服务形成带当前问题与回答的一条用户消息，跳转陪伴页，显示真实服务回复；不再使用关键词分支固定回复证明完成。
- 为消息提供请求/消息关联，防重并处理异步等待、失败、超时及迟到回复；错误和恢复方式沿用 PET-001/Q-002 会话契约，不能把失败伪造为已收到回复。
- 复用会话归属/留存和安全服务边界；本任务不创建独立灵感作品，不自动生成日记。

## 依赖

[BAS-001](BAS-001.md)（问答/提交/恢复契约）、[BAS-002](BAS-002.md)（真实服务与归属）、[BAS-003](BAS-003.md)（会话留存）、[BAS-004](BAS-004.md)、[PET-001](PET-001.md)（真实聊天）。依赖用于完整验收，接口与纯规则可先使用明确的测试替身。共同约定见[执行上下文](../execution-context.md)。

## 任务验收

| 任务验收 ID | 原始验收 / 类型 | 可检查结果 |
| --- | --- | --- |
| T-MAT-004-A01 | MAT-004-AC01 | 打开任意灵感卡显示对应问题；空/仅空白回答不能提交且会话不变。 |
| T-MAT-004-A02 | MAT-004-AC02 | 有效回答提交后进入陪伴页，用户消息完整包含该问题与回答，得到关联于该提交的真实回复。 |
| T-MAT-004-A03 | 补充工程验收；支持 AC02 | 同次提交防重，服务等待/失败可辨识，迟到或重复回复不会插到错误问题/用户会话，不假造成功。 |
| T-MAT-004-A04 | 补充工程验收；支持 AC01/02 | 未提交关闭面板不发送消息；提交只影响目标会话，不创建日记/灵感作品或修改 D1/D2。 |

## 决策与阻塞范围

- [Q-002](../../business-spec/open-questions.md)：阻塞回复质量、超时/重试/取消及离开面板后的处理细则，基础问答传递与消息关联可先实现。
- Q-003：阻塞灵感回答长度/字符计量与问题加回答后的聊天上限；不得静默截断问题或回答。
- Q-001：阻塞会话留存/重启恢复边界，统一由 PET-001/BAS-003 承担。
