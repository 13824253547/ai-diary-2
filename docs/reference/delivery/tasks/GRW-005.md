## 任务内容

- 首次进入花朵页时对该设备当前全部有效日记正文/引用做一次可恢复 baseline 识别；后续保存/编辑仅增量分析该篇当前版本。模型返回三类固定花朵候选、简短说明、来源日记引用和首次旅行证据，服务端验证来源归属后每类至多授予一次。
- 花朵授予记录按设备持久保存，编辑/删除不撤回已获花朵；同设备、同日记版本重放幂等，来源版本变化不接受旧回调。三类都获授后才由服务端授权报告。
- 花朵页读取真实逐朵状态、模型说明和三项里程碑；首次旅行来自模型有效证据，30 天按去重日历日最新连续段计算、断档后重计，100 锚点读取统一真实锚点计数。三项里程碑只显示进度，不授花。
- 模型失败每批只尝试一次并记录固定终态；用户在花朵页显式重试，不自动重试、不用 mock 补成功。未配置模型、无来源或错误结构均不显示虚构进度/花朵。
