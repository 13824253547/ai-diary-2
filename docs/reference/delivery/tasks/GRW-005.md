# T-GRW-005 自动成长、记忆花朵与里程碑

**状态：未开始。** 关联 [FSD GRW-005](../../business-spec/modules/growth-and-insights.md#grw-005-记忆花朵与里程碑)，原验收 GRW-005-AC01～AC04；[同名案例](../test-cases/GRW-005.md)。自动成长的范围、触发和计算先由 Q-006 确认；确认纳入后按规则实现，不能以开发场景开关代替。

**依赖：** [BAS-001](BAS-001.md) Q-006 成长决策、事件和读模型契约、[BAS-002](BAS-002.md) 身份隔离、[BAS-003](BAS-003.md) 成长留存、[BAS-004](BAS-004.md) 可控时钟 / 重放测试；[T-DIA-005](DIA-005.md) 已保存记录事件、[T-GRW-003](GRW-003.md) 锚点事件。Q-006 若明确其他输入，再记录条件依赖；不把展示的里程碑擅自认定为获花条件。

## 任务内容

- 依据经确认的 Q-006 把真实记录 / 锚点等合格业务事件转换为叶子、花朵和里程碑进度，保存可追溯成长状态；未保存 / 失败 / 重复事件不得凭本机点击授予成长。
- 建立可重放且幂等的计算 / 发放机制；事件乱序、编辑和数据变化按决策处理。成长读模型向树、花朵页和报告权限提供一致状态，不使用 `scenario=unlocked` 作为生产权限来源。
- 展示真实主题、进度、里程碑与集满 3 朵花的报告门槛；锁定点击解释条件，解锁后进入报告。加载 / 失败 / 恢复与身份切换可见且不误授予。
- 自动成长具体规则尚未定义；实现者须先取得 Q-006 决策后补参数化预期，不根据“30天 / 100锚点 / 差3片叶子”倒推算法。
