## 任务内容

- 依据经确认的 Q-006 把真实记录 / 锚点等合格业务事件转换为叶子、花朵和里程碑进度，保存可追溯成长状态；未保存 / 失败 / 重复事件不得凭本机点击授予成长。
- 建立可重放且幂等的计算 / 发放机制；事件乱序、编辑和数据变化按决策处理。成长读模型向树、花朵页和报告权限提供一致状态，不使用 `scenario=unlocked` 作为生产权限来源。
- 展示真实主题、进度、里程碑与集满 3 朵花的报告门槛；锁定点击解释条件，解锁后进入报告。加载 / 失败 / 恢复与身份切换可见且不误授予。
- 自动成长具体规则尚未定义；实现者须先取得 Q-006 决策后补参数化预期，不根据“30天 / 100锚点 / 差3片叶子”倒推算法。
