# T-DSC-002 真实故事阅读

**状态：未开始。** 关联 [FSD DSC-002](../../business-spec/modules/discovery.md#dsc-002-故事阅读)，原验收 DSC-002-AC01～AC03；[同名案例](../test-cases/DSC-002.md)。

**依赖：** [BAS-001](BAS-001.md) 故事详情与缺失错误契约、[BAS-002](BAS-002.md) 可见权限、[BAS-003](BAS-003.md) 缓存及撤回行为、[BAS-004](BAS-004.md) 故事夹具。可独立完成直接路由，列表入口由 T-DSC-001 接入。

## 任务内容

- 通过路由故事 ID 从真实内容仓库取得标题、封面、作者、日期、地点、正文和点赞摘要；详情与列表共用稳定 ID，不能依赖固定 mock 数组。
- 区分加载、可读、目标不存在 / 已撤回 / 无权限及网络失败状态；缺失时保留回发现动作，不把暂时性网络故障当作故事不存在。
- 用户返回时回到来路；直达链接无导航栈时按路由契约回发现。内容更新或撤回后重新进入详情应遵循真实可见性规则；不读取私密或不可访问正文。

## 任务验收

| ID | 来源 | 可验收结果 |
| --- | --- | --- |
| T-DSC-002-A01 | DSC-002-AC01 | 以故事 ID 读取并显示该故事的完整字段与正文；与列表数据对应。 |
| T-DSC-002-A02 | DSC-002-AC02 | 从发现列表进入后顶部返回恢复来路；直达场景有可用后退路径。 |
| T-DSC-002-A03 | DSC-002-AC03 | 不存在的 ID 呈现缺失态，返回发现动作可用。 |
| T-DSC-002-A04 | 新增工程 AC | 无权限、撤回和临时失败按契约处理；不泄露不可见正文，网络重试不会误判缺失。 |

**局部阻塞：** Q-007 决定公开日记是否进入发现、匿名显示、撤回与可见权限，阻塞 A04 的最终权限矩阵；Q-001 决定离线缓存的可读范围。无效 ID、真实详情和一般失败可先实施。
