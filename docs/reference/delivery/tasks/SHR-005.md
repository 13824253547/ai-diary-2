# T-SHR-005 真实平台交付与长图/PDF导出

状态：**未开始**。业务依据：[隐私与分享 · SHR-005](../../business-spec/modules/sharing-and-privacy.md#shr-005-平台分享长图与-pdf)；原始验收：`SHR-005-AC01`, `SHR-005-AC02`, `SHR-005-AC03`, `SHR-005-AC04`。

## 实施范围

- 替换 `recordShareDemo` 先记成功的演示动作。建立准备、交付、取消、失败等真实操作结果，具体终态与记录事件依 BAS-001/Q-014 契约；预览准备不能代表文件保存或平台发布。
- 真实渲染长图/PDF并写入已决定的系统/文件出口，返回可读取实际文件；私密允许本地导出，选段与匿名内容沿用统一投影，匿名输出不得携带未遮挡原图。
- 只实现页面已表达的朋友圈、小红书、X 出口；通过正式支持的系统/平台适配器交付真实资产。私密在任何外部调用前拦截并提供公开范围入口。
- 分别保存平台行为与导出行为，按约定事件更新且渠道去重；请求绑定目标、内容版本及出口，防止重复/乱序结果写错作品。权限拒绝、写失败、不支持/未安装、取消等按真实结果反馈，原日记不被导出动作修改。

- [Q-014](../../business-spec/open-questions.md)：阻塞导出范围/尺寸/格式、正式平台支持、系统权限UX、结果语义与记录时机的最终验收；先定义契约再执行真实出口案例。

- Q-001：阻塞行为与文件留存边界；基础拦截与单次实际资产交付不依赖跨设备同步。
