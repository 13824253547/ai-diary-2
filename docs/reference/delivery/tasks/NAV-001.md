# T-NAV-001 业务入口、路由参数与退出一致性

状态：进行中。依赖：[BAS-001](BAS-001.md) 的入口决策；涉及 CRE/DIA/SHR/MAT/PCD/GRW。关联：Q-009、Q-018；[页面映射](../../business-spec/page-map.md)。

## 任务内容

1. 按页面映射建立每个正式入口的导航路径和参数契约：新建/编辑草稿、日记、公开设置、分享、素材回传、明信片素材、锚点和报告。
2. 详情的继续编辑、公开设置和分享使用明确入口；不把当前“更多”实际只进入隐私页的原型行为默认冻结。每种入口正确恢复目标 ID/草稿及返回位置。
3. 处理拒绝/撤回相册权限、无效日记/故事/草稿、返回、取消、重复打开、深链和应用冷启动；错误目标不得回退展示其他数据。
4. 统一加载、空态、错误态和未保存退出确认；按业务决定对草稿、弹层和外部分享取消的处理。
5. 保持页面映射与应用文件对应：当前为 37 个页面/别名/辅助入口及 2 个布局文件；清理重定向/别名的重复实现，不让别名绕过权限和数据归属。

## 验收条件

- **T-NAV-001-A01**：从首页、回忆、详情、素材、明信片、我的和发现进入功能时，目标路由收到正确的业务 ID/模式，且对应数据不串篇。（新增实施验收）
- **T-NAV-001-A02**：新建和编辑流程在授权、选图、类型、排版师、生成、命名、编辑、保存/放弃、返回时保持草稿状态及确认的返回目标。（CRE-001～006、DIA-005；新增实施验收）
- **T-NAV-001-A03**：详情可按确认入口继续编辑、设公开范围或分享；入口行为与 Q-009 决策一致，不把隐私页误当编辑/分享。（DIA-001-AC04、Q-009）
- **T-NAV-001-A04**：冷启动和深链先恢复并验证目标；有效且有权的目标正常打开，无效或无权目标显示对应空/错误态或授权入口，不能读取或展示另一个用户/日记的内容。（DIA-001-AC03、SHR-001-AC03、DSC-002-AC03；新增实施验收）
- **T-NAV-001-A05**：取消/返回/重复打开不产生未确认写入；已保存后返回到正确详情，未保存退出遵循确认规则。（BR-01/02；新增实施验收）
- **T-NAV-001-A06**：页面映射中的 37 个页面/别名/辅助入口有自动或人工证据，2 个布局有页面栈及导航配置检查；别名不会绕过同一权限、状态和数据校验。（新增实施验收）
