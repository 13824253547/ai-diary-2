# T-GRW-004 锚点纠正真实保存

**状态：未开始。** 关联 [FSD GRW-004](../../business-spec/modules/growth-and-insights.md#grw-004-锚点纠正)，原验收 GRW-004-AC01～AC05；[同名案例](../test-cases/GRW-004.md)。

**依赖：** [BAS-001](BAS-001.md) 纠正 ID / 版本 / 写入 / 冲突契约、[BAS-002](BAS-002.md) 归属权限、[BAS-003](BAS-003.md) 纠正留存、[BAS-004](BAS-004.md) 故障环境；[T-GRW-003](GRW-003.md) 真实锚点和源日记。对聊天 / 报告的传播仅依 Q-016 决定，不把下游完成作为基础写入前置。

## 任务内容

- 用真实锚点 ID 与来源版本保存用户理解，替换拼接标签 / 日记 ID 的内存字典。纠正初值读取已提交内容或提取结果，底部入口定位第一条当前可用锚点。
- 非空、去空白及输入限制从统一校验执行；写入确认前显示处理中，失败不标记成功、不清掉待保存输入，可重试；关闭 / 取消未提交修改不写入仓库。
- 保存不改原日记正文；按 Q-016 定义标签范围及向提取、聊天、报告的传播，并保留能区分提取结果与用户纠正的来源信息。并发纠正 / 原文变更按 BAS 契约处理，不能静默旧写覆盖。
- 重开与身份切换验证纠正留存、权限及更新标识，读写不能跨用户复用。

| ID | 来源 | 可验收结果 |
| --- | --- | --- |
| T-GRW-004-A01 | GRW-004-AC01 | 卡片纠正的初值等于当前理解；底部入口目标是第一条可用锚点。 |

| T-GRW-004-A04 | GRW-004-AC04 | 取消 / 关闭未提交修改不变更理解；保存纠正不改原日记正文。 |
