# T-DSC-003 真实点赞与取消

**状态：未开始。** 关联 [FSD DSC-003](../../business-spec/modules/discovery.md#dsc-003-点赞与取消)，原验收 DSC-003-AC01～AC04；[同名案例](../test-cases/DSC-003.md)。

**依赖：** [BAS-001](BAS-001.md) 点赞写入 / 幂等 / 计数契约、[BAS-002](BAS-002.md) 操作者身份与故事权限、[BAS-003](BAS-003.md) 互动留存、[BAS-004](BAS-004.md) 并发测试替身；[T-DSC-001](DSC-001.md) 列表和 [T-DSC-002](DSC-002.md) 详情两处入口。

## 任务内容

- 用真实互动服务保存每个可访问故事的当前用户点赞状态，显示服务认可的计数；列表与详情读取同一故事状态，不靠基础 mock 数字加本机布尔值作为最终计数。
- 处理重复点击、响应丢失、乱序确认和多设备并发；按 BAS-001 的请求标识 / 版本契约保证一次目标状态只有一个生效结果，不出现负数、重复点赞或跨故事串状态。
- 点赞失败时反馈并恢复或重试到可确认状态；撤回 / 不可见故事不得继续产生可见互动。重开应用后按身份恢复已点赞状态。

## 任务验收

| ID | 来源 | 可验收结果 |
| --- | --- | --- |
| T-DSC-003-A01 | DSC-003-AC01 | 未点赞故事点赞成功后状态与计数同步变更，增加当前用户的一次互动。 |
| T-DSC-003-A02 | DSC-003-AC02 | 取消点赞成功后状态与计数恢复，不保留当前用户互动。 |
| T-DSC-003-A03 | DSC-003-AC03 | 列表与详情对同一故事显示相同的已确认点赞状态及计数，往返后同步。 |
| T-DSC-003-A04 | DSC-003-AC04 | 重复点击或响应重放不产生多份当前用户点赞，不影响其他故事。 |
| T-DSC-003-A05 | 新增工程 AC | 写入失败、离线、乱序响应与重启后，界面最终以真实服务状态收敛，且身份隔离有效。 |
