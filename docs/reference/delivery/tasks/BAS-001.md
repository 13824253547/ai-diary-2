# T-BAS-001 实施范围、业务决策与接口契约

状态：进行中。已完成第一阶段核心契约、建议默认值与任务链接回填；其余模块级决策与契约仍待继续推进。关联：[待确认问题 Q-001～018](../../business-spec/open-questions.md)、[业务对象与规则](../../business-spec/common-rules.md)、[实施约定](../execution-context.md)。

## 任务内容

1. 为准备实施的任务关闭其关联 Q：记录选择、适用版本和业务依据；同步 FSD 与任务/案例预期。未确定的部分继续标待决策。
2. 明确数据留存和身份边界、相册范围、AI 输入输出/质量/异常、社区发布关系、成长来源、文件及平台交付事件；以实际功能范围确定服务和存储方案。
3. 建立版本化契约：日记/草稿/照片 URI 与元数据/人物/公开投影/聊天/故事点赞/锚点/成长/衍生文件的结构及归属，日期区间与唯一 ID 规则。
4. 为服务能力写请求、成功/失败返回、分页与空结果、超时/取消、任务轮次、幂等键、版本冲突、权限检查。明确 AI 与客户端职责、外部平台仅能证明的交付事件。
5. 在本目录交付决策记录和契约，并链接到受影响任务。按待实施模块逐步补齐，不等待无关决策。

## 验收条件

- **T-BAS-001-A01**：每项要实施的业务规则都能追到 FSD/BR 或已记录的 Q 决策；未关闭问题不会被默认为已确认。（新增实施验收）
- **T-BAS-001-A02**：契约涵盖当前任务使用的对象、字段、标识、日期、数据归属和留存；包含有效与无效样例。（新增实施验收）
- **T-BAS-001-A03**：每项远程操作都有成功、空结果、失败、权限拒绝及适用的超时/取消/幂等语义，能据此生成请求与状态断言。（新增实施验收）
- **T-BAS-001-A04**：每项 AI 能力都有允许输入、结构输出、质量评测维度和失败/覆盖策略；固定 mock 文案不能作为质量标准。（Q-002；新增实施验收）
- **T-BAS-001-A05**：交付/成长/统计/日期/公开等未定业务预期，在相关 Q 关闭后同步到规格、任务和案例；它们之间无相反要求。（Q-004～016；新增实施验收）

## DEV-3 generation request contract 收紧

- `core-diary-v1` 的 generation create request 现有共享类型与 validator，要求非空 `draftId` / `idempotencyKey` 及从 1 开始的正安全整数 `draftVersion`。
- HTTP repository 发请求前拒绝非法请求，不调用网络；generation controller 先解析 `x-device-id`，再校验 body，缺失身份仍优先返回 `device_identity_required`；合法 body 才会进入 Store。
- generation-job response validator 同步拒绝非正或非安全整数 `draftVersion`。同设备幂等键现绑定原始 draft/version；并发相同请求会追认同一任务，键被其他草稿/版本复用时返回 `version_conflict`。contract/repository/controller/e2e tests 已新增但未运行；CASE-BAS-001-003 与相关业务 CASE 不新增通过项。
- 保存命令契约明确同设备 key 绑定 `draftId + sourceDiaryId + sourceDiaryVersion`；身份字段改变时返回 `version_conflict`，同命令身份仍重放首次结果。服务 runtime guard 与隔离 MySQL regression 已补，尚未运行，不扩展 CASE 通过证据。
- `Draft` 契约补充服务端运行时要求：字段类型/隐私合法、照片 ID 为字符串数组、`version` 为正安全整数；新增畸形 body e2e 未运行，不更改照片数量/去重或来源留存决策。
- rewrite endpoint 契约补齐请求 ID、块类型、正文和照片上下文字段的运行时约束；服务端先校验设备身份，再拒绝畸形 body，新增 controller 回归未运行。
- 回忆查询契约将 `page/pageSize` wire value 固定为十进制整数字符串；拒绝指数、十六进制、小数、空白及重复 query 参数，维持身份错误优先。
- discovery read query 契约也将分页值固定为十进制整数文本，keyword 必须是单一字符串；controller/service 双层校验，category 仍只允许已明确的 `latest`。
- PET-001 会话列表契约现明确要求分页 query 为单一十进制整数文本；controller 在身份校验后解析，service 在数据库调用前复核对象、数值类型、安全整数、页码和页容量。新增 regression 未运行，不扩展 CASE-BAS-001-002/003 的既有证据。
