# T-SHR-002 公开选段与统一内容投影

状态：**进行中**。业务依据：[隐私与分享 · SHR-002](../../business-spec/modules/sharing-and-privacy.md#shr-002-选段公开与内容范围)；原始验收：`SHR-002-AC01`, `SHR-002-AC02`, `SHR-002-AC03`, `SHR-002-AC04`。

## 实施范围

- 统一可选正文/引用句和选段保存规则，过滤不存在/非可选 ID、去重；非私密显式空集合原子拒绝，不先更新范围再失败。
- 按保存版本与选段生成独立公开内容对象，供海报、完整预览和后续真实出口共同读取。过滤正文、引用句及关联独立图片和段落引用；封面、摘要、海报照片从允许内容重新得到。
- 只选无图引用句时生成无图作品，禁止从原始封面或未选照片补齐。私密预览读取整篇；投影不修改个人原始作品。
- 覆盖真实资产 ID 和已失效引用，不依赖 `mockPhotos` 作为唯一有效集合；对共享图片/关联引用句边界执行 Q-013 决策后补充规则。
