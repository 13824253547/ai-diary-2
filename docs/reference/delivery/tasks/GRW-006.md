# T-GRW-006 专属洞察报告真实生成

**状态：未开始。** 关联 [FSD GRW-006](../../business-spec/modules/growth-and-insights.md#grw-006-专属洞察报告)，原验收 GRW-006-AC01～AC04；[同名案例](../test-cases/GRW-006.md)。

**依赖：** [BAS-001](BAS-001.md) 报告生成 / 版本 / 质量 / 请求契约、[BAS-002](BAS-002.md) 来源及权限隔离、[BAS-003](BAS-003.md) 报告留存、[BAS-004](BAS-004.md) AI 评测与真实集成环境；[T-DIA-005](DIA-005.md) 来源记录、[T-GRW-001](GRW-001.md) 统计、[T-GRW-005](GRW-005.md) 解锁状态；Q-016 确认后消费 [T-GRW-004](GRW-004.md) 的纠正影响。

## 任务内容

- 将固定三段洞察替换为从本用户可访问的真实日记和获准记忆上下文生成的报告。保留三类洞察维度，保存报告 ID、来源记录 / 版本、生成状态及结果；同一解锁状态不等于已有生成成功报告。
- UI 与生成 / 读取服务均校验权限；未解锁不展示正文、不能靠路由参数触发生成。解锁后按 Q-006 / Q-002 决定首次生成与更新时机；来源改变或纠正影响按 Q-016 更新，旧回调不能覆盖新版本报告。
- 表达生成中、无可用来源、失败、重试和已有报告读取；真实成功后才能展示报告完成，生成输出通过结构、归属与质量校验，不逐字匹配 mock 结论。
- 报告来源说明与统计使用相同口径并明确版本时间；Q-005 若规定来源子集须同步修订 FSD 的共享数量要求。数据归属文案必须符合 Q-001 的真实存储方案，不能在远端处理时误称完全本地。
