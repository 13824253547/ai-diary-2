## 任务内容

- 将固定三段洞察替换为服务端现有 PET_CHAT 模型基于当前设备全部有效日记正文/引用生成的三维结构报告；不输入普通聊天、纠正、照片、EXIF 或跨设备内容。保存报告 ID、来源日记 ID/版本、生成状态和成功结果。
- 服务端和页面均验证三类花朵已由当前设备真实获得；未解锁直达页面/API 不读正文、不调用 Provider。解锁后仅在报告页打开时检查来源版本并按需生成；每篇日记新建/编辑/删除令当前报告过期，下次打开更新。
- 报告更新期间保留上次成功报告；失败时旧报告继续可见并提供用户手动重试；每次自动批次仅尝试一次。请求任务幂等，旧来源版本/迟到回调不得覆盖新报告；真实模型失败或结构畸形不回退 mock。
- 展示本次有效来源日记数量、生成时间、固定三个洞察维度及「这不是定义，只是一面镜子」；服务端按设备保存报告，不声明数据只在本地。无来源、未解锁、错误响应分别呈现真实状态。
