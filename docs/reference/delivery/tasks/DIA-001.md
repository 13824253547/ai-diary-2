## 任务内容

- 把 useDiaryRoute 的内存查找接入已保存日记仓库，区分加载、读取失败、无效 ID 和成功；读取整个作品同一版本，不能混入未保存草稿。
- 图片组件接入真实资产引用与缺图错误，替换示例图片回退；内容按角色布局展示，不因版式变化修改正文/引用归属。
- 详情顶部“更多”连接真实日记操作菜单；公开范围、分享和删除绑定当前 `diaryId`，按用户要求不显示“继续编辑”。锚点入口仍按 GRW-003/004 验收。

## 当前实现进展

- `src/repositories/core-diary-repository.ts` / `src/repositories/http-core-diary-repository.ts` 已补单篇读取入口 `getDiary(...)`，前端可通过真实 `/diaries/:id` 读取已保存作品。
- `src/store/create-app-store.ts` 已新增 `readDiaryById(...)`：当仓库支持单篇读取时优先拉远端，成功后会把作品合并回 `diaries`、`memoriesSourceItems` 与当前 `memoriesItems`；`not_found` / `permission_denied` 会收口到“没有找到这篇日记”，其他错误会记入 issue log 并返回可见失败态。
- `app/diary/[id]/index.tsx` 已在“本地只有回忆摘要占位”或“本地没有整篇内容”时自动发起真实读取，并区分“正在读取这篇日记”“没有找到这篇日记”“暂时没把这篇日记读出来”三类页面状态；读取失败支持页面内“重新加载”。
- 详情页已用 `requestVersionRef` 做请求版本保护；切换到另一篇作品后，旧请求迟到返回不会覆盖当前详情。
- `src/components/diary/diary-paper.tsx` 已补三种开放角色的布局定位点与组件级证据：`character-blue / character-green / character-brown` 会分别走默认、明信片、北欧风布局分支，但标题、正文、引用句与同一批照片引用仍保持属于同一篇已保存作品。
- `src/components/diary/photo.tsx` 已为丢失资源和加载失败补可见占位“图片暂时不可用”；坏图时不再退成无法辨识的纯底色，`DiaryPaper` 仍会继续渲染正文与引用内容。
- DEV-3 repository 增量：`HttpCoreDiaryRepository.getDiary(id)` 在请求前拒绝 malformed ID，并在读到合法正文快照后确认返回 `diary.id` 与路由请求 ID 完全匹配；响应串 ID 时 fail closed，不交给 Store/详情页。新增 repository regression 未运行，不改详情页行为。
- DEV-3 路由缓存隔离：详情页远端读取结果现在绑定其请求 `diaryId`，不会在路由切换后盖过新目标的本地完整内容；effect 在加载、无需加载和无效 ID 等分支开始时都会推进 request version，使旧在途回调失效。新增 `saved-diary-screens.spec.tsx` 回归覆盖切换到本地完整日记、旧请求迟到及返回后重新读取，尚未运行。
- 顶部“更多操作”现连接 `/modal/more-actions`；公开范围保存后回到当前详情，分享和删除绑定当前日记 ID；按用户要求不提供“继续编辑”菜单项。锚点业务验收仍由 `GRW-003/004` 负责。

## 任务验收

- **T-DIA-001-A01：**映射 **DIA-001-AC01**。有效作品展示已保存标题、日期/地点、正文、引用句和有效照片，未保存改动不混入。
- **T-DIA-001-A02：**映射 **DIA-001-AC02**。角色决定详情布局，内容仍属于同一作品。
- **T-DIA-001-A03：**映射 **DIA-001-AC03**。无效日记 ID 显示未找到空态并可返回首页。
- **T-DIA-001-A04：**映射 **DIA-001-AC04**。详情“更多”进入当前作品操作菜单；公开范围保存后返回同一详情，分享/删除均使用当前日记 ID，菜单不显示“继续编辑”。
- **T-DIA-001-A05：**映射 **DIA-001-AC05**。锚点入口可打开锚点页；锚点业务由 GRW-003/004 负责。
- **T-DIA-001-A06：**【工程新增】读取失败与资源失效可见；切换作品后的旧读取回调不覆盖当前详情，不用示例作品掩盖错误。
- **T-DIA-001-A07：**首页最近日记只打开最新同步的 `ready` 已保存作品；草稿/生成中排除，失败可重试，封面不从无关图片补位。

当前已形成真实代码与自动化证据的是 A01、A02、A03、A06；A04、A05 已接入真实上下文，正式回路仍待对应依赖任务闭环。
