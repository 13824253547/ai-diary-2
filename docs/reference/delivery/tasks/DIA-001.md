# T-DIA-001 日记阅读

状态：未开始

## 关联 FSD 与原始 AC

[DIA-001 规格](../../business-spec/modules/diary-management.md)：DIA-001-AC01、DIA-001-AC02、DIA-001-AC03、DIA-001-AC04、DIA-001-AC05。

## 依赖

- [BAS-001](BAS-001.md)
- [BAS-003](BAS-003.md)
- [BAS-004](BAS-004.md)
- [NAV-001](NAV-001.md)

BAS-001 只要求当前功能相关决策/契约；BAS-003 定义留存，BAS-004 提供测试基础。入口连接由 NAV-001 统一验收。

## 任务内容

- 把 useDiaryRoute 的内存查找接入已保存日记仓库，区分加载、读取失败、无效 ID 和成功；读取整个作品同一版本，不能混入未保存草稿。
- 图片组件接入真实资产引用与缺图错误，替换示例图片回退；内容按角色布局展示，不因版式变化修改正文/引用归属。
- 公开范围、编辑/分享与锚点入口使用真实日记上下文；NAV-001 负责详情菜单连接，顶部“更多仅打开隐私”只是原型现状。

## 任务验收

- **T-DIA-001-A01：**映射 **DIA-001-AC01**。有效作品展示已保存标题、日期/地点、正文、引用句和有效照片，未保存改动不混入。
- **T-DIA-001-A02：**映射 **DIA-001-AC02**。角色决定详情布局，内容仍属于同一作品。
- **T-DIA-001-A03：**映射 **DIA-001-AC03**。无效日记 ID 显示未找到空态并可返回首页。
- **T-DIA-001-A04：**映射 **DIA-001-AC04**。经约定入口进入公开范围设置，完成后返回同一日记详情；具体菜单接入由 NAV-001/Q-009 验收。
- **T-DIA-001-A05：**映射 **DIA-001-AC05**。锚点入口可打开锚点页；锚点业务由 GRW-003/004 负责。
- **T-DIA-001-A06：**【工程新增】读取失败与资源失效可见；切换作品后的旧读取回调不覆盖当前详情，不用示例作品掩盖错误。

## 必要待定规则

Q-009 阻塞正式详情编辑/分享菜单路径；Q-001 阻塞留存/恢复。公开范围结果依据 SHR-001/002，不在本任务重复定义。 详见[问题清单](../../business-spec/open-questions.md)。
