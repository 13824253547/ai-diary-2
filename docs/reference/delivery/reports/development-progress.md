## DEV-89 修复 AI 素材在 iOS 模拟器的下载失败（2026-10-28）

- 根因：生成前服务端素材读取使用 `expo-file-system/legacy.downloadAsync`，iOS legacy 记录默认 `sessionType=background`。iOS 26 模拟器原生日志显示 `NSCocoaErrorDomain 4097`，无法连接 `com.apple.nsurlsessiond`，后台 `NSURLSessionDownloadTask` 创建失败并向 JS 返回 `ERR_FILESYSTEM_CANNOT_DOWNLOAD`。该错误发生在请求抵达素材接口前，不是图片损坏、权限拒绝、后端文件读取或模型失败；本地相册 file URI 不走该远程下载路径。
- 修复：改用 Expo 57 `File.downloadFileAsync` 前台下载。原生实现无进度/取消会走 `URLSession.shared`，仍保留设备身份头、临时缓存、JPEG 转换、尺寸/上传限制与最终清理。开发诊断为内容下载请求添加 `x-request-id`，按素材 ID、序号和阶段写入本机脱敏日志；正式错误文案不变。
