# 外部能力与任务处理清单

日期：2026-10-15。扫描依据：delivery 全部 42 份 task、当前 decision-register、package.json、backend provider、store、素材页、导出与分享服务。此表是能力分类及开发策略，不是功能完成报告，也不指定供应商。

## 核心结论

直接需要 AI 推理能力的功能有 **5 类**：日记生成（CRE-005）、段落重写（DIA-002 的重写部分）、宠物聊天（PET-001）、AI 配图（MAT-005）、洞察报告（GRW-006）。涉及 **5 项任务**，不是 5 个供应商；多项可共用一个文本/多模态 provider，配图需相应图像模型能力。

锚点/标签语义提取（GRW-003）是另 **1 项模型/算法方案待定任务**：规格要求真实提取和质量评测，但尚未确定外部模型、自部署还是本地算法，不能直接写成已确认必须采购第三方 API。当前可按 mock 提取结果开发下游业务。

平台专属交付还有 **2 项混合任务**：SHR-005、PCD-002。指定朋友圈等平台出口可能需要 SDK、应用注册/审核、目标 App 和平台支持；系统分享可用框架/包，但不能保证专属渠道支持，更不能保证发布或对方收取。它们的本地文件生成与保存不能整项跳过。

## 直接或条件外部能力

| 任务/能力 | 不能靠安装普通包补齐的部分 | 当前代码/资料 | DEV-1 处理 |
| --- | --- | --- | --- |
| CRE-005 日记生成 | 照片理解与自然语言生成、输出质量 | `backend/src/common/diary-generation.service.ts` 有 deterministic 与 openai-compatible；调用 `/chat/completions`，需模型/服务凭据 | 保留已接通的任务与保存服务，完善 provider 契约和编排；缺模型用 deterministic provider，延期真实模型与评测 |

| MAT-005 AI 配图 | 文生图推理与生成资源 | `app/library/index.tsx` 当前添加 `photo-9` 示例，未有真实 image provider | 先写任务、资产注册、来源/描述、版本与错误编排；使用独立 mock 图片结果，不新增正式页面调试入口 |

| GRW-003 锚点/标签提取 | 提取方案和语义质量待定，非已确认第三方采购 | task 明确 Q-016/Q-002，禁止首句截断冒充最终提取 | 提取接口和来源/版本/权限业务先写，mock 锚点；保留算法和触发规则决策 |
| SHR-005 平台交付部分 | 专属平台支持、注册/审核、平台 App 与交付结果 | 交付 orchestrator 已有；当前未接正式平台 SDK | 先开发本地 PNG/PDF、隐私投影与交付编排；外部适配器 mock/unsupported，不伪写真实交付记录 |
| PCD-002 微信/朋友圈部分 | 微信平台支持、应用身份和真实渠道调用 | task 指定好友/朋友圈；图片生成依赖 PCD-001 | 本地卡片资产和保存继续开发；渠道接口占位、真实平台交付延期 |

安装 AI SDK 只是封装请求，不会自带可用模型和凭据。自部署模型理论上可替代外部 API，但需要模型、算力和部署方案，不属于本轮“安装包即可完成”的范围。不给定供应商时不要新增购买、收费、账号或登录业务。
