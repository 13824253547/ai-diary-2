## 中文版

相册里留下了风景，也留下了当时的你。

AI旅行日记帮你把旅行照片整理成可以阅读、修改和收藏的图文游记。让照片不只停留在相册里，也让那些值得记住的瞬间，有自己的故事。

【让照片成为游记】

选择至少3张照片，挑选喜欢的排版师风格，由AI辅助生成图文游记。生成后，你可以修改标题和正文、调整段落配图，再保存成自己的回忆。

【和小橘聊聊】

把旅途见闻、日常小事和此刻的感受告诉小橘。它会结合已有的日记文字记忆与你交流。你也可以通过记忆锚点回看来源记录，纠正它对回忆的理解。

【把回忆整理起来】

在回忆空间浏览已保存的日记，按月份回看记录。随着日记积累，探索记忆花朵；集齐三类花朵后，可查看基于日记内容生成的个人洞察报告。

【制作一张自己的明信片】

从素材库选择一张照片，搭配可选的贴纸和已解锁城市印章，制作明信片。保存到相册，或通过系统分享面板交给支持图片分享的应用。

【为灵感补上画面】

描述你想留下的场景，由AI生成配图并加入素材库，用于游记创作或明信片。生成图片是创作素材，不是真实拍摄记录。

日记与AI配图提供来源提示；使用AI配图制作的明信片在保存或分享时保留标识。

【由你决定公开什么】

新建日记默认私密。你可以自行选择公开范围和公开段落，也可以把已公开的日记改回私密。

AI旅行日记适合喜欢旅行、拍照和收藏回忆的你。选几张照片，从一次值得记住的出发开始。

使用说明：AI生成与聊天需要网络连接，内容可能存在偏差，请在保存或分享前核对。萌宠陪伴与个人洞察仅用于日常交流和自我回顾，不提供医疗诊断、心理治疗或专业建议。所选照片、相关文字及必要数据会由服务端和已配置的AI服务处理；具体处理、留存及删除方式以隐私政策为准。访问系统相册、保存图片及需要定位的功能会请求相应权限。

## 隐私披露准备

当前业务会在服务端留存素材、日记、聊天及派生记忆数据，因此**不能声明“数据不收集”或“全部只保存在本地”**。匿名设备归属也不等同于数据无法关联用户。

以下为申报准备清单，不是可直接勾选的最终法律结论：

| 数据或行为 | 申报核对方向 |
|---|---|
| 已选照片、上传素材、日记配图 | 用户内容中的照片或视频；核对服务端和AI提供商的留存 |
| 日记、聊天输入、人物称呼、配图提示、用户纠正 | 用户内容及其他适用类型；核对含有敏感信息时的处理 |
| 服务端签发的设备用户身份 | 标识符中的用户ID，以及设备ID是否适用；不能仅因没有注册而选择“不关联用户” |
| 同城筛选使用的城市 | 核对粗略位置的传输及留存；日记地点兜底仅回填城市，不保存或上传原始坐标 |
| 日志、错误和任务记录 | 核对诊断数据以及部署后的第三方监控、访问日志 |
| 第三方AI服务 | 说明处理目的、传输内容、提供方、处理地区、留存、删除及训练使用安排 |
| 跟踪 | 当前未见广告跟踪用途；仍需核对最终构建全部SDK及第三方实际实践 |

用途通常涉及应用功能，是否还用于个性化、分析或其他用途须按实际确认。收集类型、与身份关联和用于跟踪是不同问题，应分别回答。

现有 `PrivacyInfo.xcprivacy` 的收集类型数组为空，不能据此认定 App Store 隐私标签无需填写；隐私清单、系统权限用途说明与商店隐私披露应分别核对并保持一致。

隐私政策至少需要说明运营主体和联系方式、数据类型与目的、第三方AI处理、服务器处理与设备归属、公开内容范围、保存期限、删除与权利请求渠道、权限撤回、未成年人安排。涉及向第三方AI传输个人数据时，应核对是否已完成清晰披露并取得所需的明确同意。
