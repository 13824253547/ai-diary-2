# 隐私与分享

用户目标：控制每篇日记的可见范围，并将允许公开的内容制作成分享或导出作品。关联流程 J-03，通用规则 BR-06～09。

## SHR-001 公开范围设置

证据：**交互已表达**；当前提供私密、匿名公开和公开仅点赞。评论选项暂时移除，评论与审核能力不开放。

前置与流程：已保存日记 → 进入公开范围 → 单选私密、匿名公开或公开仅点赞 → 选择正文/引用段落 → 完成。进入时读取已保存设置；页面内选择尚未完成前不修改日记。新作品默认私密。完成后，非私密范围会将所选内容生成/更新到发现「最新」；改回私密则撤下发现快照。完成后仍根据入口返回详情或进入分享页。

异常：日记不存在显示空态；非私密选段为空时不保存并提示至少公开一段。已知城市来自保存的日记地点；未知地点不进入同城结果。匿名内容带照片但当前无法安全遮挡时，不允许提交该匿名发布，不以原图替代。

- **SHR-001-AC01**：Given 新创建并保存的日记，When 查看公开范围，Then 默认选择私密。
- **SHR-001-AC02**：Given 有效日记，When 完成三种当前开放范围中任意一种有效设置，Then 重进页面看到对应范围；离开而未完成时仍保留原设置。
- **SHR-001-AC03**：Given 日记不存在，When 进入设置页，Then 显示可返回的空态，不对其他日记产生修改。
- **SHR-001-AC04**：Given 日记选择非私密范围并完成保存，When 读取发现最新，Then 只出现该作品公开选段及关联内容；切回私密后故事与公开图片立即不可读。

依据：[设置页面](../../../../app/share/privacy.tsx)、[隐私保存与发现同步](../../../../backend/src/common/memory-store.service.ts)。评论当前不开放；若未来恢复，再按 Q-007 定义互动/审核。Q-013 仍管理历史文件撤回。

## SHR-002 选段公开与内容范围

证据：**交互已表达**。

前置与流程：在公开范围页勾选正文/引用句，可展开全部段落 → 完成 → 分享内容按选择生成。默认选择全部可选段落；非私密至少选择一段；私密不保留公开选段限制。

结果与规则：选段约束同时作用于正文、独立图片、段落引用图片、封面、摘要及海报照片。只选无图引用时可以得到无图预览，不回退使用原封面。个人阅读原日记不因选段而被删改。当前图片块的关联与引用规则见 BR-05、BR-07；共享图片和关联引用句等细节需补充决策。

- **SHR-002-AC01**：Given 非私密日记，When 取消全部段落后完成，Then 显示至少选择一段，原公开范围与段落设置均保持不变。
- **SHR-002-AC02**：Given 只公开部分正文，When 查看海报与完整预览，Then 不出现未选正文及不属于公开内容的照片，摘要与封面也来自允许内容。
- **SHR-002-AC03**：Given 只公开无图引用句，When 查看预览，Then 显示引用内容且不使用原日记照片补齐封面或海报。
- **SHR-002-AC04**：Given 设置公开选段，When 回到个人日记详情，Then 原文仍完整；改回私密后的个人预览仍完整。

依据：[可选段落和投影规则](../../../../src/store/diary-domain.ts)、[分享预览](../../../../app/share/result.tsx)。待确认：Q-013、Q-014。

## SHR-003 匿名公开

证据：**交互已表达**，对已知姓名/别名与已标记面容进行匿名处理；未标记人物的处理待确认。

前置与流程：选择匿名公开并完成 → 查看分享内容。已知人物姓名和曾用名在标题、正文、小标题、摘要、地点、图片说明中替换为“同行人”；对外内容不携带人物名单。照片按标记的人脸区域显示遮挡，海报和完整预览使用相同设置。个人原日记保留姓名及照片。

- **SHR-003-AC01**：Given 日记包含人物姓名及曾用名，When 匿名预览，Then 对外文字与人物信息不暴露这些已知称呼，个人原文不变。
- **SHR-003-AC02**：Given 含人脸区域标记的照片，When 匿名海报或全文预览显示照片，Then 对应区域被遮挡；更改预览尺寸后遮挡仍对齐该区域。
- **SHR-003-AC03**：Given 同时选择匿名与部分段落，When 预览，Then 选段过滤和匿名处理同时生效。

依据：[匿名文本处理](../../../../src/store/diary-domain.ts)、[面容遮挡组件](../../../../src/components/diary/photo.tsx)、[隐私文案](../../../../src/constants/privacy-options.ts)。待确认：Q-010、Q-013。验收不据此推断真实照片的人脸检测准确率或完整身份不可识别保证。

## SHR-004 分享海报与预览

证据：海报、全文预览、二维码面板为 **交互已表达**；二维码外观为 **展示已表达**，真实可访问链接待 Q-014 定义。

前置与流程：已保存日记 → 分享页 → 查看海报 → 展开预览 → 查看允许内容的图文；可打开/关闭二维码面板。海报展示标题、照片或无图内容、摘要、日期/地点与匿名提示。预览始终采用公开范围处理后的内容。

- **SHR-004-AC01**：Given 有效日记及公开设置，When 打开海报和预览，Then 显示对应作品且遵循 SHR-002/003；关闭预览回到原分享页。
- **SHR-004-AC02**：Given 无效日记，When 打开分享页，Then 显示空态，不回退展示另一篇作品。

原型核验说明：当前二维码是无真实链接的装饰面板。真实扫码阅读不作为已明确的业务验收；若纳入开发，先按 Q-014 定义链接、权限、有效期与撤回。

依据：[分享页](../../../../app/share/result.tsx)。待确认：Q-009、Q-014。

## SHR-005 平台分享、长图与 PDF

证据：渠道选择、拦截、反馈、行为记录为 **交互已表达**；实际系统文件与第三方交付仅 **展示已表达**。

业务流程：从分享页选择朋友圈、小红书或 X，或保存长图、导出 PDF → 接收结果反馈。私密作品可预览、保存和导出，但平台分享被拦截并引导设置范围。导出与平台分享记录分开且渠道去重。

当前渠道以页面按钮为范围；类型里存在的微信、微博等值不能自动当成已开放入口。长图、海报与全文导出的内容范围、版式及真实成功标准尚待确认。

以下文件交付与渠道交付 AC 按用户“假定能力真实存在”的口径描述业务目标，当前未执行真实集成验收；文件规格、平台回调及记录时机由 Q-014 确认。

- **SHR-005-AC01**：Given 私密日记，When 点击外部平台渠道，Then 拦截并提供调整范围入口，不新增平台分享记录。
- **SHR-005-AC02**：Given 可导出的日记，When 保存长图或导出 PDF 成功，Then 得到实际可打开的对应文件，内容遵循已确定的导出范围及匿名设置，原日记不被修改。私密作品允许本地导出。
- **SHR-005-AC03**：Given 非私密日记，When 选择已表达的平台渠道，Then 系统准备符合公开范围及匿名设置的内容并发起该渠道的分享交付；仅准备预览不等于已发送或他人已收到。
- **SHR-005-AC04**：Given 已达到正式约定的分享/导出记录事件，When 读取行为记录，Then 平台分享与导出记录分别管理，同一渠道不产生重复标记。事件及成功/取消/失败的定义由 Q-014 确认。

原型核验说明：当前动作只准备预览、记录演示行为并反馈，未写入相册/文件或向平台发送。E14 只证明拦截和记录分离，不能证明 AC02/03 的真实交付。

依据：[渠道与反馈](../../../../app/share/result.tsx)、[分享/导出记录](../../../../src/store/use-app-store.ts)。待确认：Q-013、Q-014。
