# 日记与回忆管理

范围：已保存日记的阅读、编辑、图片引用与更换、草稿保存/放弃、回忆检索和月度装订。日记详情存在继续编辑和分享能力，但常规详情入口目前没有连接到编辑/分享菜单，入口衔接见 Q-009。

## 用户路径

创作保存后进入日记详情；从回忆页或月度合集可重新阅读。进入编辑草稿后修改文字、图片引用或排版师，保存后更新原日记，放弃则保留原日记。用户也可按月份、日期或文字搜索回忆，并从月度装订查看某月日记及导出合集。

## 功能规格

### DIA-001 日记阅读

**证据状态：**【交互已表达】打开已保存日记、阅读详情、从详情进入公开范围；继续编辑入口【展示已表达】但未由详情常规入口连通。

**业务目标：**让用户查看已保存日记的图文、地点、日期、人物相关文字及排版内容。

**前置与触发：**用户从首页、回忆列表、月度合集或完成页打开一个已保存日记。

**流程结果：**

1. 按已保存内容展示封面、标题、地点/日期、正文、关联照片和引用句。
2. 根据日记所选排版师呈现对应页面风格。
3. 提供记忆锚点相关入口；顶部“更多”当前打开公开范围设置，完成后回到详情。
4. 日记 ID 不存在时显示未找到日记的空状态。

**规则与异常：**

- 详情反映已保存版本；编辑中的未保存改动不应被当作已保存内容。
- 详情“更多”不等于已连接“继续编辑/分享”菜单。独立菜单页含编辑、公开范围和分享动作，但当前未发现详情或其他常规页面通往该菜单；Q-009 确认应有的入口。
- 公开范围设置由 SHR-001 规格定义；锚点阅读与纠正由 GRW 模块定义。

**验收条件：**

- **DIA-001-AC01：**打开有效日记时，页面展示该日记已保存的标题、地点/日期、正文、引用句及其有效照片。
- **DIA-001-AC02：**不同排版师选择对应的详情视觉布局，内容仍属于同一日记。
- **DIA-001-AC03：**无效日记 ID 显示找不到日记的空状态，并提供返回首页的路径。
- **DIA-001-AC04：**点击详情顶部“更多”进入公开范围设置，完成后回到详情；不将此动作验收为分享或编辑入口。
- **DIA-001-AC05：**记忆锚点入口可进入锚点页面；具体锚点行为按 GRW-003/004 验收。

**源码证据：**[详情页](../../../../app/diary/[id]/index.tsx#L11)、[图文详情布局](../../../../src/components/diary/diary-paper.tsx#L11)、[公开范围入口](../../../../app/diary/[id]/index.tsx#L18)、[独立更多操作菜单](../../../../app/modal/more-actions.tsx#L6)。

**待确认问题：**Q-009 详情继续编辑/分享的正常入口；Q-001 已保存内容留存；公开内容与详情展示范围见 SHR-001/002。

### DIA-002 内容编辑与局部重写

**证据状态：**【交互已表达】标题、正文/引用句编辑与重写当前段落；从详情进入编辑的常规入口尚未连接。

**业务目标：**让用户在生成后修订日记文字，并对选定段落重新生成候选内容。

**前置与触发：**有效已保存日记进入编辑草稿，或新建日记生成完成进入编辑。

**流程结果：**

1. 用户编辑标题或正文/引用句，修改仅先写入编辑草稿。
2. 用户聚焦一个正文/引用段落后选择重写本段，当前段落内容被替换，其他内容块不因该操作被直接替换。
3. 用户选择保存或放弃；数据结果按 DIA-005。

**规则与异常：**

- 重写作用于当前选中的一个正文/引用块，不对独立图片块重写；编辑输入不自动修订其他段落。
- 重写质量、生成失败/超时/重试、重生成覆盖策略和文字长度边界待确认；不以固定示例文字逐字验收。
- 既有日记继续编辑入口待 Q-009 衔接；现有编辑页具备交互不代表详情主路径已连通。

**验收条件：**

- **DIA-002-AC01：**编辑标题后，草稿显示新标题，已保存日记在提交前保持原值。
- **DIA-002-AC02：**编辑一个正文或引用段落后，仅对应草稿内容块发生变化。
- **DIA-002-AC03：**对当前选中正文/引用段落触发重写后，该块得到一份可继续编辑的替换文本；其他块保持不变。
- **DIA-002-AC04：**未选中可重写段落或目标日记不存在时，不产生内容变更，并按当前页面呈现无效/空状态。
- **DIA-002-AC05：**通过编辑保存或放弃后的结果分别符合 DIA-005；重写错误和质量门槛在 Q-002 明确前不设固定预期。

**源码证据：**[编辑页面](../../../../app/diary/[id]/edit.tsx#L12)、[文字块更新](../../../../src/store/use-app-store.ts#L122)、[重写当前块](../../../../src/store/use-app-store.ts#L143)、[编辑草稿创建](../../../../src/store/use-app-store.ts#L80)。

**待确认问题：**Q-002 重写质量、时效及异常；Q-003 标题/正文输入边界；Q-008 重生成是否覆盖手动编辑；Q-009 编辑入口；Q-001 草稿留存。

### DIA-003 照片引用与整篇照片更换

**证据状态：**【交互已表达】整篇照片替换、为段落引用照片、更新引用关联；不同来源照片的有效性/上限规则待定义。

**业务目标：**让用户调整日记照片集合，并将适合的照片关联到指定正文或引用段落。

**前置与触发：**打开日记编辑草稿；整篇更换从照片选择页进入，段落引用从相应内容块的图片入口进入。

**流程结果：**

1. 整篇更换照片后，草稿封面、人物照片关联、段落引用和独立图片块只引用当前照片集合中的有效照片。
2. 用户为正文/引用段选择照片后，照片加入整篇集合并关联至指定内容块。
3. 替换段落引用时，段落关联照片和其对应独立图片块一起更新；保存或放弃按 DIA-005。

**规则与异常：**

- 照片 ID 去重并过滤无效 ID；不允许内容块、封面、人物或海报指向整篇集合之外的照片。
- 整篇照片选择当前至少 3 张；已有日记更换照片是否应继承此下限、与新建生成要求如何区分，见 Q-008。
- 新建草稿更换整篇照片会使生成结果失效；已有日记编辑更换整篇照片当前保留既有文字并可保存，不要求重新生成。正式规则待 Q-008 确认。
- 当前引用选择展示可用照片集合；段落可引用几张、重复引用如何表示、图片顺序及照片上限待确认。

**验收条件：**

- **DIA-003-AC01：**整篇照片替换后，草稿照片集合与用户确认的选择一致，封面和所有照片引用保持在该集合内。
- **DIA-003-AC02：**为段落引用照片后，所选照片同时存在于整篇集合及目标正文/引用块的关联中。
- **DIA-003-AC03：**替换段落引用照片后，目标块关联更新；关联该段的独立图片块使用新的首张引用照片，清空引用则移除该关联图片块。
- **DIA-003-AC04：**整篇照片被移除后，不再被封面、段落图片块、人物照片或海报照片引用。
- **DIA-003-AC05：**同一照片重复选择不产生重复引用；无效照片 ID 不进入草稿。

**源码证据：**[编辑页照片入口](../../../../app/diary/[id]/edit.tsx#L17)、[整篇照片规范化](../../../../src/store/diary-domain.ts#L45)、[照片选择更新](../../../../src/store/use-app-store.ts#L92)、[段落照片引用更新](../../../../src/store/use-app-store.ts#L127)。

**待确认问题：**Q-003 照片上限与输入边界；Q-008 新建/已有日记换图差异、重新生成要求及保存下限；Q-001 草稿留存。

### DIA-004 更换排版师

**证据状态：**【交互已表达】在已有日记编辑中更换排版师并保留现有内容。

**业务目标：**让用户为现有日记选择另一种视觉和叙事风格，同时保护已编辑内容。

**前置与触发：**已有日记进入编辑，选择“更换排版师”。

**流程结果：**展示可选排版师；选择一位后更新编辑草稿角色并返回编辑页。

**规则与异常：**

- 当前更换模式保留现有文字内容，不因角色改变自动触发重写或覆盖正文。
- 更换角色后详情的最终视觉效果应反映已保存的新角色；样式细节不作为文字内容验收。
- 无效角色选择不修改草稿。创作中的角色选择及其生成影响见 CRE-004/005。

**验收条件：**

- **DIA-004-AC01：**更换排版师页面提供当前开放的角色选择，并展示风格说明。
- **DIA-004-AC02：**选择新角色后返回编辑页，草稿记录该角色，原有标题、正文及照片关联保持不变。
- **DIA-004-AC03：**保存后日记沿用原日记 ID，详情使用所选排版师的展示风格。

**源码证据：**[编辑操作与角色入口](../../../../app/diary/[id]/edit.tsx#L19)、[更换角色保留内容](../../../../app/create/character.tsx#L7)、[角色更新规则](../../../../src/store/use-app-store.ts#L102)、[详情版式](../../../../src/components/diary/diary-paper.tsx#L14)。

**待确认问题：**Q-009 详情继续编辑入口；若正式更换角色需重新生成，则与当前“保留内容”行为的关系需确认（Q-008）。

### DIA-005 草稿保存与放弃

**证据状态：**【交互已表达】新建/已有日记草稿隔离、保存、重复保存保护、退出确认和放弃。

**业务目标：**允许用户在工作副本中修改，并明确决定何时提交或丢弃。

**前置与触发：**新建生成结果或已有日记编辑草稿。

**流程结果：**

1. 新建和编辑均以未提交草稿承载修改；编辑时原日记保持不变。
2. 保存有效新建草稿后创建一篇日记并进入完成页；保存有效编辑草稿后更新原日记并返回详情。
3. 对未保存草稿退出时确认继续编辑或放弃；选择放弃移除该草稿，新建不入列表、编辑恢复原已保存版本。

**规则与异常：**

- 新建草稿须生成完成且照片集合至少 3 张才能保存；编辑草稿必须仍有有效的来源日记。
- 新建创建新日记 ID；编辑沿用原日记 ID。同一草稿重复保存返回相同日记，不重复创建。
- 已保存草稿不再接受修改；重复触发保存不改变已提交对象。
- 当前编辑页对未提交草稿的退出会要求确认；已保存草稿/不存在草稿退出不要求丢弃确认。
- 当前状态不等于跨重启落盘或跨设备恢复；留存和恢复见 Q-001。

**验收条件：**

- **DIA-005-AC01：**新建有效草稿保存后，列表出现一篇新的可阅读日记，且导航到完成页。
- **DIA-005-AC02：**已有日记编辑草稿保存后，更新原日记内容且 ID 不变，导航回该日记详情。
- **DIA-005-AC03：**编辑未保存期间退出并选择继续编辑，草稿保留且不修改已保存日记；选择放弃后草稿移除且原日记保持原值。
- **DIA-005-AC04：**新建未保存草稿放弃后，日记列表不增加作品；其生成结果不作为已保存日记展示。
- **DIA-005-AC05：**同一草稿连续保存不创建重复日记；已保存草稿不能再修改已提交日记。
- **DIA-005-AC06：**生成未完成、照片不足或编辑来源日记已不存在时，保存不创建/更新日记，并提供可继续处理的反馈。

**源码证据：**[编辑保存与退出确认](../../../../app/diary/[id]/edit.tsx#L16)、[草稿保存门槛与提交](../../../../src/store/use-app-store.ts#L162)、[草稿隔离和取消](../../../../src/hooks/use-diary-flow.ts#L6)、[已保存日记集合](../../../../src/store/use-app-store.ts#L65)。

**待确认问题：**Q-001 保存期限、重启恢复和跨设备；Q-008 既有日记换图保存门槛；Q-009 编辑入口是否需接入详情常规路径。

### DIA-006 回忆检索

**证据状态：**【交互已表达】按月/日筛选、日历标记、按标题/摘要/地点搜索及打开日记；日期区间口径存在待确认差异。

**业务目标：**帮助用户按时间或内容检索已保存日记并打开阅读。

**前置与触发：**用户进入回忆页；日记列表可为空。

**流程结果：**

1. 查看回忆月份、周日期条和月份日历；有记录日期显示标记。
2. 选择月份或具体日期筛选列表；输入地点、标题或回忆文字进行搜索。
3. 结果按旅行游记和其他生活感悟分组；选择条目进入详情；无匹配结果显示空态。

**规则与异常：**

- 可选择的月份由已保存日记日期生成，按倒序展示；“全部回忆”不限制月份。
- 搜索范围为日记标题、摘要和地点；不据此推断正文全文搜索。
- 单日记录按日历月份/日期进行筛选。对于跨日旅程，日历可标记旅程覆盖日期，而列表筛选当前依据日记起始日期；两者可能不一致。跨日、跨月归属须由 Q-004 决定，不将当前矛盾冻结为正式业务规则。
- “刚刚写下的回忆”分组目前独立于所选日/月筛选，是否应同步筛选见 Q-004。
- 日期格式和非法日期处理未定义；无匹配时展示空态。

**验收条件：**

- **DIA-006-AC01：**回忆页可打开月份选择器，并能选择某个有日记的月份或全部回忆。
- **DIA-006-AC02：**对单日记录，选中月份后列表展示该月记录，选中日期后展示该日记录；关闭选择器不改变已选筛选。重新选择月份会清除日期筛选，“显示全部”会清除月份和日期筛选。
- **DIA-006-AC03：**按标题、摘要或地点片段搜索时，结果限于匹配日记；无匹配时显示空态。
- **DIA-006-AC04：**日历对有记录日期提供可见标记；跨日旅程中间日期、跨月日期和列表过滤之间的一致验收在 Q-004 关闭后补定。
- **DIA-006-AC05：**选择检索结果打开对应日记详情；“刚刚写下的回忆”是否遵循当前筛选按 Q-004 确认。

**源码证据：**[回忆页月份、搜索与筛选](../../../../app/(tabs)/memories.tsx#L14)、[日历日期点亮](../../../../app/(tabs)/memories.tsx#L40)、[日记日期分组](../../../../src/store/diary-domain.ts#L22)。

**待确认问题：**Q-004 跨日/跨月旅程归属、日历与列表筛选一致性及“刚刚写下”筛选；Q-001 数据留存；Q-005 日记统计不作为回忆条目数量的额外规则。

### DIA-007 月度装订

**证据状态：**【交互已表达】按月查看合集、查看合集内日记并打开详情；【展示已表达】月度导出意图，当前仅提供演示反馈，未完成可交付合集。

**业务目标：**将指定月份的日记整理为可翻阅、可导出的月度回忆合集，使用户能够阅读并保存该月记录。

**前置与触发：**用户从个人成长/回忆入口进入月度装订；有记录时查看月份分册；空数据时显示提示。

**流程结果：**

1. 以月份分册展示可用的月度合集与其中日记数量。
2. 打开某月合集后列出其日记；选择条目打开日记详情。
3. 选择“导出这个月的回忆”后，业务目标是生成可打开的合集交付物，内容包含所选月份归档的日记。

**规则与异常：**

- 月份合集按日记日期分组，按时间倒序呈现；每个日记只归入其日记日期所属的合集。跨日旅程按哪个月归档待 Q-004 决定。
- 空数据时提示先创建日记；无效月份/合集不应展示不存在的日记。
- 导出文件格式、内容范围、封面、选段/隐私处理、合集是否保存及交付位置未定义，见 Q-011。不得以导出成功提示替代可打开、内容正确的合集交付验收。
- 当前原型导出按钮只显示本地演示提示，不写入文件；该提示只能核验按钮反馈，不能证明导出交付已满足。

**验收条件：**

- **DIA-007-AC01：**存在日记时，按月份展示月度分册；分册月份及所含日记与归档结果一致。
- **DIA-007-AC02：**打开分册后仅列出该合集的日记；点击日记进入其详情。
- **DIA-007-AC03：**无日记时显示引导用户先记录日记的空状态，不出现空白或伪造合集。
