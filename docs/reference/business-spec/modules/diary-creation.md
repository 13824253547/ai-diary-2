# AI 日记创作

范围：从相册授权、照片选择到旅行日记生成和同行人物命名。明确开放的创建类型为旅行游记；文中“生成”描述业务目标，不限定 AI 的固定示例文字或真实服务实现。

## 用户路径

首页开始创作 →（尚未授权时）查看并允许照片访问 → 选择至少 3 张照片 → 选择旅行游记模板 → 选择排版师 → 查看生成进度 →（检测到人物时）命名自己和同行者 → 进入日记编辑。用户也可从首页先浏览排版师，再进入创作；角色确认是否应重复由 Q-009 确认。

## 功能规格

### CRE-001 相册授权

**证据状态：**【交互已表达】授权说明、允许/暂不允许操作及创作流程的授权状态；系统相册权限状态与范围尚未定义。

**业务目标：**在用户知情同意后访问照片素材，继续创建日记。

**前置与触发：**用户开始创作且尚未授权照片访问。

**流程结果：**

1. 展示访问相册用途、默认私密说明及权限撤回提示。
2. 选择允许后记录已授权状态并进入照片选择；若原创作草稿仍有效则继续该草稿。
3. 选择暂不允许或关闭时，不授予访问状态，退出本次创作并回到上一页或首页；未保存草稿被放弃。

**规则与异常：**

- 新建日记默认私密。
- “仅读取最近 3 天照片”等说明文案的实际读取范围、系统权限弹窗和受限照片处理均未定义；按 Q-018 确认前不将文案当成权限算法。
- 从系统设置撤回权限、拒绝后再次进入以及系统授权失败的流程待定义。

**验收条件：**

- **CRE-001-AC01：**未授权用户开始创作时，先看到相册访问说明，且不能绕过授权说明直接进入照片选择。
- **CRE-001-AC02：**用户允许访问后，进入照片选择；当前有效创作草稿和已选排版师不因授权步骤丢失。
- **CRE-001-AC03：**用户暂不允许或关闭授权页后，不进入照片选择，未保存的新建草稿被放弃。
- **CRE-001-AC04：**新建日记在用户另行修改公开范围前保持私密。

**源码证据：**[授权页](../../../../app/permission/photos.tsx#L10)、[授权状态与草稿创建](../../../../src/store/use-app-store.ts#L66)、[首页创作入口](../../../../app/(tabs)/home.tsx#L13)。

**待确认问题：**Q-018 系统权限状态、受限照片和“最近 3 天”含义；Q-001 草稿留存与应用重启恢复；Q-009 首次授权、排版师浏览和创作返回衔接。

### CRE-002 照片选择

**证据状态：**【交互已表达】照片多选、选择数量、最低数量校验、继续与取消；设备相册来源和最大选择数待定义。

**业务目标：**让用户选择构成一篇日记的照片，或替换已有日记的整篇照片集合。

**前置与触发：**存在新建草稿或编辑草稿；相册授权通过。新建从首页创作进入，替换从日记编辑进入。

**流程结果：**

1. 浏览照片、选择或取消选择，查看已选数量。
2. 少于 3 张时不可继续；选择至少 3 张后，新建继续选择模板，替换模式返回编辑页。
3. 成功应用后，草稿照片集合与选择结果一致。

**规则与异常：**

- 最少选择 3 张不同且有效的照片；选择集合去重，无效照片 ID 不纳入结果。
- 替换模式也有当前的 3 张下限；它与已有日记保存及历史内容的关系待 Q-008 确认。
- 当前相册分组、照片样本总数、默认选中照片数均为原型展示，不构成相册数量、日期范围或业务配额。
- 最大选择数、空相册、照片缺少时间/地点、有限照片访问及选择顺序规则待确认。

**验收条件：**

- **CRE-002-AC01：**选择 0、1 或 2 张有效照片时，继续按钮不可用，并显示最低数量提示。
- **CRE-002-AC02：**选择 3 张有效照片时，继续按钮可用；新建模式继续到模板，替换模式返回当前编辑草稿。
- **CRE-002-AC03：**重复切换同一照片后，该照片在选择集合中最多出现一次；未选择照片不进入草稿照片集合。
- **CRE-002-AC04：**取消新建照片选择时，可选择继续编辑或放弃草稿；取消替换时返回编辑且不应用未确认的选择。

**源码证据：**[照片选择页](../../../../app/album/select.tsx#L11)、[最低数量和照片去重](../../../../src/store/diary-domain.ts#L3)、[照片集合更新](../../../../src/store/use-app-store.ts#L92)、[照片类型](../../../../src/types/diary.ts#L12)。

**待确认问题：**Q-003 照片上限及缺失元数据处理；Q-008 新建与既有日记替换照片的重生成和保存差异；Q-018 设备相册授权范围；Q-001 草稿留存。

### CRE-003 日记类型

**证据状态：**旅行游记【交互已表达】；工作反思、情绪记录【预告未开放】。

**业务目标：**让用户按写作目的选择日记类型及相应内容模板。

**前置与触发：**照片选择满足最低数量后进入类型/模板选择。

**流程结果：**

1. 展示旅行游记、工作反思、情绪记录及其适用场景。
2. 选择旅行游记后进入排版师选择。
3. 工作反思和情绪记录显示未开放状态，不能进入对应创作流程。已有情绪日记可阅读不代表情绪创作开放。

**规则与异常：**

- 当前仅旅行游记可用于新建；不可用类型的直接选择不应启动生成。
- 类型可选项和各类型的正式模板结构、后续开放时间待定义。

**验收条件：**

- **CRE-003-AC01：**类型页显示旅行游记为可用，用户选择后进入排版师选择。
- **CRE-003-AC02：**工作反思、情绪记录显示未开放且不可选择，不创建对应类型的生成草稿。
- **CRE-003-AC03：**已有情绪类型日记仍可从回忆列表阅读；该行为不开放情绪日记新建入口。

**源码证据：**[类型与模板选项](../../../../src/mocks/creation.ts#L2)、[模板页](../../../../app/create/template.tsx#L9)、[类型约束](../../../../src/store/use-app-store.ts#L205)、[日记类型](../../../../src/types/diary.ts#L1)。

**待确认问题：**未定义工作/情绪类型的开放范围与正式模板；本功能不预设上线日期。

### CRE-004 排版师选择

**证据状态：**【交互已表达】创作中选择排版师，以及从首页进入排版师浏览；排版质量标准待定义。

**业务目标：**让用户为日记选择叙事风格和对应视觉呈现。

**前置与触发：**选择可用的旅行游记类型后进入选择页；首页也提供排版师浏览入口。

**流程结果：**

1. 展示当前可选择的风格和角色说明。
2. 用户选择一位排版师，选择结果应用于当前创作草稿。
3. 创作模式进入生成；首页浏览模式进入照片选择或授权。

**规则与异常：**

- 当前创作选择页展示 3 位排版师；其他示例角色不因此视为该流程可选项。
- 新建草稿的生成内容依据所选风格；具体文风质量不以固定示例文案逐字验收。
- 从首页浏览角色开始时，仍会经过类型页并再次进入角色选择；首次授权时有效草稿会保留角色。用户是否应在流程中重复确认角色属于 Q-009。

**验收条件：**

- **CRE-004-AC01：**创作页展示当前可选的 3 种排版师风格及相应描述。
- **CRE-004-AC02：**选择排版师后，当前草稿记录所选角色，后续生成使用该选择。
- **CRE-004-AC03：**无照片权限时从首页浏览角色并开始创作，授权后所选角色仍关联有效草稿。
- **CRE-004-AC04：**选择无效角色 ID 时，不覆盖草稿当前角色。

**源码证据：**[角色选择页](../../../../app/create/character.tsx#L7)、[角色定义](../../../../src/mocks/characters.ts#L4)、[角色更新与校验](../../../../src/store/use-app-store.ts#L102)、[首页浏览入口](../../../../app/(tabs)/home.tsx#L16)。

**待确认问题：**Q-009 角色浏览、授权及类型选择的衔接；Q-002 风格生成质量与失败/重试；Q-008 更换角色对已编辑正文的影响。

### CRE-005 日记生成生命周期

**证据状态：**【交互已表达】生成进度、阶段提示、生成完成后进入命名或编辑；真实生成质量、时效与异常恢复待定义。

**业务目标：**将用户选定的照片组织为可编辑的旅行日记草稿。

**前置与触发：**有未保存的新建草稿、至少 3 张不同有效照片及有效排版师；选择排版师后开始生成。

**流程结果：**

1. 日记内容进入生成中，生成任务从未开始进入执行中并展示进度。
2. 生成完成后形成标题、摘要、正文/引用句和图片关联，日记内容进入可编辑状态；任务标记完成。
3. 如果有识别到的人物，先进入人物命名；否则直接进入编辑。
4. 生成完成不等于日记已保存；保存见 DIA-005。

**规则与异常：**

- 日记状态为草稿、生成中、可编辑内容；生成任务状态为未开始、执行中、完成。两者不可等同于已保存。
- 少于 3 张有效照片或草稿不存在时不能开始新建生成；重复触发正在执行的同一生成不得建立另一轮。
- 离开生成页会暂停当前未完成轮次；重新进入可开启新轮。过期轮次的进度/完成结果不得覆盖新一轮状态。
- 新建草稿更改整篇照片集合会使已生成内容失效，保存前须重新生成。已有日记编辑更换照片当前不要求重生成；两者是否为正式规则见 Q-008。
- 失败、超时、取消、重试次数、生成时长及用户修改与重生成的覆盖策略未定义；不以固定演示文案或进度时长验收。

**验收条件：**

- **CRE-005-AC01：**满足前置条件时，生成从草稿/未开始进入生成中/执行中，并提供可观察进度。
- **CRE-005-AC02：**本轮成功后生成结果可进入后续命名或编辑，任务进入完成；此时仍未自动创建已保存日记。
- **CRE-005-AC03：**未满足最低照片数时不能开始生成，也不能保存新建日记。
- **CRE-005-AC04：**未完成生成时离开页面，当前轮次停止更新；重新进入后产生的新轮次不被旧轮次结果覆盖。
- **CRE-005-AC05：**新建草稿在生成完成后更换整篇照片，生成结果回到待生成状态，保存前必须完成新一轮；既有日记换图规则按 Q-008 确认。

**源码证据：**[生成页与导航](../../../../app/create/generating.tsx#L13)、[生成状态转换与保存门槛](../../../../src/store/use-app-store.ts#L150)、[生成内容和照片关联](../../../../src/store/diary-domain.ts#L104)、[状态类型](../../../../src/types/diary.ts#L3)。

**待确认问题：**Q-002 质量、时效、失败/超时/取消/重试及覆盖策略；Q-008 新建与编辑换照片、重新生成规则；Q-001 草稿恢复；Q-003 照片上限。

### CRE-006 人物命名

**证据状态：**【交互已表达】查看识别人物、编辑称呼、保存或跳过；跨日记人物记忆尚未表达。

**业务目标：**让用户为照片中自己和同行者标注称呼，使人物信息在当前日记中可辨认。

**前置与触发：**生成完成后，选中照片关联到一个或多个人物；无人物时跳过命名页直达编辑。

**流程结果：**

1. 为当前识别到的每个人展示称呼输入项。
2. 用户修改名字后保存，或选择跳过，继续进入编辑。
3. 命名更新当前草稿的人物信息；当前生成功能已先于命名执行，因此命名不自动重写既有正文。

**规则与异常：**

- 当前输入最多 16 个字符；最终长度、字符计量和空值规则待 Q-003 确认。
- 保存草稿时空的自己称呼回落为“我”，空的同行者称呼回落为“同行人”；跳过不等同于清空人物信息。
- 更改称呼会保留当前草稿人物的旧名和新名作为别名；不能据此推断跨日记人物档案已实现。
- “只需一次命名，以后见面就记得”的跨日记记忆及已有正文是否同步改名待确认。

**验收条件：**

- **CRE-006-AC01：**生成结果有人物时进入命名页；无人物时跳过该页并进入编辑。
- **CRE-006-AC02：**用户可分别修改识别到的人物称呼，输入不得超过原型展示上限；正式边界见 Q-003。
- **CRE-006-AC03：**保存命名后继续进入编辑，当前草稿人物信息反映用户称呼；已生成正文保持原内容。
- **CRE-006-AC04：**跳过命名继续进入编辑，不丢失草稿人物，也不要求跨日记自动复用称呼。
- **CRE-006-AC05：**空称呼保存日记时分别按“我”或“同行人”作为显示回落值。

**源码证据：**[命名页](../../../../app/companion/naming.tsx#L11)、[人物名称更新](../../../../src/store/use-app-store.ts#L111)、[照片人物关联](../../../../src/store/diary-domain.ts#L12)、[保存时称呼回落](../../../../src/store/use-app-store.ts#L168)。

**待确认问题：**Q-003 名称输入边界；Q-010 跨日记人物记忆、识别纠正、重命名和正文同步；Q-001 人物信息留存；Q-002 生成文本质量。
