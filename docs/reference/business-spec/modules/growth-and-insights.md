# 个人空间与成长洞察

版本：FSD v0.1 · 原型能力基线初稿。范围：个人空间、成长树、记忆锚点、锚点纠正、记忆花朵、里程碑及专属洞察报告。月度装订由 DIA-007 描述，不在本模块重复定义。

本文将原型表达的成长记忆视为产品业务能力。【交互已表达】表示可以在原型中完成操作；【展示已表达】表示已有展示意图；【预告未开放】表示入口或文案表达了未来能力。示例统计和固定素材不作为正式业务算法；没有确定的算法保留为待确认问题。

## 用户路径

底部导航「我的」 → 「我的小世界」查看回忆，或「小橘眼中的你」查看成长树 → 标签查看锚点 → 阅读关联日记 / 纠正理解。成长树 → 记忆花朵 → 查看里程碑与解锁进度 → 满足条件后阅读专属洞察报告。

## 功能规格

### GRW-001 个人空间与统计

**证据状态：**【交互已表达】进入回忆、成长记忆和月度装订；【展示已表达】头像、昵称、简介、VIP 标识、通知 / 设置图标及日记积累数量。

**业务目标：**为用户提供个人记录资产的集中入口，并呈现记录积累与成长记忆。

**前置与流程结果：**

1. 用户进入「我的」，看到个人资料和日记积累数量。
2. 点击「我的小世界」进入回忆归档。
3. 点击「小橘眼中的你」进入 GRW-002；月度装订入口进入 DIA-007。

**明确规则与异常：**

- 「我的小世界」展示已积累记录数量，并与 PET-002、成长入口使用同一日记统计来源。
- 原型统计使用示例基线加本次会话新增记录，不能把固定数量或计算方式直接认定为正式统计口径。
- 头像、昵称、简介、VIP 标识及通知 / 设置图标表达资料与身份展示意图；原型没有表达账号编辑、会员购买、通知或设置的操作流程。正式范围由 Q-012 确认。
- 当前成长入口的锚点数和开花进度文案为示例展示，正式统计与成长规则由 Q-005、Q-006 确认。

**验收条件：**

- **GRW-001-AC01：**个人空间显示头像、昵称、简介以及记录积累维度；不将示例昵称、VIP 状态或固定计数作为所有用户的固定断言。
- **GRW-001-AC02：**点击「我的小世界」后进入回忆页；点击「小橘眼中的你」后进入成长树页。
- **GRW-001-AC03：**点击月度装订的「查看全部」或某一本月份书籍后，进入月度装订流程；合集行为按 DIA-007 验收。
- **GRW-001-AC04：**同一数据状态下，个人空间、萌宠页及成长入口展示的日记数量一致。

**源码证据：**[个人空间与入口](../../../../app/(tabs)/profile.tsx#L12)；[成长入口卡片](../../../../src/components/profile/growth-entry-card.tsx#L4)；[统计来源](../../../../src/store/diary-domain.ts#L33)。

**待确认问题：**Q-005 记录数量、照片数量、记录天数及同行者统计口径；Q-012 账号、VIP、通知与设置范围；Q-001 资料和记录的数据归属 / 持久化。

### GRW-002 成长树与标签

**证据状态：**【交互已表达】标签和花朵入口；【展示已表达】成长树、记忆标签、日记 / 锚点概览及成长进度文案。

**业务目标：**把小橘对用户日记的长期理解组织成可探索的主题记忆，提供从主题到具体回忆的路径。

**前置与流程结果：**

1. 用户从个人空间进入「小橘眼中的你」。
2. 用户点击成长树上的主题标签，进入该标签的锚点页 GRW-003。
3. 用户点击花朵、主题花朵文案或成长提示，进入 GRW-005。

**明确规则与异常：**

- 当前原型展示「珍视旧友」「追光的人」「山与海」「深夜食堂」四类主题标签；标签与具体日记的关联由 GRW-003 描述。
- 「人生旷野的寻路者」花朵主题以及花朵图形属于记忆花朵入口。
- 返回操作返回上一页；无可返回页面时进入「我的」。
- 日记统计与其他概览保持一致；锚点计数和「再长若干片叶子会开花」表达成长意图，不定义正式阈值。
- 自动生成标签、叶子增长、花朵产生及标签更新没有可确认的业务算法，见 Q-006、Q-016。

**验收条件：**

- **GRW-002-AC01：**成长树页显示当前原型的四类主题标签；点击任一标签后打开对应分类的锚点页，页面标题反映该标签。
- **GRW-002-AC02：**点击树上的花朵、花朵主题文案或成长提示后进入记忆花朵页。
- **GRW-002-AC03：**页面展示日记 / 记忆锚点两个统计维度与成长提示；该条件只验证展示，不验证自动长叶或开花。
- **GRW-002-AC04：**返回动作在有历史页面时返回上一页，在无历史页面时进入「我的」。

**源码证据：**[成长树页面](../../../../app/profile/insights.tsx#L14)；[标签与花朵交互](../../../../src/components/profile/growth-artwork.tsx#L17)；[标签素材元数据](../../../../src/components/profile/growth-assets.json#L23)。

**待确认问题：**Q-006 标签、叶子、花朵之间的成长算法与进度展示；Q-016 标签 / 锚点提取、日记修改后的更新；Q-005 锚点统计口径。

### GRW-003 锚点阅读与原日记关联

**证据状态：**【交互已表达】按标签打开锚点、阅读关联日记；【展示已表达】从原日记提取的短摘、日记日期、标题及封面。

**业务目标：**让用户看见小橘从日记中记住的内容，并能追溯到原始记录。

**前置与流程结果：**

1. 用户从成长标签或 PET-002 进入锚点页。
2. 页面按标签展示相关锚点卡片；每张卡片关联一篇原日记。
3. 点击卡片打开对应日记；需要纠正时执行 GRW-004。

**明确规则与异常：**

- 锚点展示日记封面、起始日期、标题和短摘，短摘不是整篇日记。
- 有用户保存的纠正时，展示该纠正内容，并标识「已按你的想法更新」；无纠正时展示原型提取的短摘。
- 当前短摘从正文句子选取；「珍视旧友」优先选含同行者姓名的句子。短摘选句及截断实现作为证据，正式语义提取与长度规则由 Q-016、Q-003 确认。
- 原型标签与样例日记关联是固定映射，不能作为正式自动分类规则，也不定义新日记一定产生锚点。
- 未指定标签或标签不存在时，原型回落到「珍视旧友」；最终默认分类规则待 Q-016 确认。
- 关联日记不存在时不显示对应卡片；当前分类没有可用锚点时展示「还没有这个记忆锚点」。

**验收条件：**

- **GRW-003-AC01：**进入存在锚点的标签时，页面标题含当前标签，卡片显示关联日记的日期、标题、封面和短摘。
- **GRW-003-AC02：**点击任一锚点卡片后，打开该卡片关联的原日记。
- **GRW-003-AC03：**已有保存纠正的锚点显示用户纠正文案和更新标识；未纠正的锚点显示提取短摘。
- **GRW-003-AC04：**在该分类所有关联日记均不存在的数据状态下，显示锚点为空的提示，不展示无效卡片。
- **GRW-003-AC05：**未提供标签或提供未知标签的原型入口，回落到「珍视旧友」分类。

**源码证据：**[标签关联与短摘](../../../../app/profile/anchors.tsx#L14)；[分类选择与关联日记](../../../../app/profile/anchors.tsx#L35)；[卡片与空状态](../../../../app/profile/anchors.tsx#L60)。

**待确认问题：**Q-016 锚点提取时机、标签体系、默认分类、一个日记的锚点数量、修改 / 删除原日记后的关联更新；Q-003 短摘长度边界；Q-005 去重与总量统计；Q-001 锚点存储与数据归属。

### GRW-004 锚点纠正

**证据状态：**【交互已表达】打开纠正面板、编辑、保存、取消及更新展示。

**业务目标：**允许用户纠正小橘对一段回忆的理解，使用户对自己的记忆含义保持控制。

**前置与流程结果：**

1. 用户点击锚点卡片的更多动作，打开该锚点的「说说你的理解」面板。
2. 面板以已保存的纠正内容或当前短摘作为初始值。
3. 用户修改后保存，面板关闭，卡片显示新的理解；取消则不保存此次编辑。

**明确规则与异常：**

- 页面底部「它可能看错了？点我纠正」打开当前分类第一条可用锚点的纠正面板。
- 非空内容才能保存；保存前去除首尾空白。
- 原型纠正输入上限为 240 字符，正式字符计量与边界由 Q-003 确认。
- 保存后更新当前标签与关联日记对应的锚点理解，不直接修改原日记正文。
- 同一日记位于不同标签时，当前纠正按标签分别维护；是否需要影响其他标签、小橘聊天或洞察报告由 Q-016 确认。
- 点击取消、遮罩或系统关闭动作关闭面板；无锚点时不显示底部纠正动作。

**验收条件：**

- **GRW-004-AC01：**从某张卡片打开纠正面板后，输入初始值与该卡片当前理解一致；从底部纠正入口打开时，目标为当前分类第一条可用锚点。
- **GRW-004-AC02：**输入空字符串或仅空白时，保存按钮不可提交；输入非空内容可保存。
- **GRW-004-AC03：**保存后面板关闭，目标卡片显示去除首尾空白的纠正文案及更新标识；再次打开面板时以保存内容作为初始值。
- **GRW-004-AC04：**修改后取消或关闭面板，原先显示的理解不变；保存纠正不改变关联日记正文。
- **GRW-004-AC05：**当前分类没有锚点时，不显示底部纠正入口。

**源码证据：**[编辑初始值](../../../../app/profile/anchors.tsx#L43)；[卡片和底部纠正入口](../../../../app/profile/anchors.tsx#L73)；[输入、保存及取消](../../../../app/profile/anchors.tsx#L84)；[纠正状态保存](../../../../src/store/use-app-store.ts#L201)。

**待确认问题：**Q-016 纠正对标签、聊天、洞察报告及后续提取的影响范围，恢复原理解 / 删除纠正和审计规则；Q-003 字符限制及特殊内容边界；Q-001 纠正记录的持久化与数据归属。

### GRW-005 记忆花朵与里程碑

**证据状态：**【交互已表达】查看花朵页、点击报告入口查看解锁条件；【展示已表达】花朵主题、锁定 / 绽放状态、成长里程碑和报告解锁进度。通过业务行为自动获取叶子 / 花朵的完整规则尚未定义。

**业务目标：**用花朵和里程碑呈现用户的记录成长，并说明专属洞察报告的解锁条件。

**前置与流程结果：**

1. 用户从成长树进入记忆花朵页，查看主题、里程碑和解锁进度。
2. 未解锁时点击报告入口，收到条件提示并留在花朵页。
3. 已解锁状态下点击报告入口，进入 GRW-006。

**明确规则与异常：**

- 文案明确表达「集满 3 朵花可解锁专属洞察报告」。
- 原型展示「人生旷野的寻路者」「觉察自我的思考者」「压力迷茫的疗愈者」三类花朵主题；第三朵具有未解锁 / 已绽放两种展示。
- 里程碑展示首次旅行、连续记录 30 天、100 个锚点。名称和目标表达展示意图，未确定是否已达成、如何计算或是否决定花朵解锁。
- 当前示例进度和解锁状态是演示场景，不能据此推断任一用户的初始花朵数量或自动成长算法。
- 未解锁时提示集满 3 朵花的条件；已解锁时进入报告。
- 返回操作在有历史时返回上一页，无历史时进入成长树。

**验收条件：**

- **GRW-005-AC01：**花朵页展示花朵主题、成长里程碑、解锁条件及进度区域；不以固定示例进度断言所有用户的状态。
- **GRW-005-AC02：**在未解锁的原型场景中，第三朵显示未解锁状态，点击报告入口显示解锁条件提示，并留在花朵页。
- **GRW-005-AC03：**在已解锁的原型场景中，第三朵显示已绽放状态，报告入口显示可查看状态，点击后进入报告页。
- **GRW-005-AC04：**锁定与解锁状态的进度展示、按钮语义及报告访问结果一致。

当前基线验收里程碑和进度展示、锁定 / 解锁分支；自动长叶、开花和授予里程碑需 Q-006 确认后补充验收条件。

**源码证据：**[锁定与入口行为](../../../../app/profile/flowers.tsx#L13)；[里程碑与进度](../../../../app/profile/flowers.tsx#L23)；[花朵状态展示](../../../../src/components/profile/growth-artwork.tsx#L14)；[花朵主题](../../../../src/components/profile/growth-assets.json#L121)；[解锁状态定义](../../../../src/store/use-app-store.ts#L26)。

**待确认问题：**Q-006 花朵和叶子的获得条件、主题含义、重复获得、成长进度、里程碑计算和解锁撤销；Q-005 连续天数 / 锚点数量口径；Q-001 成长资产持久化。

### GRW-006 专属洞察报告

**证据状态：**【交互已表达】锁定校验、返回花朵页和已解锁报告阅读；【展示已表达】基于用户记录的洞察标题、来源数量及三类个人洞察。

**业务目标：**在成长条件达成后，把长期记录组织为可阅读的个人洞察，帮助用户回看自己的偏好与特质。

**前置与流程结果：**

1. 用户在已解锁状态下从花朵页进入报告。
2. 报告展示记录来源数量与洞察内容。
3. 未解锁状态直接进入报告时，展示锁定说明，并提供返回花朵页的动作。

**明确规则与异常：**

- 报告页自身校验解锁状态，不能仅依赖入口页拦截。
- 未解锁时展示「再等一朵花盛开」及集满 3 朵记忆花的条件，不展示已解锁报告内容。
- 已解锁时展示「基于你的记录生成」来源说明及内在矛盾、珍视之物、性格特质三类洞察。
- 来源日记数量与共享统计来源一致；报告示例正文只说明洞察呈现方式，不作为每个用户应获得的固定结论。
- 报告以「这不是定义，只是一面镜子」表达辅助自我回看的定位。
- 报告生成时机、更新频率、结果证据、纠正、生成失败及报告历史未形成确定规则，见 Q-002、Q-016。
- 页面「数据仅保存在本地」是数据归属的产品意图，正式存储、同步和删除约束需由 Q-001 确认。

**验收条件：**

- **GRW-006-AC01：**未解锁状态直接打开报告时，显示锁定说明和花朵入口，不显示三类洞察正文。
- **GRW-006-AC02：**点击锁定页的「去看看记忆花朵」后进入花朵页。
- **GRW-006-AC03：**已解锁场景中，显示报告标题、记录来源数量，以及内在矛盾、珍视之物、性格特质三个洞察维度；不以示例结论作为正式 AI 输出断言。
- **GRW-006-AC04：**报告来源数量与同一数据状态下的共享日记统计一致，报告显示辅助回看定位及本地数据意图说明。

**源码证据：**[洞察维度示例](../../../../app/profile/report.tsx#L11)；[解锁校验与锁定提示](../../../../app/profile/report.tsx#L20)；[报告来源与内容](../../../../app/profile/report.tsx#L29)；[定位与数据文案](../../../../app/profile/report.tsx#L58)。

**待确认问题：**Q-002 生成质量、时效、失败 / 重试、来源证据及更新周期；Q-016 锚点纠正与日记变化对报告的影响；Q-005 报告来源数量的统计口径；Q-006 解锁条件计算；Q-001 本地存储、跨设备同步、删除及隐私约束。
