# 明信片

用户目标：将一张风景或素材制作成可分享的回忆卡片。入口：回忆的明信片区、素材预览。关联流程 J-04，素材功能 MAT-001/003/005。

## PCD-001 选择素材与生成明信片

证据：**交互已表达**；独立作品留存尚未定义。

流程：素材库预览任一素材并点击“用于明信片” → 进入独立应用页并预选该素材 → 按“照片 → 贴纸 → 城市印章”逐项完成 → 预览 → 分享或保存。照片必选，贴纸和印章可跳过，跳过会清除对应可选项。步骤、选择摘要与下一步/跳过操作固定在页脚，不随照片列表滚走；页头仅保留标题和返回。切换步骤回到列表顶部，返回上一步保留选择。移除旧的“选择照片后，可再添加一张贴纸和一个已解锁的城市印章。”提示。

城市印章步骤快捷展示最近 6 枚已解锁印章，当前数据按有效已保存日记日期由新到旧排列并去重（不是独立解锁时间）。提供“按地区浏览”，复用虚拟化城市目录；选用已解锁印章后返回原应用页的印章步骤，保留照片、贴纸和位置配置。非快捷六枚中的已选印章额外显示在快捷区，并保持选中；可在此再点一次取消，无需返回目录。未解锁项目仍只能预览。

卡片以照片为主体，固定寄语继续保留；移除照片上的日期/时间水印，仅在照片有有效地点时显示地点标记。城市印章使用照片范围内连续随机的横纵坐标及 -18 至 18 度旋转角，按实际照片宽度换算，为旋转外沿预留边距；有地点标记时将右侧落印映射到标记下方可用范围，避免挤到同一条线。更换照片或选用不同印章（含取消后重新选择、地区目录回传）时重新随机；同素材再点选、换贴纸、切步骤、同一组合预览、返回编辑和导出保持位置，不随重新渲染跳动。旧四落点参数继续兼容。用户选择的贴纸固定在卡片正文区域右下，与印章同时显示。未选择贴纸时不显示默认表情贴纸。保持卡片外框与照片区域，不提供多张贴纸/印章或自由拖拽排版。

- **PCD-001-AC01**：Given 预设卡片列表，When 切换照片，Then 主卡片显示对应照片且生成状态重置。
- **PCD-001-AC02**：Given 从素材库选择一张有效照片及可选贴纸/已解锁城市印章，When 预览明信片，Then 照片、所选贴纸和城市印章按独立布局同时显示；城市印章使用组合中的安全随机位置，照片有效地点可显示，不显示日期/时间水印。缺少贴纸或城市印章不阻断预览。
- **PCD-001-AC03**：Given 已选卡片素材，When 分享或保存触发导出，Then 得到包含当前照片、信息、固定寄语及全部已选装饰的可读卡片结果；历史作品留存规则由 Q-015 确认。
- **PCD-001-AC04**：Given 独立明信片素材应用页中的组合选择，When 同类再次选择或移除可选装饰，Then 同类最多保留一个、重新选择替换旧项；贴纸/城市印章可移除，照片必须保留或替换。
- **PCD-001-AC05**：Given 分步素材应用页，When 下一步、返回或跳过，Then 只显示当前类别，照片必须选择，跳过清除可选项；城市目录选中返回后在快捷预览中可取消，已有照片和贴纸不丢失。

原型核验说明：早期生成只改变页面状态与文案；现已接入临时图片捕获，真实设备图片及输出视觉仍待集成验收。

依据：[卡片输入、切换与生成](../../../../app/postcard/index.tsx)。待确认：Q-001、Q-015。

2026-10-27 局部决议：当前已选真实设备/已生成素材可以直接渲染成临时 PNG 供保存和分享；不新增作品历史。无有效素材、图片未加载或捕获文件不可读时不能交付。页面仍沿用现有明信片卡片视觉，正式分辨率和跨重启留存仍待定。

2026-10-27 组合决议：一张明信片要求一张素材照片，可选一张贴纸和一个已解锁城市印章；三者可同时呈现。用户后续要求将组合选择放入独立页面，而非通用素材库底栏；素材库预览负责携带当前素材进入应用页。卡片固定布局中城市印章位于照片左下、所选贴纸位于正文右下；不选择贴纸时不显示默认表情。2026-10-28 用户要求移除照片日期/时间水印，卡片仅在有效时显示地点标记。系统分享与保存输出当前完整组合。

2026-10-28 随机落印补充决议：原左下固定位置及四落点方案由连续随机坐标和角度取代；换照片、换印章重新随机，单纯预览/导出稳定，不新增拖动或重新随机按钮。位置与实际照片宽度加入捕获输入版本；有印章时须等照片布局完成才允许导出。

## PCD-002 明信片分享与保存

证据：渠道弹层与结果反馈为 **交互已表达**；真实交付为 **展示已表达**。

流程：分享给好友 → 准备当前卡片并打开弹层 → 微信好友、朋友圈或保存图片 → 结果反馈。分享动作会先将卡片标为已生成；关闭弹层不变更选中素材。

- **PCD-002-AC01**：Given 当前卡片，When 点击分享，Then 展示当前卡片对应的渠道选择，即使未提前点击生成也可进入。
- **PCD-002-AC02**：Given 当前已生成卡片，When 选择微信好友或朋友圈，Then 系统将当前卡片结果交给所选分享渠道；When 保存图片成功，Then 得到实际可打开且与当前卡片一致的图片。渠道交付不等于第三方发布或他人收取成功，细则待 Q-014。
- **PCD-002-AC03**：Given 分享弹层，When 取消关闭，Then 保留当前卡片和素材选择。

原型核验说明：早期渠道动作只有演示反馈；现已接入系统分享与相册保存，真实第三方接收和相册独立打开仍待设备验收。

依据：[明信片渠道与反馈](../../../../app/postcard/index.tsx)。待确认：Q-013、Q-014、Q-015；匿名/隐私规则是否适用于明信片，需要单独决策。

2026-10-27 局部决议：用户明确选择通过系统分享面板分享当前明信片 PNG，由系统列出可接收图片的已安装应用（含支持时的小红书、X）；不承诺指定平台入口或第三方发布成功。用户主动分享时允许私密或匿名日记来源的原图明信片，不额外遮挡；保存只请求相册写入权限。取消分享保持当前素材不变，不记录分享成功；平台扩展可用性、正式输出规格仍需设备验收。
