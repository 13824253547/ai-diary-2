# 明信片

用户目标：将一张风景或素材制作成可分享的回忆卡片。入口：回忆的明信片区、素材预览。关联流程 J-04，素材功能 MAT-001/003/005。

## PCD-001 选择素材与生成明信片

证据：**交互已表达**；独立作品留存尚未定义。

流程：素材库预览任一素材并点击“用于明信片” → 进入独立的明信片素材应用页，预选该素材 → 在应用页选择或替换照片、贴纸和已解锁城市印章 → 进入明信片预览 → 分享或保存。卡片页可返回素材应用页继续调整。照片为必需项，没有有效照片时不能进入卡片。

卡片以照片为主体，沿用照片地点/日期标记和固定寄语；城市印章固定叠放于照片区域左下，用户选择的贴纸固定在卡片正文区域右下。未选择贴纸时不显示默认表情贴纸。保持当前卡片外框与照片区域，不提供多张贴纸/印章、拖拽、旋转、缩放或自由排版。城市印章沿用已解锁门槛。

- **PCD-001-AC01**：Given 预设卡片列表，When 切换照片，Then 主卡片显示对应照片且生成状态重置。
- **PCD-001-AC02**：Given 从素材库选择一张有效照片及可选贴纸/已解锁城市印章，When 预览明信片，Then 照片、贴纸和城市印章按固定独立位置同时显示；照片使用自身地点和日期。缺少贴纸或城市印章不阻断预览。
- **PCD-001-AC03**：Given 已选卡片素材，When 分享或保存触发导出，Then 得到包含当前照片、信息、固定寄语及全部已选装饰的可读卡片结果；历史作品留存规则由 Q-015 确认。
- **PCD-001-AC04**：Given 独立明信片素材应用页中的组合选择，When 同类再次选择或移除可选装饰，Then 同类最多保留一个、重新选择替换旧项；贴纸/城市印章可移除，照片必须保留或替换。

原型核验说明：早期生成只改变页面状态与文案；现已接入临时图片捕获，真实设备图片及输出视觉仍待集成验收。

依据：[卡片输入、切换与生成](../../../../app/postcard/index.tsx)。待确认：Q-001、Q-015。

2026-10-27 局部决议：当前已选真实设备/已生成素材可以直接渲染成临时 PNG 供保存和分享；不新增作品历史。无有效素材、图片未加载或捕获文件不可读时不能交付。页面仍沿用现有明信片卡片视觉，正式分辨率和跨重启留存仍待定。

2026-10-27 组合决议：一张明信片要求一张素材照片，可选一张贴纸和一个已解锁城市印章；三者可同时呈现。用户后续要求将组合选择放入独立页面，而非通用素材库底栏；素材库预览负责携带当前素材进入应用页。卡片固定布局中城市印章位于照片左下、所选贴纸位于正文右下；不选择贴纸时不显示默认表情。系统分享与保存输出当前完整组合。

## PCD-002 明信片分享与保存

证据：渠道弹层与结果反馈为 **交互已表达**；真实交付为 **展示已表达**。

流程：分享给好友 → 准备当前卡片并打开弹层 → 微信好友、朋友圈或保存图片 → 结果反馈。分享动作会先将卡片标为已生成；关闭弹层不变更选中素材。

- **PCD-002-AC01**：Given 当前卡片，When 点击分享，Then 展示当前卡片对应的渠道选择，即使未提前点击生成也可进入。
- **PCD-002-AC02**：Given 当前已生成卡片，When 选择微信好友或朋友圈，Then 系统将当前卡片结果交给所选分享渠道；When 保存图片成功，Then 得到实际可打开且与当前卡片一致的图片。渠道交付不等于第三方发布或他人收取成功，细则待 Q-014。
- **PCD-002-AC03**：Given 分享弹层，When 取消关闭，Then 保留当前卡片和素材选择。

原型核验说明：早期渠道动作只有演示反馈；现已接入系统分享与相册保存，真实第三方接收和相册独立打开仍待设备验收。

依据：[明信片渠道与反馈](../../../../app/postcard/index.tsx)。待确认：Q-013、Q-014、Q-015；匿名/隐私规则是否适用于明信片，需要单独决策。

2026-10-27 局部决议：用户明确选择通过系统分享面板分享当前明信片 PNG，由系统列出可接收图片的已安装应用（含支持时的小红书、X）；不承诺指定平台入口或第三方发布成功。用户主动分享时允许私密或匿名日记来源的原图明信片，不额外遮挡；保存只请求相册写入权限。取消分享保持当前素材不变，不记录分享成功；平台扩展可用性、正式输出规格仍需设备验收。
