# 素材与灵感

用户目标：把照片、装饰、写作灵感和未拍摄的画面用于日记或明信片。入口：首页素材区与工具入口、明信片选择素材。关联流程 J-04。

## MAT-001 照片素材添加、搜索与预览

证据：真实设备照片多选、后端磁盘存储和素材删除已有实现；真实设备、部署持久卷及端到端读写仍待验收。首页“我的照片素材”只读取当前设备已同步且登记在素材集合中的图片，最多预览 4 张；未完成同步显示加载状态，服务失败显示独立错误提示，成功但无素材才显示空态，不使用日记照片缓存或示例图补位。

流程：素材库 → 多选设备照片 → 上传到后端素材库；单次上传最多 12 张，素材库总量最多 100 张。每次上传都会创建独立素材条目；同一设备照片可再次选择和上传，不在本地相册标记为已上传，重复条目分别计入总量。搜索日记标题、副标题、地点、摘要、日期、人物信息或正文/引用/图片说明；命中日记后，仅显示该日记引用的素材照片，不读取照片标题、素材地点、GPS/EXIF 或识别照片画面来匹配。未被任何日记引用的照片显示“未生成日记”。日常素材页最多展示 9 张（3 行），点击“展开”进入独立照片墙查看完整结果。删除素材不删除已经保存日记的独立原图副本；搜索无结果显示空态。

AI 配图由服务端生成后直接写入同一个设备隔离素材仓库，不再由客户端重复上传；与设备上传的照片合计纳入每设备 100 张总量，单次 12 张只约束相册多选上传。

- **MAT-001-AC01**：Given 有效照片，When 多次上传同一设备照片，Then 每次成功上传都创建独立素材条目，素材 ID 不同，原设备照片 ID 仅用于来源关联。
- **MAT-001-AC02**：Given 已保存日记引用素材照片，When 搜索日记信息或正文片段，Then 显示命中日记所引用的素材照片；照片自身标题/地点、GPS/EXIF 和画面内容不参与匹配；无匹配显示空态，清空后恢复全部素材。
- **MAT-001-AC03**：Given 素材照片，When 打开/关闭预览，Then 显示所选照片并能返回；使用状态与当前日记照片引用一致。
- **MAT-001-AC04**：Given 设备相册中有可读取照片，When 多选并上传，Then 单次最多上传 12 张，素材库总量最多 100 张，照片原文件及元数据保存至设备隔离的后端磁盘仓库。
- **MAT-001-AC05**：Given 素材照片已被保存日记引用，When 删除素材，Then 素材库条目与原素材文件删除，日记引用的独立原图副本仍可读取。
- **MAT-001-AC06**：Given 素材库照片超过 9 张，When 查看素材页并点击“展开”，Then 素材页只展示前 9 张，独立照片墙展示当前筛选下的完整素材照片集合。
- **MAT-001-AC07**：Given 首页素材区，When 当前设备素材读取成功，Then 只展示已登记的素材照片（最多 4 张）；读取失败与确实无素材需分别提示，不以日记图片缓存或示例图补位。

依据：[素材库](../../../../app/library/index.tsx)、[照片墙](../../../../app/library/wall.tsx)、[日记筛选](../../../../src/services/material-photo-search.ts)、[素材集合](../../../../src/store/use-app-store.ts)、[照片资产仓库](../../../../backend/src/modules/photos/photo-asset.service.ts)。用户于 2026-10-23 确认单次上传最多 12 张、素材库总量最多 100 张、按日记信息/正文匹配并按日记引用筛选、主素材页展示三行并可展开照片墙；后端磁盘存储及被日记引用时复制原文件也已确认。部署持久卷、设备端读写与总体 URI 生命周期仍待验收/确认。

## MAT-002 将照片用于已有日记

证据：**交互已表达**。

前置：选中照片，目标日记存在并有正文块。流程：预览照片 → 用于日记 → 选择目标作品 → 创建或复用编辑草稿 → 将照片设为第一段正文的唯一引用（替换原引用）→ 进入编辑 → 保存后生效。正式产品是否允许选择其它段落仍待确认。

- **MAT-002-AC01**：Given 有正文的目标日记，When 应用照片，Then 进入该日记的编辑草稿，首段引用及整篇照片集合含该照片。
- **MAT-002-AC02**：Given 已应用照片的草稿，When 放弃，Then 已保存日记不变；When 保存，Then 修改写入原日记且沿用原 ID。
- **MAT-002-AC03**：Given 首段已引用同一照片，When 再次应用，Then 引用和整篇照片集合不重复。
- **MAT-002-AC04**：Given 目标已有未保存的编辑草稿，When 将素材照片用于日记，Then 以该照片替换当前草稿首段引用、将其加入整篇照片集合，并保留草稿其它未保存修改；被替换照片仍保留在整篇照片集合。此为 2026-10-20 用户确认的局部规则；真实素材导入/留存及其它目标范围仍见 Q-015。

依据：[应用照片](../../../../app/library/index.tsx)、[段落照片关联](../../../../src/store/use-app-store.ts)。待确认：Q-009、Q-015；无日记、无正文或目标失效的用户反馈还需定义。复用已有草稿时以当前草稿为准；素材替换首段引用的局部行为已按 AC04 实现，真实设备素材链路及其它范围仍待验证。

## MAT-003 贴纸与城市印章

证据：**交互已表达**。

流程：素材库预览照片、贴纸表情或已解锁城市印章 → “用于明信片”打开独立的明信片素材应用页，并预选当前素材 → 在应用页选择或替换照片、贴纸和城市印章 → 进入明信片预览。照片必需；贴纸与城市印章各可选一个，同类别重选时替换原项。三类素材可同时显示在同一张卡片。素材库页面不暂存明信片组合，也不显示组合底栏。当前不支持任意拖拽、旋转或自由排版，也不支持日记装饰编辑。

素材库首页的“城市印章”区只展示已保存且状态为 `ready` 的日记地点可靠匹配并解锁的印章，最多展示 3 枚；没有已解锁印章时显示“暂无城市印章”空态。旁侧“按地区浏览”仍进入完整城市目录，目录预览不等于用户已获得。

明信片分步应用页的印章快捷区显示最近 6 枚（按有效已保存日记日期由新到旧去重），与素材库首页 3 枚上限分开。应用页“按地区浏览”复用地区/城市虚拟化列表；选中已解锁印章后返回原印章步骤，保留其它素材。目录带回且不在快捷六枚中的已选印章额外显示，可直接再次点选取消。普通城市目录入口行为保持不变，未解锁印章不可选用。

日记纸张封面如展示圆印章，印章必须来自该篇日记地点的可靠目录匹配；地点未知、模糊/未核实、同名歧义无法消解或目录无对应城市时不显示印章，不用固定默认城市图案替代。排版师原有无印章版式保持不变。

城市邮戳由共享 SVG 模板绘制，城市名、拉丁字母名、地区标记、编号及印色作为配置传入；新增城市可复用模板，不需要新增整张位图。城市名称按 SVG 安全宽度动态缩放，极长名称在最小字号下仍无法容纳时以省略号收尾，不得溢出印面。上弧展示国家/地区英文名及分区序号，下弧居中展示 `TRAVEL POST`。

全球城市目录按各国家/地区官方城市级行政单位或明确的城市型市政单位收录，不以联合国《World Urbanization Prospects》聚居区直接代表法定城市名录。WUP、GeoNames populated-place、OSM place 标签和地名匹配仅作候选发现或交叉核对，不能单独证明行政类别。每条保留官方行政类别、稳定行政代码或来源实体 ID、名称及来源、上级行政区和产品内序号；外文名优先使用有来源依据的官方名称，无官方外文名时可用明确标记的标准罗马化转写。没有足够证据确认城市级身份或稳定身份的地区/记录列入来源缺口，不猜测、不以 WUP 回填；已核实地区可以先发布。未核实记录不得进入可解锁目录。匹配可信度不是日记到访证据：可发布城市仍须由已保存且状态为 ready 的日记地点与城市名称或经审核别名完整匹配后解锁应用，同名城市须由地点中的国家/地区信息唯一消歧，模糊子串不解锁。产品序号按该国家/地区目录显示名排序，从 01 起编，仅用于展示，不代表官方排名；中文名按拼音或记录的标准罗马化排序。采用 OSM 派生名称时，城市目录数据库按 ODbL-1.0 发布，城市目录页展示 OpenStreetMap 贡献者署名；完整目录来源、许可证、引用和链接保存在目录元数据及项目审计文件中。该许可边界不扩展到 App 源代码。港澳台分别显示为“中国香港 / HONG KONG · CHINA”“中国澳门 / MACAO · CHINA”“中国台湾 / TAIWAN · CHINA”。既有 `stampKyoto`、`stampKamakura`、`stamp` 装饰 ID 必须继续可读取；解锁门禁只限制新应用，不影响已保存明信片解析旧 ID。

**已核实的中国大陆口径**：中国大陆以民政部截至 2025-12-31 的行政区划代码库为单位依据，仅收 4 个直辖市和 293 个地级市，共 297 个；不收县级市、自治州、地区、盟、县、区、镇或街道。中文行政名称和代码取自民政部名录，拉丁字母名是官方中文名称的无声调汉语拼音转写。地区显示名为“中国大陆 / MAINLAND CHINA”，并排在“中国台湾”之前；港澳台标签仍分别为“中国香港”“中国澳门”“中国台湾”。中国大陆目录来源和分类已核实；非大陆地区仍在逐区审计，现有 14,368 条 WUP 记录属于待替换的旧目录数据，不能据此声称符合新的全球行政城市范围。香港和澳门按单一区域展示，不把香港分区或澳门堂区扩成城市。城市页面不展示展开式数据来源说明，仅保留 OSM 要求的贡献者署名；完整来源和许可信息保存在目录元数据及项目审计文件中。

- **MAT-003-AC01**：Given 贴纸或印章素材，When 预览，Then 显示所选素材；When 用于明信片，Then 卡片使用对应装饰。
- **MAT-003-AC02**：Given 装饰预览，When 关闭，Then 返回素材页且不修改已有日记。
- **MAT-003-AC03**：Given 素材库首页，When 已有匹配日记地点时，Then 只显示已解锁的城市印章；When 没有匹配记录时，Then 显示“暂无城市印章”空态且仍可进入按地区浏览目录。
- **MAT-003-AC04**：Given 日记纸张的邮戳展示版式，When 地点能唯一可靠匹配目录城市时，Then 显示对应城市邮戳；When 地点未知或无法匹配时，Then 隐藏邮戳，不显示默认城市替代图案。
- **MAT-003-AC05**：Given 独立明信片素材应用页，When 选择照片、贴纸和已解锁城市印章，Then 三者可以同时用于卡片；照片必需，每类最多一个，同类别重新选择替换当前项，重复点选已选装饰可移除。

依据：[装饰与预览](../../../../app/library/index.tsx)、[明信片装饰](../../../../app/postcard/index.tsx)。待确认：Q-015。

## MAT-004 灵感卡与陪伴联动

证据：**交互已表达**。

流程：选择灵感问题 → 输入回答 → 和小橘聊聊 → 仅将回答作为用户消息发送至陪伴对话；灵感问题只作为页面引导，不拼入消息。空白回答不可提交。这里没有独立“灵感作品保存”或自动生成日记的规则。

- **MAT-004-AC01**：Given 灵感卡，When 打开，Then 显示对应问题；回答为空白时提交不可用。
- **MAT-004-AC02**：Given 非空回答，When 提交，Then 转入萌宠页，用户消息仅包含回答，不包含灵感问题，并获得对应回复。

依据：[灵感卡提交](../../../../app/library/index.tsx)、[对话状态](../../../../src/store/use-app-store.ts)。待确认：Q-001、Q-002、Q-003。

## MAT-005 AI 补图

证据：输入、生成动作、加入素材和预览为 **交互已表达**；真实生成质量与时效待定义。

流程：描述想留下的画面 → 生成配图 → 新配图加入素材并打开预览 → 可保存到相册、直接用于明信片，或点击“生成日记”进入日记照片选择页。生成日记入口创建新草稿、直接打开素材库并预选当前配图；用户仍可继续选择其它设备照片或素材，且至少选择 3 张后才能继续。该入口不恢复旧式“用于日记”菜单，也不跳过照片选择和最低数量校验。描述为空白时不能生成；生成中按钮不可重复使用。配图依据描述的效果、失败重试、费用与数量待确认。

配图成功以服务端保存真实图片并写入素材记录为准；满额时在调用付费模型前拒绝，入库仍由设备配额事务复核并发。每次生成计入同一素材库总量，不另占一次“上传”条目；具体费用、其它次数/质量规则仍按 Q-002 确认。

- **MAT-005-AC01**：Given 配图面板，When 描述为空白，Then 生成不可用；非空时允许提交。
- **MAT-005-AC02**：Given 有效描述，When 生成完成，Then 得到写实摄影风格、可预览的配图资产，配图出现在素材集合；结果预览提供“保存到相册”“用于明信片”和“生成日记”按钮。“用于明信片”将同一配图 ID 传入明信片页；“生成日记”创建新草稿、直接进入素材库照片选择页并预选当前配图，仍执行至少 3 张校验；不显示“更多操作”或旧式“用于日记”操作。除写实摄影风格外，与描述匹配的其它质量标准由 Q-002 确认。
- **MAT-005-AC03**：Given 配图请求处于生成状态，When 再次触发，Then 不重复提交。这是异步业务目标初稿；原型同步完成，没有可持续操作的等待状态，需在 Q-002 确认后执行验证。

依据：[配图输入与结果](../../../../app/library/index.tsx)、[AI 配图契约](../../delivery/contracts/ai-image-generation-v1.md)。2026-10-27 用户确认移除 AI 配图预览中的“更多操作”和旧式“用于日记”操作；后续要求在底部操作中直接提供“用于明信片”，并新增独立“生成日记”按钮，进入照片选择页的素材库来源并预选当前配图。该入口遵循 CRE-002 的照片选择及最低数量规则。写实摄影画风为已确认规则；质量门槛、Q-003、Q-015 仍待确认。当前固定示例图片不是未来 AI 的逐像素预期结果。
