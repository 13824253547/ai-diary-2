# 素材与灵感

用户目标：把照片、装饰、写作灵感和未拍摄的画面用于日记或明信片。入口：首页素材区与工具入口、明信片选择素材。关联流程 J-04。

## MAT-001 照片素材添加、搜索与预览

证据：**交互已表达**；真实设备上传机制待定义。

流程：素材库 → 添加照片 → 加入素材集合；按照片标题/地点搜索 → 预览。已在素材集合中的照片再次添加不产生重复条目；未被任何日记引用的照片显示“未生成日记”。搜索无结果显示空态。

- **MAT-001-AC01**：Given 有效照片，When 添加后再添加同一照片，Then 素材集合仅有一个对应条目。
- **MAT-001-AC02**：Given 素材库有照片，When 搜索标题或地点片段，Then 只显示匹配素材；无匹配显示空态。
- **MAT-001-AC03**：Given 素材照片，When 打开/关闭预览，Then 显示所选照片并能返回；使用状态与当前日记照片引用一致。

依据：[素材库](../../../../app/library/index.tsx)、[素材集合](../../../../src/store/use-app-store.ts)。待确认：Q-001、Q-003、Q-015。示例照片总数不是上传容量限制。

## MAT-002 将照片用于已有日记

证据：**交互已表达**。

前置：选中照片，目标日记存在并有正文块。流程：预览照片 → 用于日记 → 选择目标作品 → 创建或复用编辑草稿 → 将照片加入第一段正文引用 → 进入编辑 → 保存后生效。原型以首段为添加位置，正式产品是否允许选择段落待确认。

- **MAT-002-AC01**：Given 有正文的目标日记，When 应用照片，Then 进入该日记的编辑草稿，首段引用及整篇照片集合含该照片。
- **MAT-002-AC02**：Given 已应用照片的草稿，When 放弃，Then 已保存日记不变；When 保存，Then 修改写入原日记且沿用原 ID。
- **MAT-002-AC03**：Given 首段已引用同一照片，When 再次应用，Then 引用和整篇照片集合不重复。
- **MAT-002-AC04**：Given 目标已有未保存的编辑草稿，When 将素材照片追加到日记，Then 保留草稿已有引用并追加新照片，不覆盖此前修改。这是“追加素材”的业务目标初稿；当前原型差异见 Q-015，需确认后纳入正式验收。

依据：[应用照片](../../../../app/library/index.tsx)、[段落照片关联](../../../../src/store/use-app-store.ts)。待确认：Q-009、Q-015；无日记、无正文或目标失效的用户反馈还需定义。复用已有草稿时，当前应用动作从已保存正文读取旧引用，可能覆盖尚未保存的照片引用，AC04 尚未由原型满足。

## MAT-003 贴纸与城市印章

证据：**交互已表达**。

流程：素材库 → 预览贴纸表情或城市印章 → 用于明信片 → 卡片显示对应装饰。当前表达的是明信片装饰应用，未表达任意拖拽、旋转、删除或日记装饰编辑。

- **MAT-003-AC01**：Given 贴纸或印章素材，When 预览，Then 显示所选素材；When 用于明信片，Then 卡片使用对应装饰。
- **MAT-003-AC02**：Given 装饰预览，When 关闭，Then 返回素材页且不修改已有日记。

依据：[装饰与预览](../../../../app/library/index.tsx)、[明信片装饰](../../../../app/postcard/index.tsx)。待确认：Q-015。

## MAT-004 灵感卡与陪伴联动

证据：**交互已表达**。

流程：选择灵感问题 → 输入回答 → 和小橘聊聊 → 问题与回答组成一条消息进入陪伴对话。空白回答不可提交。这里没有独立“灵感作品保存”或自动生成日记的规则。

- **MAT-004-AC01**：Given 灵感卡，When 打开，Then 显示对应问题；回答为空白时提交不可用。
- **MAT-004-AC02**：Given 非空回答，When 提交，Then 转入萌宠页，对话包含该问题与回答及对应回复。

依据：[灵感卡提交](../../../../app/library/index.tsx)、[对话状态](../../../../src/store/use-app-store.ts)。待确认：Q-001、Q-002、Q-003。

## MAT-005 AI 补图

证据：输入、生成动作、加入素材和预览为 **交互已表达**；真实生成质量与时效待定义。

流程：描述想留下的画面 → 生成配图 → 新配图加入素材并打开预览 → 可用于日记或明信片。描述为空白时不能生成；生成中按钮不可重复使用。配图依据描述的效果、失败重试、费用与数量待确认。

- **MAT-005-AC01**：Given 配图面板，When 描述为空白，Then 生成不可用；非空时允许提交。
- **MAT-005-AC02**：Given 有效描述，When 生成完成，Then 得到可预览、可引用的配图资产，配图出现在素材集合并提供用于日记/明信片入口。与描述匹配的质量标准由 Q-002 确认。
- **MAT-005-AC03**：Given 配图请求处于生成状态，When 再次触发，Then 不重复提交。这是异步业务目标初稿；原型同步完成，没有可持续操作的等待状态，需在 Q-002 确认后执行验证。

依据：[配图输入与结果](../../../../app/library/index.tsx)。待确认：Q-002、Q-003、Q-015。当前固定示例图片不是未来 AI 的逐像素预期结果。
