# 素材与灵感

用户目标：把照片、装饰、写作灵感和未拍摄的画面用于日记或明信片。入口：首页素材区与工具入口、明信片选择素材。关联流程 J-04。

## MAT-001 照片素材添加、搜索与预览

证据：真实设备照片多选、后端磁盘存储和素材删除已有实现；真实设备、部署持久卷及端到端读写仍待验收。

流程：素材库 → 多选设备照片 → 上传到后端素材库；单次上传最多 12 张，素材库总量最多 100 张。每次上传都会创建独立素材条目；同一设备照片可再次选择和上传，不在本地相册标记为已上传，重复条目分别计入总量。搜索日记标题、副标题、地点、摘要、日期、人物信息或正文/引用/图片说明；命中日记后，仅显示该日记引用的素材照片，不读取照片标题、素材地点、GPS/EXIF 或识别照片画面来匹配。未被任何日记引用的照片显示“未生成日记”。日常素材页最多展示 9 张（3 行），点击“展开”进入独立照片墙查看完整结果。删除素材不删除已经保存日记的独立原图副本；搜索无结果显示空态。

- **MAT-001-AC01**：Given 有效照片，When 多次上传同一设备照片，Then 每次成功上传都创建独立素材条目，素材 ID 不同，原设备照片 ID 仅用于来源关联。
- **MAT-001-AC02**：Given 已保存日记引用素材照片，When 搜索日记信息或正文片段，Then 显示命中日记所引用的素材照片；照片自身标题/地点、GPS/EXIF 和画面内容不参与匹配；无匹配显示空态，清空后恢复全部素材。
- **MAT-001-AC03**：Given 素材照片，When 打开/关闭预览，Then 显示所选照片并能返回；使用状态与当前日记照片引用一致。
- **MAT-001-AC04**：Given 设备相册中有可读取照片，When 多选并上传，Then 单次最多上传 12 张，素材库总量最多 100 张，照片原文件及元数据保存至设备隔离的后端磁盘仓库。
- **MAT-001-AC05**：Given 素材照片已被保存日记引用，When 删除素材，Then 素材库条目与原素材文件删除，日记引用的独立原图副本仍可读取。
- **MAT-001-AC06**：Given 素材库照片超过 9 张，When 查看素材页并点击“展开”，Then 素材页只展示前 9 张，独立照片墙展示当前筛选下的完整素材照片集合。

依据：[素材库](../../../../app/library/index.tsx)、[照片墙](../../../../app/library/wall.tsx)、[日记筛选](../../../../src/services/material-photo-search.ts)、[素材集合](../../../../src/store/use-app-store.ts)、[照片资产仓库](../../../../backend/src/modules/photos/photo-asset.service.ts)。用户于 2026-10-23 确认单次上传最多 12 张、素材库总量最多 100 张、按日记信息/正文匹配并按日记引用筛选、主素材页展示三行并可展开照片墙；后端磁盘存储及被日记引用时复制原文件也已确认。部署持久卷、设备端读写与总体 URI 生命周期仍待验收/确认。

## MAT-002 将照片用于已有日记

证据：**交互已表达**。

前置：选中照片，目标日记存在并有正文块。流程：预览照片 → 用于日记 → 选择目标作品 → 创建或复用编辑草稿 → 将照片设为第一段正文的唯一引用（替换原引用）→ 进入编辑 → 保存后生效。正式产品是否允许选择其它段落仍待确认。

- **MAT-002-AC01**：Given 有正文的目标日记，When 应用照片，Then 进入该日记的编辑草稿，首段引用及整篇照片集合含该照片。
- **MAT-002-AC02**：Given 已应用照片的草稿，When 放弃，Then 已保存日记不变；When 保存，Then 修改写入原日记且沿用原 ID。
- **MAT-002-AC03**：Given 首段已引用同一照片，When 再次应用，Then 引用和整篇照片集合不重复。
- **MAT-002-AC04**：Given 目标已有未保存的编辑草稿，When 将素材照片用于日记，Then 以该照片替换当前草稿首段引用、将其加入整篇照片集合，并保留草稿其它未保存修改；被替换照片仍保留在整篇照片集合。此为 2026-10-20 用户确认的局部规则；真实素材导入/留存及其它目标范围仍见 Q-015。

依据：[应用照片](../../../../app/library/index.tsx)、[段落照片关联](../../../../src/store/use-app-store.ts)。待确认：Q-009、Q-015；无日记、无正文或目标失效的用户反馈还需定义。复用已有草稿时以当前草稿为准；素材替换首段引用的局部行为已按 AC04 实现，真实设备素材链路及其它范围仍待验证。

## MAT-003 贴纸与城市印章

证据：**交互已表达**。

流程：素材库 → 预览贴纸表情或城市印章 → 用于明信片 → 卡片显示对应装饰。当前表达的是明信片装饰应用，未表达任意拖拽、旋转、删除或日记装饰编辑。

城市邮戳由共享 SVG 模板绘制，城市名、拉丁字母名、地区标记、编号及印色作为配置传入；新增城市可复用模板，不需要新增整张位图。城市名称按 SVG 安全宽度动态缩放，极长名称在最小字号下仍无法容纳时以省略号收尾，不得溢出印面。上弧展示国家/地区英文名及分区序号，下弧居中展示 `TRAVEL POST`。

城市目录按联合国《World Urbanization Prospects 2025》Cities table F21 收录；该口径代表表内城市实体，并不声称覆盖所有城镇或聚居点。每个城市显示中英文名、国家/地区和产品内序号；序号按该国家/地区内中文名拼音排序，从 01 起编，仅用于展示，不代表官方排名。中文名优先采用 GeoNames 中文别名或 UNGEGN 无歧义匹配；其次可采用 Wikidata 中按 GeoNames 稳定编号关联且唯一的中文标签，或 Wikidata 英文主标签/别名与 WUP 英文名完全一致且距 WUP 中心点最近并且唯一（50 公里内）的中文标签；也可采用 OSM `city`/`town` 中英文标签的精确名称及唯一最近点匹配（50 公里内）。标签冲突或城市实体无法可靠匹配时必须列入人工核对，不得猜名或以英文补位。采用 OSM 派生名称时，城市目录数据库按 ODbL-1.0 发布，城市目录页展示 OpenStreetMap 贡献者署名；同时提供完整目录来源、许可证、引用和链接。该许可边界不扩展到 App 源代码。素材库可按国家/地区浏览和预览，但城市印章仅在已保存且状态为 ready 的日记地点与城市中文名、英文名或经审核别名完整匹配后解锁应用；同名城市须由地点中的国家/地区信息唯一消歧，模糊子串不解锁。港澳台分别显示为“中国香港 / HONG KONG · CHINA”“中国澳门 / MACAO · CHINA”“中国台湾 / TAIWAN · CHINA”。既有 `stampKyoto`、`stampKamakura`、`stamp` 装饰 ID 必须继续可读取；解锁门禁只限制新应用，不影响已保存明信片解析旧 ID。

- **MAT-003-AC01**：Given 贴纸或印章素材，When 预览，Then 显示所选素材；When 用于明信片，Then 卡片使用对应装饰。
- **MAT-003-AC02**：Given 装饰预览，When 关闭，Then 返回素材页且不修改已有日记。

依据：[装饰与预览](../../../../app/library/index.tsx)、[明信片装饰](../../../../app/postcard/index.tsx)。待确认：Q-015。

## MAT-004 灵感卡与陪伴联动

证据：**交互已表达**。

流程：选择灵感问题 → 输入回答 → 和小橘聊聊 → 仅将回答作为用户消息发送至陪伴对话；灵感问题只作为页面引导，不拼入消息。空白回答不可提交。这里没有独立“灵感作品保存”或自动生成日记的规则。

- **MAT-004-AC01**：Given 灵感卡，When 打开，Then 显示对应问题；回答为空白时提交不可用。
- **MAT-004-AC02**：Given 非空回答，When 提交，Then 转入萌宠页，用户消息仅包含回答，不包含灵感问题，并获得对应回复。

依据：[灵感卡提交](../../../../app/library/index.tsx)、[对话状态](../../../../src/store/use-app-store.ts)。待确认：Q-001、Q-002、Q-003。

## MAT-005 AI 补图

证据：输入、生成动作、加入素材和预览为 **交互已表达**；真实生成质量与时效待定义。

流程：描述想留下的画面 → 生成配图 → 新配图加入素材并打开预览 → 可用于日记或明信片。描述为空白时不能生成；生成中按钮不可重复使用。配图依据描述的效果、失败重试、费用与数量待确认。

- **MAT-005-AC01**：Given 配图面板，When 描述为空白，Then 生成不可用；非空时允许提交。
- **MAT-005-AC02**：Given 有效描述，When 生成完成，Then 得到写实摄影风格、可预览且可引用的配图资产，配图出现在素材集合；结果预览以“保存到相册”为显式操作，“用于日记”和“用于明信片”收纳在溢出菜单。除写实摄影风格外，与描述匹配的其它质量标准由 Q-002 确认。
- **MAT-005-AC03**：Given 配图请求处于生成状态，When 再次触发，Then 不重复提交。这是异步业务目标初稿；原型同步完成，没有可持续操作的等待状态，需在 Q-002 确认后执行验证。

依据：[配图输入与结果](../../../../app/library/index.tsx)、[AI 配图契约](../../delivery/contracts/ai-image-generation-v1.md)。写实摄影画风及预览操作入口为用户局部确认规则；质量门槛、Q-003、Q-015 仍待确认。当前固定示例图片不是未来 AI 的逐像素预期结果。
