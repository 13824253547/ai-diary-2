# 发现内容

版本：FSD v0.2 · 发现列表接入公开日记快照。

本文将原型表达的故事内容视为可浏览的业务内容。【交互已表达】表示可以在原型中完成操作；【展示已表达】表示已有展示意图；【预告未开放】表示入口或文案表达了未来能力。示例作者、地点、故事数量和基础点赞数不作为正式业务规则。

## 用户路径

底部导航「发现」 → 默认查看最新 / 切换同城 → 可选关键词搜索 → 打开故事 → 阅读已公开选段 → 点赞或取消点赞 → 返回列表查看同步结果。

## 功能规格

### DSC-001 发现分类浏览与搜索

**证据状态：**【交互已表达】分类切换、搜索输入、结果筛选和故事入口；【展示已表达】双列内容卡片、封面、标题、作者与点赞信息。

**业务目标：**让用户浏览其他人的旅途故事，并按分类或关键词找到感兴趣的内容。

**前置与流程结果：**

1. 用户进入发现页，默认查看「最新」分类；「推荐」暂不展示。
2. 用户可切换「同城」，也可点击搜索图标展开或收起搜索输入框。
3. 输入关键词后，列表显示同时满足分类与关键词条件的内容；点击卡片打开 DSC-002。

**明确规则与异常：**

- 当前开放分类为「最新」和「同城」；「推荐」先隐藏，不以最新结果冒充推荐。
- 「最新」按故事日期降序显示；同日期按稳定故事 ID 降序。
- 用户在公开范围页完成非私密设置后，所选正文/引用及其关联照片形成或更新发现故事快照；改回私密时撤下故事并立即停止公开读取。编辑保存仅刷新同一作品对应快照，不回填启用前的历史公开日记。
- 发现快照仅保留被选中的正文/引用块、标题、作品地点及与所选段落关联的照片；未选段落不进入发现。暂无独立发布/审核入口。
- 「同城」仅在用户主动打开该分类时请求一次前台位置，并通过 Expo 反向地理编码读取 `city`；不请求后台定位、不保存用户坐标。将当前 `city` 与已公开作品地点规范化后精确匹配；城市反查失败、地点未知或名称不匹配时不显示该故事。
- 匿名公开会替换可识别的姓名/别名并隐藏地点；若选中内容包含照片，而匿名照片遮挡能力不可用，则公开范围保存失败，不会将未遮挡照片发布到发现。
- 搜索当前匹配标题、地点和作者，以输入文本是否被这些字段包含为条件。正文检索、模糊检索和大小写规则待 Q-007 确认。
- 分类条件与搜索条件同时生效；切换分类不清空已输入关键词。
- 收起搜索框只隐藏输入框，不清空关键词，也不取消筛选。最终是否应清空由 Q-007 确认。
- 无匹配内容时展示「没有找到这处风景」，不展示空白列表。

**验收条件：**

- **DSC-001-AC01：**进入发现页时「最新」为选中状态；「推荐」入口隐藏；切换「同城」后选中状态与查询条件一致。
- **DSC-001-AC02：**在故事日期不同的数据集下，选择「最新」后，结果按日期从新到旧排列。
- **DSC-001-AC03：**打开搜索输入框后，分别以已知故事的标题、地点、作者中的唯一片段搜索，返回对应故事；关键词与最新/同城条件共同限制结果。
- **DSC-001-AC04：**输入不存在的关键词后展示无结果提示；清空关键词后恢复当前分类的可见结果。
- **DSC-001-AC05：**收起再展开搜索框时，当前关键词保留；收起期间列表仍保持相同筛选结果。
- **DSC-001-AC06：**卡片展示封面、标题、作者与点赞信息，点击封面或标题进入对应故事详情。

**源码证据：**[分类与搜索条件](../../../../app/(tabs)/discover.tsx#L14)；[分类与卡片交互](../../../../app/(tabs)/discover.tsx#L21)；[故事字段示例](../../../../src/mocks/discovery.ts#L3)。

**待确认问题：**评论当前不开放，是否恢复及审核/互动留存规则待后续确认；Q-013 匿名身份与历史导出文件撤回。推荐本轮不开放。同城匹配依据、前台定位和公开日记快照触发已局部确认。Q-001 浏览数据缓存与归属；Q-003 搜索输入长度和特殊字符边界。

### DSC-002 故事阅读

**证据状态：**【交互已表达】打开故事、返回、无效故事回到发现；【展示已表达】故事封面、标题、作者、日期、地点、正文和点赞信息。

**业务目标：**提供完整的故事阅读体验，使列表中的内容摘要能够展开为正文。

**前置与流程结果：**

1. 用户从发现卡片进入带故事标识的详情页。
2. 内容存在时，展示对应故事；用户可返回上一页或执行 DSC-003。
3. 内容不存在时，展示状态提示，并允许用户回到发现列表。

**明确规则与异常：**

- 详情必须与进入时选定的故事一致，包含封面、标题、作者、日期、地点、正文和点赞信息。
- 顶部返回操作返回上一页。
- 故事标识不存在时，展示「这篇故事暂时不在这里」及「返回发现」动作。
- 原型没有表达评论、关注作者、收藏或发布故事的用户流程；这些能力不属于当前基线。
- 自己的非私密日记按公开范围创建/更新发现快照，改回私密即撤下；匿名内容按姓名/别名规则处理，含照片且遮挡不可用时失败关闭。

**验收条件：**

- **DSC-002-AC01：**从任一内容卡片打开详情后，标题、作者、封面和日期与该故事数据一致，并展示地点及完整正文。
- **DSC-002-AC02：**点击详情顶部返回动作，返回进入详情前的页面。
- **DSC-002-AC03：**使用不存在的故事标识打开详情时，展示缺失提示；点击「返回发现」后进入发现列表。

**源码证据：**[详情数据与缺失状态](../../../../app/discover/[id].tsx#L13)；[故事展示字段](../../../../src/mocks/discovery.ts#L3)。

**待确认问题：**Q-007 评论权限、审核和撤回后的互动数据规则；Q-013 匿名显示与历史文件撤回。Q-002 若故事来自 AI 日记时的内容质量边界；Q-001 内容的数据归属及缓存。

### DSC-003 点赞与取消

**证据状态：**【交互已表达】列表与详情点赞、取消点赞及状态同步。

**业务目标：**让用户表达对故事的喜欢，并能撤回自己的点赞。

**前置与流程结果：**

1. 用户在发现列表卡片或故事详情点击点赞。
2. 当前用户的点赞状态变为已点赞，显示数量增加一。
3. 再次点击后取消点赞，显示数量恢复；另一入口同步反映同一状态。

**明确规则与异常：**

- 点赞是同一用户针对同一故事的开关状态，重复点击切换状态，不累计多个当前用户点赞。
- 未点赞显示空心图标；已点赞显示实心图标，并提供对应操作语义。
- 显示数量由故事基础点赞数与当前用户点赞状态共同组成。示例基础数不作为固定业务值。
- 列表与详情共享同一故事的当前用户点赞状态。
- 原型没有表达身份验证、请求失败、并发计数和撤回时限；正式规则由 Q-007 确认。

**验收条件：**

- **DSC-003-AC01：**对未点赞故事执行一次点赞后，图标变为已点赞，显示数量比操作前增加一。
- **DSC-003-AC02：**对已点赞故事取消点赞后，图标变为未点赞，显示数量比操作前减少一。
- **DSC-003-AC03：**在列表点赞后进入该故事详情，详情显示已点赞及相同数量；详情取消后返回列表，列表同步显示取消状态与数量。
- **DSC-003-AC04：**重复执行点赞 / 取消不会为同一故事保留多个当前用户点赞，也不影响其他故事的状态。

**源码证据：**[列表点赞](../../../../app/(tabs)/discover.tsx#L17)；[详情点赞](../../../../app/discover/[id].tsx#L16)；[共享状态切换](../../../../src/store/use-app-store.ts#L199)。

**待确认问题：**Q-007 点赞身份、权限、匿名交互、并发计数与失败恢复；Q-001 点赞持久化及跨设备同步。
