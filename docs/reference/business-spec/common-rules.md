# 通用规则与业务对象

本页集中记录跨页面、跨模块的一致性要求，避免在各页重复定义。规则依据当前可观察行为形成初稿，产品确认前不等于正式发布基线。

## 业务对象

| 对象 | 业务含义 | 关键关联 |
| --- | --- | --- |
| 日记 Diary | 已保存的图文记录 | 类型、排版师、照片、内容块、人物、公开范围 |
| 草稿 Draft | 新建或修改日记的工作副本 | 新建无来源日记；编辑指向原日记；记录生成状态和是否已保存 |
| 照片 Photo | 创作与展示的图片素材 | 时间、地点、人物关联、人脸区域；可被多个日记引用 |
| 内容块 Block | 正文、引用句或独立图片 | 正文可引用照片；独立图片可关联正文 |
| 排版师 Character | 写作风格与排版形象 | 创作选择影响生成；编辑更换可保留内容 |
| 人物 Person | 照片中的自己或同行者 | 当前照片分组、称呼、曾用名；跨作品档案待 Q-010 |
| 公开内容 | 供分享使用的日记内容范围 | 正文/引用句、关联照片、封面、摘要、匿名处理 |
| 发现故事 | 他人的公开内容条目 | 作者、地点、时间、正文、点赞状态；与个人日记关系待 Q-007 |
| 记忆锚点 | 对某段日记的简短理解 | 标签、原日记、用户纠正内容；生成规则待 Q-016 |
| 明信片/月度合集 | 日记之外的衍生展示 | 素材/装饰，或按月关联多篇日记；作品留存与导出待确认 |

来源：[日记类型](../../../src/types/diary.ts)、[状态管理](../../../src/store/use-app-store.ts)、[发现数据](../../../src/mocks/discovery.ts)。这些是业务对象梳理，不替代数据库表和 API 设计。

## 状态

| 维度 | 当前状态 | 转换要点 |
| --- | --- | --- |
| 日记内容状态 | 草稿 → 生成中 → 可编辑内容 | 内容生成完成并不等于已保存；还需草稿提交 |
| 生成任务 | 未开始 → 执行中 → 完成 | 离开执行页后本轮失效；重新进入可开启新一轮 |
| 草稿提交 | 未保存 → 已保存 | 重复提交返回同一作品；已保存草稿不再被修改 |
| 公开范围 | 私密/匿名公开/公开仅点赞/公开可评论 | 与生成、保存、是否已分享分别管理 |
| 洞察报告 | 未解锁/已解锁 | 页面校验解锁状态；解锁状态来源尚待 Q-006 |

开发映射可使用源码枚举，但不要将 `ready`、已导出、已分享和已保存合并成一个“完成”状态。生成失败、超时、后台恢复还没有完整状态定义，见 Q-002。

## 一致性规则

| 规则 ID | 初始规则 | 关联功能 |
| --- | --- | --- |
| BR-01 草稿隔离 | 新建草稿相互独立；编辑草稿不直接修改已保存日记。放弃后原日记保留 | CRE-005、DIA-002/005 |
| BR-02 提交一致性 | 新建生成新 ID；编辑沿用原 ID；同一草稿重复保存不重复创建作品 | DIA-005 |
| BR-03 生成有效性 | 暂停、离开或输入变化后，旧任务的进度/完成回调不得覆盖新状态。新建改变照片使生成失效 | CRE-005、DIA-003/004 |
| BR-04 照片有效性 | 选择集合去重、排除未知照片；新建生成要求至少 3 张不同的有效照片 | CRE-002/005 |
| BR-05 引用一致性 | 段落图片引用属于整篇照片集合；移除照片应同步关联图片、人物、封面、海报引用；清空段落引用应处理关联图片块 | DIA-003、MAT-002 |
| BR-06 默认隐私 | 新作品默认私密；更改公开范围是独立的保存动作，不以平台分享隐式改变范围 | CRE-005、SHR-001/005 |
| BR-07 公开内容一致性 | 明确选段时公开至少一段正文/引用句；对外内容只包含已选段及关联图片，摘要/封面/海报不能回退到未公开内容 | SHR-002/004/005 |
| BR-08 匿名一致性 | 已知姓名和别名在标题、正文、摘要、图片说明等处替换；人物身份信息不出现在公开内容；带人脸标记的照片显示遮挡 | SHR-003 |
| BR-09 私密与出口 | 私密可本地预览、长图/PDF，不能发到外部平台；导出记录与平台分享记录分别管理 | SHR-005 |
| BR-10 操作校验 | 空聊天不发送；空灵感回答不提交；空配图描述不生成；空锚点纠正不保存；无效日记/故事显示空态 | PET-001、MAT-004/005、GRW-004、DIA-001、DSC-002 |
| BR-11 共享状态 | 日记保存后各业务读取同一作品；发现列表与详情的点赞一致；锚点纠正不修改原日记 | DIA-005～007、DSC-003、GRW-004 |
| BR-12 能力边界 | 预告模板不能进入创作；锁定报告不能通过直接进入报告页绕过 | CRE-003、GRW-006 |

规则证据主要在 [领域规则](../../../src/store/diary-domain.ts)、[草稿与分享状态](../../../src/store/use-app-store.ts)、[流程退出处理](../../../src/hooks/use-diary-flow.ts) 与各模块页面。

## 尚未形成统一规则的事项

数据保存期限、重启/跨设备恢复（Q-001）；AI 质量与异常（Q-002）；输入限制与照片上限（Q-003）；日期区间和月份归属（Q-004）；统计口径（Q-005）；成长（Q-006）；社区身份与公开关系（Q-007）；新建/编辑换照片差异（Q-008）；人物长期记忆（Q-010）；匿名失败与公开撤回（Q-013）。这些需要业务决策后再补充开发契约和测试预期。
