# 中国香港及中国澳门发行隐私核对

日期：2026-10-29。仅供内部发布准备，不作为法律意见或已完成合规证明。

## 本次调整

- 当前发行计划收敛为中国香港和中国澳门，不在中国大陆或其他地区App Store发行；没有代用户修改App Store Connect销售区域。
- 线上政策草案升级1.4，章节标题改为“二、AI创作”，补充适用资料保护要求、查阅与更正渠道、境外处理说明。
- 保留既有政策正文其他内容与草案警示，不将尚未核验的模型归属、数据所在地、删除能力或授权撤回能力写成已验证事实。

## 两地都不是隐私豁免市场

中国香港《个人资料（私隐）条例》要求合法及适度收集、目的透明、控制保存期限、保障安全、公开政策和提供查阅/更正。不能因为没有注册或只有设备ID，就认定不处理个人资料。资料交给云服务或模型服务方处理，也要按实际说明用途与接收者类别。

中国澳门第8/2005号法律涉及资讯权、查阅/更正等权利、资料安全、敏感资料以及境外转移。适用时还须判断资料处理通知和许可义务。不能把“不在中国大陆上架”推导为“澳门无需通知、无需许可”。

香港专员公署公开跨境指引说明第33条尚未生效，同时鼓励保障跨境资料。发布前应核验最新生效状态；不要套用澳门的许可规则到香港，也不要因香港相关条款未生效而认定没有其他资料保护义务。

澳门第19、20条涉及向特区以外转移的适当保护及例外/许可条件。是否适用、采取何种合法依据，以及是否须通知或许可，应结合运营主体、收集方式、云服务与模型的实际处理地区判断。通用勾选同意不自动解决所有问题，也不能直接宣称所有跨境处理都一律须许可。

## 发布前重点

- 明确真实运营主体、联系地址和可受理请求的隐私邮箱。香港查阅要求存在适用的法定期限；不沿用任意的响应天数。
- 核实业务服务器、图片、备份及模型接收方实际地区。本次没有根据IP猜测机房所在地，也不因App在香港或澳门发行就宣称数据保存在当地。
- 核对云/模型合同、用户告知、同意、数据保护措施及澳门适用的通知/许可要求。
- 补齐内容保留、删除和备份退出期限，以及真实可用的用户权利渠道。暂保留政策中的待填字段。
- Apple对第三方AI数据处理的明确披露与许可、访客身份删除和公开内容治理等要求仍不因商店销售地区改变而免除。
- “AI创作”是章节标题，不是自研模型事实认证。现有自研表述仍是带假设标记的草案；实际部署曾核对为火山方舟，正式政策需与真实数据处理一致。
- 建议提供繁体中文政策及商店本地化；这属于语言体验建议，不能据此宣称现有App已有繁体中文界面。本次没有自动翻译或新增界面。
