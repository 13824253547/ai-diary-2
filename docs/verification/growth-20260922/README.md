## 素材处理与保留差异

修复脚本从 PPT 的 `image14.png` 和 `image4.png` 重新取局部插画，在限定文字范围内以字形掩膜进行 OpenCV Telea 修补，再将外缘平滑接到页面暖底。没有将整页截图作为页面背景；标题、文字、标签点击区域、按钮、进度和导航仍为原生 UI。

当前树为 **459 × 616 px**，三花组合为 **462 × 495 px**，玻璃罩花为 **162 × 182 px**。它们来自扁平合成稿，放大仍受原始分辨率限制；玻璃和花瓣的半透明视觉已与暖底合成，无法无损恢复真实图层透明通道、遮挡后的内容或额外高清细节。文字修补可能保留轻微底纹，不能宣称无损重建。

第三朵花的解锁画面是**同一原稿开放花朵的局部合成**，用于前端解锁演示；没有对应的独立 PPT 解锁稿，也不是生成式 AI 图片。锁定与解锁使用分开的组合素材，状态文字和进度由页面同步切换。

记忆锚点继续展示当前会话内真实关联日记的日期、标题、封面和摘录，所以部分照片、文案、换行与设计稿中的固定示例不同；没有为了截图替换关联记录或伪造详情。设计中的手机外框、圆角和系统栏不在应用内重复绘制；图标采用现有字体图标，其笔触不宣称与扁平设计逐像素相同。

素材来源、修复方法和坐标详见[成长素材说明](../../business/growth-assets.md)、[素材坐标与哈希](../../business/growth-assets.json)、[修复脚本](../../../tools/restore-growth-assets.py)。旧提取脚本及页面映射中整块透明挖空的过时指导已修正。
